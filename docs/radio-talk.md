# Рация и разговоры

> Подробности, перенесённые из CLAUDE.md. Обновляйте вместе с кодом системы.

## Рация и разговоры (`systems/Radio.ts`, `systems/Talk.ts`, `systems/phrases.ts`, `config/radio.ts`, `config/talk.ts`, `config/places.ts`, `world/places.ts`)
- **Происшествие** (`Radio.report(kind, x, y, {what, reporter, suspect, victim})`, `IncidentKind`, `RADIO.kinds`: код,
  сколько юнитов, бегом ли, важность, реплики): все тревоги идут через `WarSystem.raiseAlarm(…, info: AlarmInfo)` (вид,
  кто доложил, подозреваемый, пострадавший; `radio: false` — не в эфир; рации нет — прежняя строка журнала); сам
  `Radio` замечает юнит в бою в городе (`contact`), упавшего/погибшего юнита («потеря биосигнала», `unitDown`), погоню и
  задержание (хуки закона `LawSystem.onFlee/onLost/onArrest`), драку (`CpBrain.lookAround` → `brawl`), место
  преступления (`CrimeScenes` → `scene`: Надзор — следователю, медику, офицеру). Только город на сети (не КПП, пустошь,
  канализация), при красном коде вызовов нет. Рядом с открытым (`incident.merge`) — то же происшествие: важнее —
  повышение и ещё юниты, иначе «обновление» (не чаще `updateEvery`); нападение, бой, погибший юнит — **подмога**
  (`escalate`: ещё юниты бегом, не больше `times` раз). Открытых не больше `maxOpen` (мелкое вытесняется).
- **Вызов** (`dispatch`): ближайшие свободные (`CpBrain.canRespond(prio)`: патрульный или ведущий группы в обходе, не
  пост, не служба, не бой; едет на вызов не ниже важностью — занят) получают `CpBrain.call` (`RadioCall`: точка, до
  какого времени, бегом); `shouldHunt` → `hunt` к месту (`callPoint`: известный нападавший рядом с местом — к нему),
  ведомые группы — с ведущим. Доложивший (кроме погони) идёт молча. Игрок-ВС ближе `RADIO.player` — Надзор зовёт и его,
  событие `radio:call` ставит метку на карте. `watch`: прибыл (`arrive`) — «на месте»; вызванный вступил в бой —
  «контакт», подмога; все выбыли — Надзор шлёт ещё (раз); на месте тихо `calm` с — «чисто» / «задержан» /
  «нейтрализован» (по подозреваемому) и отбой; не закрыли за `maxTime` — отбой по таймеру. Беглец — точка вызова за ним.
- **Эфир** (`push` → `flush` → `air`): одна частота, строго по очереди (доклад → вызов → подтверждения), реплика —
  когда эфир свободен (`slot` × длительность + `gap`); залежавшееся дольше `stale` выпадает, очередь длиннее
  `maxQueue` — выпадает самое неважное. Подстановки — в момент выхода в эфир (`VarsSrc`: направление беглеца `{dir}`,
  где перехватить `{ahead}`, приметы `{suspect}` — `describe`: кто на вид, чем вооружён, в розыске; «буду через…» —
  `eta`). Юнит говорит облачком `say(…, 'radio')`, Надзор — `'dispatch'` над адресатами (до `listeners.max`), над
  игроком-ВС (важное) и над ближайшим к игроку не из ВС юнитом (слышно его рацию). Журнал: вызовы — всем, остальное —
  игроку-ВС или если сказано рядом (`hear`). `feed` — последние передачи (звук рации, тесты).
- **Плановое**: живой пост сам выходит на связь (`checkIn`, не чаще `routine.checkIn`, эфир пуст) — доклад по делу
  (`status`: пост, людно, ночь, патруль, группа N, прочёсывание, проверка, конвой, склад, фронт…) и «принято» Надзора
  с поправкой (ночь, код жёлтый, недавний вызов рядом — `statusAck`); Надзор опрашивает случайный юнит (`rollCall`) и
  даёт сводки (`info`: в розыске N, ночь, раздача, бой на КПП, вакансии, вызовов за смену). Фронт: КПП ожил, капт,
  точка потеряна, прорыв, отбили, Легион выдвигается (`front`) — гарнизон докладывает, Надзор отвечает; коды тревоги и
  штурм Управы — `code`.
- **Места в речи** (`world/places.ts` → `whereOf(zone)`, `config/places.ts`): имя зоны в предложном падеже («на
  Заводской улице», «в Старом квартале», «на КПП «Север», в шорте», «у склада Протектората»): точные имена, правила по
  форме (прилагательные «-ая/-ый/-ий»), по виду зоны, иначе «в районе «…»».
- **Слухи** (`Talk.event(kind, x, y, {who, gang, front, big, radius, cp, kinOf, rebels})`, `News`, `TALK.newsTopics`):
  из эфира (`Talk.incident`), смерти горожанина (родня знает сразу) и повстанца (весь лагерь), задержания, прорыва и
  потери точки (весь город), кодов, выборов, академии (набор, присяга). Узнают свидетели в `witness` px (выстрелы — в
  `hear`), вся сеть ВС (`cp`), родня (`kinOf`), все (`big`); у человека — не больше `perPerson`, живут `ttl` с.
- **Беседа** (`Talk.dialogue(a, b, setting)` → 2–4 реплики; `converse` — ведёт сама система, `update`: по очереди с
  паузой по длине фразы, разошлись дальше `maxDist` (у постов — `far`) — оборвалась; `busy`, `stop`, `mayLeave` — тему
  договаривают, не дольше `linger`): тема — слух, который знает A (собеседник узнаёт — `told`; уже знал — «слышал»;
  мелкие и частые — `newsWeight`), тема места (`TALK.settings`: улица, скамейка, семья, бочка, столовая, карты,
  перекур, банда, пост, лагерь, курсанты) по обстановке (`topicWeight`: голод, раздача, код, ночь, утро, бой у стены,
  стража рядом, работа, безработица, деньги, спор лоялиста с недовольным, район банды, родня — что с ней на самом деле,
  у ВС — последний вызов по рации и чем кончился `cpRadio`, потери, вакансии), иначе пара из старых списков. Ответ — по
  отношению собеседника (`attitude`: loyal, neutral, grumble, tough — банды и воры, cp, rebel); `variants` — «вопрос —
  свои ответы», `backTo` — реакция на ответ собеседника. Повтор темы с тем же — × `repeatMul`.
- **Фразы без повторов** (`phrases.ts`: `phrase`, `freshTemplate`, `remember`): у каждого свои недавние
  (`memory.own`) и общие недавние (`memory.global`); всё звучало — давнее всех. Род в шаблонах: `{м|ж}` — по
  говорящему, `[м|ж]` — по собеседнику (`gendered`; силовики — мужской). Через `phrase` идут реплики закона
  (`config/lines.ts`, расширены), паники, медика, охраны, сна, банды на районе, боя (`Barks`). Один говорит
  (`Talk.remark`): слух, обстановка или реплика занятия (бочка, скамейка, карты, перекур, доска — с именем
  разыскиваемого, столовая, обращение Коменданта по отношению); на улице — `streetBark` через `remark` (ВС — свои
  реплики и о недавнем вызове).
- **Где беседуют**: `CitizenBrain` chat (родня — `family`, одна банда — `gang`), скамейка, бочка (сосед по кругу),
  столовая (сосед по столу); `CpBrain.postLife` — напарники на постах (до двух тем); лагерь (`RebelBrain` camp —
  `chatNear`), курсанты на обеде и в личное время (`CadetBrain`).
- **Облачка** (`EntityRenderer.drawLabels`, `RENDER.entity.bubble`): перенос по словам (`maxWidth`, `maxLines`),
  хвостик к голове; рация — тёмно-зелёное с рамкой и значком рации, Надзор — тёмно-синее с биркой «НАДЗОР»; реплики
  рации важнее в раскладке (`radioScore`) и видны и при отдалённой камере. Звук — `GunfireAudio.radio` (`AUDIO.radio`):
  «кшш» в начале передачи, у Надзора — двойной писк; игроку-ВС — все, остальным — рядом. В «отряд на отряд» рация и
  беседы выключены (`enabled`).
- Тесты — `tests/radio.test.ts` (места в речи, вызов → выезд → отбой, слияние и подмога, биосигнал, погоня, драка,
  одна частота, пост на связи, КПП, вызов без тревоги), `tests/talk.test.ts` (слухи и пересказ, весь город и родня,
  ответ по характеру, спор, родня в КПЗ, ВС о вызове, род, без повторов, беседа в мире).
