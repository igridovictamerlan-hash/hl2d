# CLAUDE.md — Верхнеречье

Браузерная 2D-игра с видом сверху в духе ролевых серверов: оккупированный город у ГЭС, тесные переулки под
контролем Протектората (лор — `LORE.md`, вводная в меню — `INTRO` в `config/menus.ts`). Все персонажи — пешки в стиле RimWorld (цвет формы по рангу) с подписью имени/роли. Игрок управляет одним,
остальные — NPC, ведущие себя как игроки RP-сервера.

**Язык:** интерфейс, комментарии и документация — по-русски; идентификаторы в коде — по-английски.

## Свой мир вместо HL2 (названия)
Игрок видит только названия своего мира; внутренние идентификаторы в коде остались прежними (так
меньше правок и сохранения не ломаются). Новые тексты пишите в новых названиях:

| В коде (id, тип) | Игрок видит |
|---|---|
| город, `Сити-17` в старых сохранениях | Верхнеречье |
| `Alliance`/`combine`, `authority` | Протекторат |
| `cp` (силовой блок) | Внутренняя стража, кратко «ВС» (позывные `ВС-1234`) |
| `ota`, `OtaBrain`, `ota_alpha`/`ota_king` | Легион: легионер `LGN.ALPHA`, претор `LGN.PRAETOR` |
| `cwu` | Трудовой союз (ТС) |
| `vort`, `vort_slave` | поднадзорные: серая роба с номером, ошейник-маячок (`PAWN.outfits.vort.convict`) |
| `admin` | Комендант |
| зона `nexus`, POI `nexus_*` | Управа (женский род: «Управа захвачена») |
| «Цитадель» (откуда корабли) | ГЭС («с ГЭС», «на ГЭС») |
| HYDRA (`elite`, `hydra_*`) | спецотряд «Гроза», нашивка-молния (`O.lambda` — её цвет) |
| `ar2` (`pulse`) | импульсная винтовка Легиона «ИВЛ» |
| `cremator` | Санитар |

## Команды

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # vitest: генератор, A*, коллизии, JSON, симуляция NPC
npm run typecheck  # tsc для src и tests
npm run build      # typecheck + сборка в dist/
npm run mapstats   # метрики генератора по 30 сидам (DEBUG_GEN=1 — причины отбраковки попыток)
npm run worldstats # аудит живого мира: MINUTES игровых минут города (SEED) — смерти, еда, деньги, занятия, застрявшие
```

Параметры адреса: `?seed=123` (карта по seed, пишется в адрес автоматически), `?map=city17`
(загрузить `public/maps/city17.json`), `?npcs=40`, `?debug=1`, `?mode=squad&side=rebel|combine`
(экспериментальный режим «отряд на отряд»), `?touch=1` (сенсорное управление и с мышью).

## Стек и почему без движка

TypeScript + Vite + HTML5 Canvas 2D, без игровых движков. Всё ключевое здесь нестандартное —
генератор переулков, туман войны лучами, A* по якорям 2×2 с учётом радиуса, уступание дороги;
Phaser не дал бы готового для этого, а добавил бы свой цикл, сцену и физику, с которыми пришлось бы
бороться. Логика не зависит от DOM и целиком тестируется в Node (vitest), включая безголовую
симуляцию NPC (`tests/simHarness.ts`).

### Тик логики (`Game.update`, 60 Гц)
1. `PlayerController`: ввод → `player.wantX/wantY`, взгляд на курсор, прицел (ПКМ), огонь, смена оружия, E/F/1/2/3.
   Задержанному игроку временно ставится `PrisonerBrain` — тогда ввод движения игнорируется.
2. `updateNpcs`: мозги (FSM) → `Mover` выставляет `wantX/wantY` → `dodgeGrenades` (граната рядом —
   бегство поверх решения мозга) → присед (в бою стоит — сел, `CROUCH.npcStill`); тяжелораненые
   лежат, их мозг ждёт; затем `PathService.process()`.
3. `DoorSystem`: двери открываются, если рядом кто-то есть; закрываются через `DOORS.closeDelay`.
4. `stepPhysics`: разгон → движение → расталкивание по массам → выталкивание из стен.
5. `LawSystem.update`: неподчинение игрока, заведение в камеру, сроки, освобождение.
5a. `EconomySystem` (раздача, голод, зарплаты, поломки) → `CombatSystem` (пули в полёте, гранаты, дым,
   перезарядка, перевязка, кровотечение, регенерация, уборка убитых) → `Particles` (эффекты) →
   `WarSystem` (отряды у КПП, подкрепления, прорыв, тревоги) → `InsurgencySystem` (гарнизон убежища,
   операции) → … → `CwuHq` → `ArsenalSystem` (борт и заявки, брошенный груз, приёмка, отсек, конвои, смена, заряд, инспекция) → … → `Radio` (эфир, происшествия) → `Talk` (реплики бесед) → возрождение игрока. В «отряд на отряд» после боя — только `SquadArena`.
6. Видимость: многоугольник обзора игрока (`VISION.rays` лучей DDA) и `c.visible` у всех.
7. Камера (в границах уровня игрока; сменил уровень — `snapTo`), зоны, UI (DOM — с частотой `GAME.hudInterval`).

Отрисовка (`Game.render`): карта → терминал найма → эффекты на земле (тела, щитки, очередь, склад и
тень корабля, тюрьма) → персонажи (только видимые; нос-треугольник — взгляд, силуэт оружия по классу) → ящики
в руках грузчиков → конусы NPC → дымок из труб → **свет** (карта света × картинку) → свечение ламп и
огня, маяк склада → пылинки → частицы боя → пули и гранаты → взмахи дубинки → туман → отсвет взрывов и
дым → корабль Протектората (в небе — поверх тумана) → конус игрока → подписи и реплики → отладка → виньетка →
зерно → красный код/ранение → вспышка ранения и маркер попадания → указатели на КПП → колесо оружия → прицел. Интерполяция `prevX → x`.
Вспышки выстрелов, пули и частицы рисуются после света — ночью они ярко видны.

### Свет и уют (`world/Lighting.ts`, `world/Ambience.ts`, `config/lighting.ts`) — только картинка
- **Время суток**: `LIGHTING.dayLength` с игрового времени (`Game.time`), начало — закат (`start`);
  `dayFraction`, `dayState` — плавно между ключевыми точками `keys` (свет вокруг `ambient`, насколько
  горят лампы `lamps`, название), `clockText`; часы в HUD («19:40 · вечер», `Game.clock`). На логику
  не влияет (NPC видят как раньше).
- **Карта света** (`Lighting.draw`): холст в `lightmapScale` от экрана — заливка светом суток, поверх
  сложением мягкие пятна-спрайты (по спрайту на цвет): фонари улиц (`lamp`, ночью), бочки и костры
  (мерцают), комнаты и места по POI (`LIGHTING.pois`: жилые — тёплые лампы, Протекторат — холодный белый,
  КПП — прожекторы, `night` — только в темноте), узлы Протектората (сломан — не горит), свет из люков в
  канализации; пламя, взрывы, вспышки выстрелов (`Fx.t`, `muzzle.time`), горящие, свой свет игрока.
  Потом `multiply` на картинку. Ясный день — проход пропускается (`skipDay`); канализация — свои
  сумерки (`sewer`). Источники карты собираются раз (`staticLights`).
- **Свечение** (`drawBloom`): плафоны, окна, огонь — пятна в мелком буфере, на экран одним проходом
  `lighter`, тем ярче, чем темнее. **Пылинки** в свете ламп, **дымок из труб** (`MapRenderer
  .chimneyPoints`, сносит ветром, чаще ночью), **зерно** (тайл шума со сдвигом раз в два кадра),
  тёплая виньетка (`COZY.vignette`), тёплая палитра интерфейса. Звук: ветер с порывами (ночью громче),
  треск огня у бочек и костров (`GunfireAudio.ambient`, `AUDIO.ambient`, `Game.fireSpots`).
- **Меню**: «Атмосфера» вкл/выкл (`COZY.storageKey`). Слабая машина (кадров меньше `autoLite.fps`
  дольше `after` с) — упрощённо (`lite`: без зерна, свечения и пылинок), сама обратно не усложняется.
- Тесты — `tests/lighting.test.ts` (сутки, часы, источники).

### Ключевые понятия
- **Тайл** 16 px. Город 300×230 тайлов (4800×3680 px; главный проспект между КПП ~165 тайлов —
  бегом ~15 с) в кольце пустоши за стеной (8 тайлов слева и справа, 26 снизу: тропа и лагерь
  сопротивления) — 316×256; справа за зазором — канализация (масштаб 1:2), вся карта 478×256. Типы — `world/tiles.ts` (`solid`, `opaque`, символ для JSON).
  Добавляя тип, допишите его в `TILE_DEFS`, палитру `MapRenderer` и `DevPanel`.
- **Уровни** (`Level`: city / sewer) — две области одной сетки без прохода между ними; связь только
  люками. `GameMap.underground` (прямоугольник канализации по её зонам), `levelAt`, `levelBounds`;
  `NavGrid.level` по якорям. A* между уровнями сразу отказывает, `randomAnchorAround` берёт цели
  только на своём уровне, камера не выходит за границы уровня, в канализации обзор короче
  (`VISION.sewerRadius`), выстрелы с другого уровня не слышны.
- **Якорь 2×2**: персонаж радиусом 12 px занимает квадрат 2×2 тайла. Якорь (ax, ay) ↔ центр в
  ((ax+1)·16, (ay+1)·16). Связность карты, A* и поиск «карманов» работают по якорям — поэтому
  проход 2 тайла (32 px) пропускает ровно одного, 3 тайла (48 px) — двоих.
- **Зоны** — сетка `zoneGrid` (id зоны на тайл) + список `zones` (kind + имя). `ZoneKind`:
  residential, avenue, plaza, nexus, cells, industrial, restricted, checkpoint (пограничные КПП),
  outlands (пустоши за стеной), shop (магазин ТС, лавки и кафе проспекта — у каждой своя зона с
  названием), sewer, rebel_base (убежище), black_market, cwu_hq (штаб ТС), arsenal (склад Протектората),
  canteen (общая столовая), prison (тюрьма Протектората), academy (академия ВС).
- **Точки интереса (POI)** — `map.pois` в координатах тайлов: лагерь сопротивления и его тайник, окно раздачи, центр площади, терминал
  найма, ворота и стойка Управы, терминал кодов тревоги, камеры КПЗ, ворота запретной зоны, заводские дворы, посты часовых
  КПП, выходы в пустоши, люки (`hatch` в городе / `sewer_hatch` в канализации: якорь 2×2, x,y — его
  левый верхний тайл; пары связаны одинаковым `id`), убежище, тайник, прилавок и место торговца.
- **Двери** — группы соседних тайлов `DOOR`. Состояние (закрыта/заперта) живёт в `GameMap.doorClosed/
  doorLocked`: закрытая перекрывает обзор (`isOpaque`), запертая — ещё и проход (`isSolid`).
  Запирание вызывает `NavGrid.refresh` вокруг двери.
- **Видимость**: `visibility.ts` — луч DDA до первого непрозрачного тайла. Игрок видит в радиусе
  `VISION.radius`; NPC — в `VISION.npcRange` с углом обзора `npcFovDeg` (вплотную — во все стороны).
  Одни и те же функции для игрока и NPC: от ВС можно скрыться за поворотом или за дверью.
- **Фракции и ранги** — `config/factions.ts`. Цвет формы пешки по рангу (`colorsOf`): ВС от голубого
  (RCT) до тёмно-синего (DvL). У сопротивления юнит — по профессии (`REBEL_RANKS`, `rebelUnitOf`,
  `REBEL_UNIT`; `rank` = номер юнита, HP — `roleHp`): армия — жёлтые ники, глава Патрик и HYDRA
  (`elite`) — красные. Рубаха армии синяя, жилет — с солдата.
  `authority` — кто проверяет, а не проверяется (ВС, OTA, комендант).

### Генератор (`world/generator/CityGenerator.ts`)
1. `layout`: магистраль по центру (+ вторая с шансом 50%), линии решётки с отступами от проспекта,
   углы запретной зоны и промзоны, площадь на длинном прямом участке проспекта, Управа рядом.
   **Проспект старого города** (`GENERATOR.avenue`, `planAvenueSegs`): ширина `width` (10), ось плавно
   изгибается (`bends` полуволн синусоиды амплитудой `amp`, от КПП разгон `ease`), проспект — череда
   участков `segmentLength` (≈ фасад дома; `AvenueSeg` — свои `offset` и `width`), ось на стыке сдвигается
   не больше `maxStep`, края — ещё на ±`edgeJitter`; у площади — прямой участок. Линии решётки отходят от
   проспекта на полосу домов (`avenueSpacing`: `avenueReach` + `facadeReach`); переулки от узлов
   проспекта пересекают её прямо — излом ребра за полосой (`constrainAvenueLanes` → `LEdge.kinkMin/
   kinkMax`). Между фасадом Управы и неровным краем асфальта — площадка (`fillForecourt`).
1б. **Улицы-артерии** (`generator/streets.ts`, `GENERATOR.streets/dorms/villas`) — по решётке после
   разметки регионов, до лабиринта (`planStreets`): стволы шириной 4 от узлов проспекта (и от дальнего
   края площади) на `branchRow` линий вглубь, на конце — ветви вдоль горизонтальной линии в обе
   стороны (до `branchMax` рёбер), от ветвей — улочки шириной 3 (`lanes`) дальше вглубь; сторона без
   стволов (там Управа и КПП) получает улицу через `detachedRow` линий. Рёбра артерий сразу вырезаны
   (`LEdge.artery`, ширина не меняется в `finalizeEdges`), изломы Z-образные, как у переулков; асфальт
   (`carveArteries`), у каждой артерии своя зона вида `avenue` («улица Гидростроителей»…, `ZONE_NAMES.streets`).
   Вдоль улиц — места под **общежития** (`DORM_TEMPLATE` 21×17: Т-коридор, 7 комнат `r` → POI `home`
   с `kind: 'dorm'`, общая комната `m` → `dorm_common` со столом `x` → `dorm_table`) и **особняки
   лоялистов** (`VILLA_TEMPLATE` 16×14: живая изгородь `h` → `HEDGE`, сад `v` → `GARDEN`, деревья `t`
   → POI `tree`, спальня → `home` `kind: 'villa'`, гостиная → `villa_living`); вход на улицу
   (`faceTemplate`: S/N/E/W), здания — пустоты решётки (лабиринт их обходит), штампуются вместе с
   Управой, выходы прокапываются. Зоны: «Общежитие №k», «Особняки лоялистов» — вид residential
   (стены — штукатурка). Символы зон в JSON у многочисленных зон (улицы, общежития, особняки) —
   первый свободный из `ZONE_CHAR_POOL` (`addZone(…, null)`). Проверка карты требует ≥ 2 общежитий
   и ≥ 2 особняков.
   **Штаб ТС** (`CWU_HQ_TEMPLATE` 25×17, `GENERATOR.cwuHq`) — в макроплане (`layout.cwuHq`, пустота
   решётки, как Управа): фасадом прямо на главный проспект (площадка до изгибающегося края —
   `fillForecourt`), не ближе `cpClear` к КПП; из мест вдоль проспекта — самое далёкое (по краям
   прямоугольников) от Управы и площади и от КПП × `cpWeight`. Т-образный коридор,
   как в Управе: сверху цех фасовки `p` с тремя конвейерами `y` (POI `ration_line`) и складом коробок
   `u` (`cwu_store`), комната отдыха `l` (`cwu_lounge`), кабинет главы `e` (`cwu_office`) со столом `H`
   (`cwu_head_desk`); по сторонам «ножки» — приёмная `a` (`cwu_lobby`) со стойкой найма `J` (`cwu_hire`)
   и столовая `n` (`cwu_canteen`); POI `cwu_hq` — прямоугольник здания, `cwu_production` — цех. Зона
   `cwu_hq` «Штаб ТС» (пол — плитка). Помещения по символам — `StampResult.areas`. Проверка карты
   требует штаб, стойку, стол главы, три конвейера и склад.
   **Склад Протектората** (`ARSENAL_TEMPLATE` 32×42 — здание 32×27 и крыльцо 14×14; `GENERATOR.arsenal`) —
   последним и на своём генераторе (`rng.fork`: штаб, общежития и особняки не сдвигаются): из `tries`
   свободных мест (`fits`) — те, откуда до улицы, начинающейся у проспекта (`Artery.rooted` — стволы от
   проспекта и площади и их ветви/улочки; отдельные улицы `detachedRow` — нет), не дальше `road.reach`,
   и из них самое далёкое от проспекта (минус `road.penalty` × длина проезда; `StreetPlan.arsenal`);
   крыльцо — в сторону проспекта (`face` S/N). **Вход один**: проём в ограде крыльца `Y` (пол `BUNKER`,
   ~14×15: места сброса `X` → `arsenal_drop`, маяк `Q`, мачты `4` → `arsenal_mast`, посты `E` — по бокам
   двери и проёма, не в проходе) → дверь `D` → коридор `,`. Помещения (`StampResult.areas` → POI с w/h): зал `s` →
   `arsenal_hall` (стойки `S` вдоль стен → `arsenal_rack`, три блока стеллажей `A` → `arsenal_ammo`,
   проходы по 2 тайла — всё достижимо якорем 2×2), гранатный отсек `j` → `arsenal_vault_room` (полки `G`
   → `arsenal_grenades`, дверь `L` в 3 тайла → `arsenal_vault`), мастерская `N` → `arsenal_workshop`
   (верстак `O` → `arsenal_bench`, ящики консервации `U` → `arsenal_repair`), выдача `f` →
   `arsenal_issue_room` (окно `W` в коридор → `arsenal_window`, стол кладовщика `K` → `arsenal_desk`,
   расходный стеллаж `5` → `arsenal_issue`), контора `e` → `arsenal_office` (опись `I` →
   `arsenal_ledger`), бытовка `1` → `arsenal_breakroom` (стол `2` → `arsenal_table`), караулка `z` →
   `arsenal_guardroom` (койки `V`; здесь ждёт экипаж конвоя — `crewSpots`), крыльцо → `arsenal_pad`.
   Места у верстака и стола описи — со стороны комнаты (`access`, склад бывает развёрнут входом на север). Мебель, стеллажи и стойки — `BARRIER`
   (укрытие: не пройти, видно поверх). Символы шаблонов общие (`TEMPLATE_TILES`) — у склада свои, с
   Управой и штабом не пересекаются. Проём — на **«Складской проезд»** (`carveAccessRoad`: фартук
   `apron` перед фасадом + кратчайший путь BFS шириной `width` до улицы от проспекта или площади,
   асфальт, своя зона вида avenue), не в переулок. Зона `arsenal` «Склад Протектората» (жители, санитар и
   патрули её избегают; гражданин внутри — нарушение `restricted`). Проверка карты требует склад,
   стол, 2 тайла окна, опись, 8 мест сброса, маяк, 4 поста, верстак, площадку, зал, 4 полки выдачи,
   ящик консервации, бытовку, выдачу, ≥ 40 ячеек патронов, ≥ 12 гранат, ≥ 20 стоек.
2. `lattice`: узлы с «дрожанием» (соседи на линии смещены ≥ 3 тайла) → лабиринт «растущее дерево»
   от узлов проспекта + петли (несколько маршрутов). Рёбра вырезаются Z-образно; излом ставится так,
   чтобы прямой участок ≤ 25 тайлов и перемычка не вставала в створ соседних переулков.
3. Вырезание переулков и магистралей, чистка «шипов» (двухфазная — иначе съедаются тонкие стены).
4. Зоны, штампы: площадь с будкой и терминалом найма, Управа по ASCII-шаблону (`templates.ts`,
   правится руками, 36×30: 7 одиночных камер КПЗ `c`, общая камера `C` → POI `common_cell` (x, y, w, h),
   коридоры в 4 тайла (Т-образный зал), двор с воротами, кабинет Коменданта с
   терминалом `T`, канцелярия со столами `w` → POI `clerk_desk`, казарма ВС с нарами `b` → `bunk`,
   комната OTA `q` → `ota_spot`), кольцо запретной зоны с КПП (позиция ворот подбирается перебором),
   два пограничных КПП на концах главного проспекта (шаблон `CHECKPOINT_TEMPLATE`, восточный —
   зеркальный, 66×25): пустошь → внешние ворота → **внешний двор** (D3/D5) → два прохода, как в CS:
   **шорт** (прямой, 3 тайла) и **лонг** (обход поверху) → **внутренний двор** (D4/D6) → внутренние
   ворота → **проходная** → дверь → проспект (ось — `CHECKPOINT_AXIS_ROW`). Во дворах бетонные
   блоки-укрытия (`BARRIER`: не пройти, но видно поверх), посты `P` (2 во внешнем, 3 во внутреннем)
   и бункеры ВС. Проходная (`CHECKPOINT_GATEHOUSE_X`) отгораживает город от боя: стена-«зигзаг» на
   оси (из двора в город нет ни прямой видимости, ни прострела — даже при открытой двери), дверь со
   стороны проспекта (закрыта, пока рядом никого) и 2 поста RCT `R` (POI `gate_post`). Каждая часть —
   своя зона (`checkpointSection`, имена «… · D3», «… · шорт», «… · лонг», «… · D4», «… · проходная»).
   Пол КПП (`BUNKER`) не считается «переулком» в метрике прямых участков.
4б. **Ряды домов** (`generator/arbat.ts`, `GENERATOR.facades`, `config/arbat.ts`) — после штампов, до
   деталей застройки: вдоль обеих сторон проспектов (`avenueFrontages`), трёх сторон площади
   (`rectFrontages`) и прямых кусков улиц-артерий (`arteryFrontages`) — сплошной ряд домов шириной
   `width`, глубиной `depth` (обрезки уже `minWidth` отходят соседу — фасад со ступенькой, дверь тогда
   в нише с улицы). Дом (`FacadeBuilding`): стены в тайл, комната, дверь 2 тайла на улицу, заблокирован;
   POI `facade` (прямоугольник, `face`, `use`: house/shop/cafe/canteen, `sub` — лавка). Сначала столовая
   — на главном проспекте, почти прямой кусок фасада ближе к площади (`canteen`: зал с кухней, раздачей
   `canteen_cook`/`canteen_serve` и рядом столов `canteen_table`, зона `canteen`); потом дома по всем
   улицам (жилые — POI `home`); из домов главного проспекта и площади ближе к площади — лавки
   `ARBAT.shops` (прилавок `BARRIER` в ряду `counterRow`, `shop_front` — покупатель, `vendor_spot`;
   первая — магазин ТС, даёт `shop_counter`; иначе — старый `stampShop`) и кафе `ARBAT.cafes` (`cafe_table`);
   у каждой лавки своя зона с названием. Посередине проспекта (`placeAvenueDecor`, `decor`) — ларьки 3×2
   (`kiosk`, `sub`, окошко на `face`) и клумбы 2×2 (`planter`) через `every` тайлов, чередуясь: укрытие
   `BARRIER`, вокруг кольцо асфальта, не у устья переулка, не ближе `endClear` к КПП. Проверка карты
   требует столовую, ≥ 2 стола, ≥ 2 ларька, ≥ 40 домов и ≥ 4 продавцов.
5. `features`: заводские дворы, дворы-колодцы с арками, сквозные арки (только если обход длинный;
   подъезды-коридоры с дверями отключены — `passages.archChance = 1`), тупики. Каждая деталь
   откатывается (`GenGrid.snapshot/restore`), если открывает прямой обзор длиннее нормы.
5б. **Городок** (`world/houses.ts`, `generator/homes.ts`, `HOUSES`): сплошная застройка (WALL) между
   переулками режется на участки-дома (`computeLots`: связные массивы стен рекурсивно делятся на
   прямоугольники `lot.min…max`) — детерминированно по тайлам и seed, поэтому генератор и
   `MapRenderer` получают одну нарезку без хранения в JSON. `addHomes`: доля `homes.share`
   прямоугольных участков у переулка в жилых кварталах — жилой дом: стены в тайл, пол
   (`INTERIOR`), дверь в 2 тайла на переулок, POI `home` (x, y, w, h — пол комнаты, для мебели);
   прострел длиннее нормы — откат. Узкие переулки (2–3 тайла) не меняются. Отрисовка: у каждого
   участка своя двускатная крыша (сдержанный серый шифер с лёгкой разницей оттенков — `RENDER.tiles.roof`;
   скаты, конёк, черепица, труба, швы между домами), стены
   жилых домов — светлая штукатурка. Дома вдоль улиц (POI `facade`) крыш не имеют: у каждого своя
   штукатурка (`RENDER.facade.plaster`, приглушённые пастели старой Европы), по фасаду — цоколь, окна
   через `windowEvery` тайлов (у лавок — витрины с бликом), над входом лавки — полосатая маркиза с
   вывеской трафаретом (`MapRenderer.overlays`, в кэше кусков карты); прилавки и столы — дерево, ларёк —
   с окошком и вывеской, клумба — с цветами; проспекты вымощены брусчаткой (`cobble`). Ночью светятся
   витрины, окошки ларьков и зал столовой (`LIGHTING.pois`). Пол помещений: в жилых зонах — доска, в остальных (Управа,
   КПЗ, магазин) — серая плитка (`MapRenderer.floor`, `RENDER.tiles.woodFloor/tileFloor`).
5в. **Убранство** (`world/furnish.ts`, `config/furniture.ts`, `world/FurnitureRenderer.ts`) — не
   генератор, а отрисовка по готовой карте: `furnishMap` детерминированно раскладывает мебель по
   комнатам (POI `home` по `kind` — дом, общежитие, особняк; `dorm_common`, `villa_living`) по
   рецептам `FURNITURE.recipes`: вдоль стен, от углов к середине, проход у двери (`doorClear`)
   свободен; кровать обязательна (в тесной комнате — узкий проход `doorClearMin`, потом кровать
   поменьше), стол со стульями — после кровати, в свободной части. Размеры — по пешке (≈16×28 px):
   кровать 22×32, двуспальная 36×34, койка казармы 20×30. Плюс мебель Управы по точкам шаблона
   (койки `bunk`, столы канцелярии, шкафчики OTA) и стол для карт общежития. Рисунок в духе
   RimWorld (плоские заливки, тёмный контур, волокна дерева, цветные корешки книг), каждый предмет —
   спрайт в кэше (вид, размер, поворот, вариант, квантованный масштаб).
6. `ensureConnectivity`: flood fill по якорям; мелкие фрагменты засыпаются, крупные соединяются
   тоннелем минимальной стоимости (Дейкстра); недостижимые тайлы засыпаются.
7. Метрики и проверка (`validateMap`: точки интереса, связность, доля застройки; ворота запретной зоны
   ведут в общий город — `restrictedReachable`, иначе люки подполья в отрезанной зоне бесполезны); до
   `GENERATOR.validation.attempts` попыток, иначе лучшая.
8. `wastes.addWastes`: карта расширяется влево, вправо и вниз — скалы (`ROCK`), в них тропа шириной
   `trail` от выхода в пустошь каждого КПП (проход сквозь стену) вдоль края и по низу карты; в
   середине нижней полосы — лагерь сопротивления (зона `rebel_camp`, POI `rebel_camp`, `camp_cache`).
   Тропа — зона `wasteland`: горожане, патрули и сканеры туда не ходят.
9. `sewers.addSewers`: карта расширяется вправо; ровно два люка — в запретной зоне у края города
   (`hatchEdge`; зона застроена — прорезается ход от площадки к воротам, `carveHatchYards`: якорь хода —
   внутри стен зоны или на уже проходимом, так что с ворот в кольце стен шагнуть можно), сеть тоннелей (решётка → «растущее дерево» + петли; 3 тайла — сток
   посередине, дорожки по бокам), от каждого люка в масштабе 1:2 — ниша с лестницей и сухой ход к
   узлу, убежище с ящиками-укрытиями и тайником, рядом чёрный рынок с прилавком; засыпка мест, куда
   не пролезть. Только добавляет проходимое — связность по построению (проверяет тест).
Генерация детерминирована по seed; ~25–40 мс на попытку.

### Формат карты JSON (`world/mapIO.ts`, версия 1)
`tiles` и `zoneGrid` — массивы строк по символу на тайл (легенда в `legend`), `zones`, `pois`
(у люков — `id` пары), `stats`. Связность в F2 и тестах считается с учётом люков (`hatchLinks`). Карту можно поправить в редакторе с моноширинным шрифтом; при загрузке проверяются размеры
и символы (ошибка с номером строки/столбца), панель F2 показывает связность и прямые участки.

### ИИ NPC
- `Brain` (интерфейс) решает, что делать; каждая фракция — свой класс в `ai/brains/` с
  `StateMachine` (idle, walk, work, patrol, chase, flee, fight, arrested — по мере этапов).
- `Mover` — общее передвижение: запрос пути, следование со «сглаженным» путём, объезд встречных
  по правилу правой руки (но не в стену), распознавание блокировки:
  встречные лоб в лоб → уступает младший по `FACTIONS[*].yieldPriority` (игрок главнее всех),
  при равенстве — тот, кому ближе до «кармана»; стоящего NPC просят отойти; стоящего игрока ждут,
  потом разворачиваются; упёрся в стену — перестраивает путь. Проскочил точку пути (оттолкнули) —
  следующую берёт, только если первые `AI.move.skipCheck` px к ней не в стену (`openToward`).
  Сторож затора (`AI.move.giveUp*`, `ghost*`): идёт к цели, но не отходит дальше 64 px от одного места —
  через 4 с, упираясь в NPC, ненадолго проходит сквозь NPC (`Character.ghost`, физика не расталкивает;
  игрока — никогда), через 12 с бросает цель (`failed`). Тест: никто не упирается дольше 20 с.
- Цели прогулок — `ai/destinations.ts`; зоны, которых NPC избегают, — через `avoidZones` в A*.

### Кулаки, драки и «братва» (`systems/Brawls.ts`, `config/brawl.ts`, `ctx.brawls`)
- **Кулаки у всех** (`FISTS`, `CombatSystem.punch`): удар пустыми руками — не оружие и не предмет (в руках
  ничего, `c.weapon` остаётся null); игрок — ЛКМ без оружия. Кулаком не убить: здоровье не ниже `floor`,
  дошёл до него — нокаут (оглушён `knockout` с, `knockedOut`). Удар по сотруднику Протектората — нападение

  идёт вперёд (капт — `coverLeft` стоит), граната в прижатую цель — × `TACTICS.grenadeMul`. Игроку —
  тёмные края (`RENDER.suppressVignette`, `Game.drawCondition`), дрожь и щелчок пролёта (`Fx` `whiz`,
  `GunfireAudio.whiz`, `AUDIO.whiz`).
- **Присед** (`CROUCH`, `Character.crouch`; игрок — C, бег встаёт; NPC — `updateNpcs`): скорость ×
  `speedMul`, конус × `spreadMul`, прицел быстрее, в ноги реже (`rollZone(…, legMul)`). Низкое укрытие:
  у присевшего бетонный блок ближе `coverReach` на линии огня держит пулю с шансом `coverStop` (запись

  (`squash` по вертикали к ступням).
- **Тяжёлое ранение** (`DOWNED`, `Character.downedUntil/downedAt`, `downed`, `fit` — жив и на ногах):
  смертельный урон — `down()`: лежит `time` (20) с, `health` 1, не стреляет (`busy`), не угроза
  (`threat`), пули поверх (в него — только прицельно, в своего лежащего — никогда; выпущенные до падения
  — мимо), физика и `Mover` его не замечают; истёк — смерть от ранившего (`bledOut`). Сразу насмерть:
  голова без шлема (`damage(…, instant)`), взрыв ближе `blastInstant` радиуса, урон сверх `overkill` ×
  макс. здоровья; кровотечение до нуля — тоже падает. Любой урон по лежащему добивает (`finished`).

  через `heal` поднимают сразу. Тащить (`startDrag/stopDrag`, игрок — X): `dragDist` позади,

  `law.arrest`; задержанные (`inCustody`) — не цель. Добивание — `Gunner.wantsFinish`: раз за падение
  на сторону (`finish`: OTA, повстанцы, ВС — только на фронте). Счётчики: `downs`, `revives`,
  `finished`. Отрисовка — `EntityRenderer.downedBody` (лужа, пешка на боку, кольцо-таймер), подпись
  «тяжело ранен · N с», экран игрока — красные края и надпись. В войне и арене считаются только `fit`.
- **Тактика ИИ** (`ai/Tactics.ts`, `TACTICS`; `Tactician` у `CpBrain`, `OtaBrain`, `RebelBrain`,

  дольше, перезаряжается за стеной) или **блок** (`blockToward`; сидит, `suppressive` — очереди по месту,
  где видели врага); не у своих (`claims`, `spacing`), не дальше `leash` от поста/места боя; засвечено —
  пересмотр (`rethink`, `exposedRecheck`); цель помнит `memory` с (`Gunner.memory`). `rescue` — свой
  тяжелораненый в `helpRange`: подбежать, на виду у врага — оттащить (`safeSpot`), поднять (один
  спасатель — `rescuers`). `detain` — ВС в городе стабилизирует лежащего врага и ведёт в КПЗ (`escort`).
  **Колонна** (`columnSpot`/`followColumn`/`watchSector`): след ведущего — крошки через `stack.crumb`, k-й
  на `k × gap` по следу, стоя смотрит в свой сектор. Ведомые PCU — колонной за ведущим (`FOLLOW`,
  `columnIndex`); на капте звено (`RebelBrain.pointman`: глава-NPC или младший по номеру) — ведущий
  у входа в шорт/лонг ждёт, пока звено выстроится (`teamStacked`, `stackWait`, не дольше `stackMax`),

  повстанцев — только на пустоши и в КПП (`FRONT_ZONES`).
- **Реплики** (`systems/Barks.ts`, `config/barks.ts`): контакт, перезарядка, ранен, убил, потеря

### Рация и разговоры (`systems/Radio.ts`, `systems/Talk.ts`, `systems/phrases.ts`, `config/radio.ts`, `config/talk.ts`, `config/places.ts`, `world/places.ts`)
- **Происшествие** (`Radio.report(kind, x, y, {what, reporter, suspect, victim})`, `IncidentKind`, `RADIO.kinds`: код,
  сколько юнитов, бегом ли, важность, реплики): все тревоги идут через `WarSystem.raiseAlarm(…, info: AlarmInfo)` (вид,
  кто доложил, подозреваемый, пострадавший; `radio: false` — не в эфир; рации нет — прежняя строка журнала); сам
  `Radio` замечает юнит в бою в городе (`contact`), упавшего/погибшего юнита («потеря биосигнала», `unitDown`), погоню и
  задержание (хуки закона `LawSystem.onFlee/onLost/onArrest`), драку (`CpBrain.lookAround` → `brawl`), место
  преступления (`CrimeScenes` → `scene`: Надзор — следователю, медику, офицеру). Только город на сети (не КПП, пустошь,
  канализация), при красном коде вызовов нет. Рядом с открытым (`incident.merge`) — то же происшествие: важнее —
  повышение и ещё юниты, иначе «обновление» (не чаще `updateEvery`); нападение, бой, погибший юнит — **подмога**
  (`escalate`: ещё юниты бегом, не больше `times` раз). Открытых не больше `maxOpen` (мелкое вытесняется).
- **Вызов** (`dispatch`): ближайшие свободные (`CpBrain.canRespond(prio)`: патрульный или ведущий группы в обходе, не
  пост, не служба, не бой; едет на вызов не ниже важностью — занят) получают `CpBrain.call` (`RadioCall`: точка, до
  какого времени, бегом); `shouldHunt` → `hunt` к месту (`callPoint`: известный нападавший рядом с местом — к нему),
  ведомые группы — с ведущим. Доложивший (кроме погони) идёт молча. Игрок-ВС ближе `RADIO.player` — Надзор зовёт и его,
  событие `radio:call` ставит метку на карте. `watch`: прибыл (`arrive`) — «на месте»; вызванный вступил в бой —
  «контакт», подмога; все выбыли — Надзор шлёт ещё (раз); на месте тихо `calm` с — «чисто» / «задержан» /
  «нейтрализован» (по подозреваемому) и отбой; не закрыли за `maxTime` — отбой по таймеру. Беглец — точка вызова за ним.
- **Эфир** (`push` → `flush` → `air`): одна частота, строго по очереди (доклад → вызов → подтверждения), реплика —
  когда эфир свободен (`slot` × длительность + `gap`); залежавшееся дольше `stale` выпадает, очередь длиннее
  `maxQueue` — выпадает самое неважное. Подстановки — в момент выхода в эфир (`VarsSrc`: направление беглеца `{dir}`,
  где перехватить `{ahead}`, приметы `{suspect}` — `describe`: кто на вид, чем вооружён, в розыске; «буду через…» —
  `eta`). Юнит говорит облачком `say(…, 'radio')`, Надзор — `'dispatch'` над адресатами (до `listeners.max`), над
  игроком-ВС (важное) и над ближайшим к игроку не из ВС юнитом (слышно его рацию). Журнал: вызовы — всем, остальное —
  игроку-ВС или если сказано рядом (`hear`). `feed` — последние передачи (звук рации, тесты).
- **Плановое**: живой пост сам выходит на связь (`checkIn`, не чаще `routine.checkIn`, эфир пуст) — доклад по делу
  (`status`: пост, людно, ночь, патруль, группа N, прочёсывание, проверка, конвой, склад, фронт…) и «принято» Надзора
  с поправкой (ночь, код жёлтый, недавний вызов рядом — `statusAck`); Надзор опрашивает случайный юнит (`rollCall`) и
  даёт сводки (`info`: в розыске N, ночь, раздача, бой на КПП, вакансии, вызовов за смену). Фронт: КПП ожил, капт,
  точка потеряна, прорыв, отбили, Легион выдвигается (`front`) — гарнизон докладывает, Надзор отвечает; коды тревоги и
  штурм Управы — `code`.
- **Места в речи** (`world/places.ts` → `whereOf(zone)`, `config/places.ts`): имя зоны в предложном падеже («на
  Заводской улице», «в Старом квартале», «на КПП «Запад», в шорте», «у склада Протектората»): точные имена, правила по
  форме (прилагательные «-ая/-ый/-ий»), по виду зоны, иначе «в районе «…»».
- **Слухи** (`Talk.event(kind, x, y, {who, gang, front, big, radius, cp, kinOf, rebels})`, `News`, `TALK.newsTopics`):
  из эфира (`Talk.incident`), смерти горожанина (родня знает сразу) и повстанца (весь лагерь), задержания, прорыва и
  потери точки (весь город), кодов, выборов, академии (набор, присяга). Узнают свидетели в `witness` px (выстрелы — в
  `hear`), вся сеть ВС (`cp`), родня (`kinOf`), все (`big`); у человека — не больше `perPerson`, живут `ttl` с.
- **Беседа** (`Talk.dialogue(a, b, setting)` → 2–4 реплики; `converse` — ведёт сама система, `update`: по очереди с
  паузой по длине фразы, разошлись дальше `maxDist` (у постов — `far`) — оборвалась; `busy`, `stop`, `mayLeave` — тему
  договаривают, не дольше `linger`): тема — слух, который знает A (собеседник узнаёт — `told`; уже знал — «слышал»;
  мелкие и частые — `newsWeight`), тема места (`TALK.settings`: улица, скамейка, семья, бочка, столовая, карты,
  перекур, банда, пост, лагерь, курсанты) по обстановке (`topicWeight`: голод, раздача, код, ночь, утро, бой у стены,
  стража рядом, работа, безработица, деньги, спор лоялиста с недовольным, район банды, родня — что с ней на самом деле,
  у ВС — последний вызов по рации и чем кончился `cpRadio`, потери, вакансии), иначе пара из старых списков. Ответ — по
  отношению собеседника (`attitude`: loyal, neutral, grumble, tough — банды и воры, cp, rebel); `variants` — «вопрос —
  свои ответы», `backTo` — реакция на ответ собеседника. Повтор темы с тем же — × `repeatMul`.
- **Фразы без повторов** (`phrases.ts`: `phrase`, `freshTemplate`, `remember`): у каждого свои недавние
  (`memory.own`) и общие недавние (`memory.global`); всё звучало — давнее всех. Род в шаблонах: `{м|ж}` — по
  говорящему, `[м|ж]` — по собеседнику (`gendered`; силовики — мужской). Через `phrase` идут реплики закона

  (`Talk.remark`): слух, обстановка или реплика занятия (бочка, скамейка, карты, перекур, доска — с именем
  разыскиваемого, столовая, обращение Коменданта по отношению); на улице — `streetBark` через `remark` (ВС — свои
  реплики и о недавнем вызове).
- **Где беседуют**: `CitizenBrain` chat (родня — `family`, одна банда — `gang`), скамейка, бочка (сосед по кругу),
  столовая (сосед по столу); `CpBrain.postLife` — напарники на постах (до двух тем); лагерь (`RebelBrain` camp —

  рации важнее в раскладке (`radioScore`) и видны и при отдалённой камере. Звук — `GunfireAudio.radio` (`AUDIO.radio`):

  беседы выключены (`enabled`).
- Тесты — `tests/radio.test.ts` (места в речи, вызов → выезд → отбой, слияние и подмога, биосигнал, погоня, драка,

### Академия ВС, штатное расписание, пропуска и живые посты (`systems/Academy.ts`, `systems/Staffing.ts`, `systems/Access.ts`, `config/academy.ts`, `config/staffing.ts`, `config/access.ts`)
- **Здание** (`ACADEMY_TEMPLATE` 34×33, `GENERATOR.academy`; символы шаблона — кириллица, латиница и цифры
  уже заняты): ставится последним на своём генераторе (`rng.fork(0xacad)`, места других зданий не
  сдвигаются) у улицы от проспекта, не ближе `apart` к складу и тюрьме, от Управы — около `nexusIdeal`;

  под ней (`MapRenderer`), свет — `LIGHTING.pois`, метка на картах — у стойки вахты.
- **Курсанты** (`CP_UNIT.cdt`, фракция ВС, лицо открыто, пилотка; `CadetBrain`): живут в академии по
  распорядку (`ACADEMY.schedule` по кругу: построение с перекличкой, строевая колонной за направляющим, стрельбы,
  класс, физподготовка — бегом по кругу плаца, обед, личное время; ночью при включённом распорядке — сон у
  своей койки). `AcademySystem.task(c)` — что делать сейчас; присутствие на месте занятия (`attend`) → баллы
  по предметам (`ACADEMY.gain`, `CadetRecord`: строевая, физо, теория, стрельбы). **Тир**: смены по 3 на
  огневом рубеже (`rangeTick`), по `range.shots` выстрелов настоящими пулями из учебного USP; попадание —
  пуля прошла у мишени ближе `hitRadius` (`scoreBullets`, так же считается и игрок); новичок «дёргает»
  (ошибка `tremor` + `error` × (1 − талант), со стрельбами `error` меньше; в среднем ~60% попаданий). **Инструкторы** PCU.INS (2, служба `instructor`:
  место на занятии — `dutyFor`, команды и лекции — `talk`). Набрал баллы (`exam.need`) — **экзамен** в конце
  того же занятия: точность не ниже `exam.accuracy` — сдал, иначе урезаются стрельбы и пересдача; сдавший на
  ближайшем построении принимает **присягу** (`graduate`): позывной `ВС-xxxx`, RCT.PCU — на свободную
  должность RCT, нет её — в резерв академии (дневальный, `RoleKind 'reserve'`). Напали — курсант
  отстреливается с места.
- **Набор** (`recruit`, раз в `recruit.every` с): лоялист (от `minLoyalty`, не в розыске, не под стражей) получает
  направление (`EnlistBrain`: сам идёт на вахту, `applyTime` с у стойки → `enroll`: форма, пистолет, койка,
  роль курсанта, дом освобождается). Курсантов держат до `target`; **усиленный набор** (вакансий RCT от
  `urgentVacancies` или штат ниже `urgentStaff`) — до `capacity`, планка лояльности ниже, учёба быстрее
  (`urgentMul`: ускоренный курс — один круг распорядка, без личного времени); резерв выпускников полон — набор стоит. **Приток жителей** (`RosterSystem.inflow`,
  `ROSTER.inflow`): граждан меньше, чем при заселении (`baseline`), — раз в `every` с в квартале появляется
  новый житель со своим домом (`newcomer`). Игрок-гражданин — E у стойки вахты: заявление (лояльность от
  `minLoyalty`), курсант — подсказка в HUD (занятие, баллы, точность — `hint`), сдал — присяга и служба RCT.
- **Штатное расписание** (`Staffing`, `STAFFING`): у каждого ВС — должность (`StaffSlot`: роль с постом,
  группой, КПП…; `adopt` при появлении). **ВС не возрождаются**: погиб — должность свободна; через `wait` с её
  занимает лучший из младших (`from` — из каких юнитов, по порядку) по баллам `score` = заслуги (`merit`) +
  выслуга (минуты службы × `perMinute`); нужно `minScore`, никто не дотянул за `actingAfter` с — назначают
  лучшего «врио». Переводят только свободного от дела (`freeStates`), за раз — одно назначение (`every`); его
  прежняя должность освобождается — цепочка вниз до RCT, которых пополняют выпускники (`reserve`).
  `applyPost`: звание, здоровье в той же доле, недостающее снаряжение набора, роль и мозг (`brainFor`).
  Журнал — «Приказ по силовому блоку: …». **Заслуги** (`STAFFING.merit`): проверка, штраф, задержание
  (`LawSystem.merit`), убитый враг, найденный убийца (следователь), отстоял построение; убитый мирный —
  минус. Начальный состав — с «заслугами прошлых лет» (`startMerit`). Игрок-ВС — тоже кандидат, но только по

### Война на границе (`systems/WarSystem.ts`, `ai/brains/RebelBrain.ts`, `config/war.ts`)
- Фронт = пограничный КПП из **двух отдельных дворов-точек**, как «война на D» на UnionRP: «Запад» —
  D3 → D4, «Восток» — D5 → D6 (`WAR.pointNames`), между ними шорт и лонг (`Front.short/long`,
  `shortZone/longZone`). `buildFronts` находит части по зонам: двор с воротами к пустоши — внешний,
  с воротами к городу — внутренний, из двух проходов ближе к оси ворот — шорт. `DPoint`: зона, посты,
  пол (от входа), центр. Пустошь 14 тайлов с завалами; гарнизон — спецназ SU.03 на всех постах
  (2 во внешнем дворе, 3 во внутреннем) + медик SU.02 в бункере. Проходная (`Front.gatehouse`,
  узнаётся по концу имени зоны `ZONE_NAMES.gatehouse`) — не часть точек D: там 2 RCT.PCU (роль `gate`,
  `Front.gatePosts`, проверяют входящих), `Front.apron` — за её дверью, в городе. `sectionAt` (0 — внешний двор,
  1 — шорт/лонг, 2 — внутренний), `pointAt`, `pointOfPost`. Разметка на полу — `drawPoints`.
- **Наступления** (`WAR.offensive`, `RebelCommand.updateOffensive`, `Offensive`): армия не лезет на КПП
  без конца — между наступлениями лечится и пополняется в лагере, к КПП ходит только разведка
  (`COMMAND.scouts` солдат, режим `raid`). Первое — не раньше `firstAfter` с, следующие — через
  `interval` с; начинается ночью (`hours`, по `ctx.routine.hour()`; не дождались — через `maxWait` с
  и днём), если в лагере готовых (`readyHealth`) ≥ `minReady`; журнал «Надзор: в пустоши движение…».
  Готовые идут на цель главы (`committed`), `COMMAND.diversion` — на второй КПП. Конец: выбыла доля
  `breakLoss` вышедших (убит, лежит, задержан, ушёл раненым в лагерь — `out`), штурм выдохся за `maxTime`
  с без капта, прорыв в город отбит (`pushed`, потом `cityPush` снят) — `endOffensive`: все, кроме
  державших посты и прорвавшихся, отходят в лагерь (`withdraw`), `stats.offensives/broken`.
  `launchOffensive(front)` — сразу (тесты; игрок-глава у КПП начинает его сам).
- Ритм фронта «сбор → капт»: армия приходит из лагеря тропой (этап 7) и собирается на
  пустоши вне видимости постов (`RebelBrain` режим `gather`, `pickGather`, `WAR.gatherDist`) — не
  лезет под огонь по одному. Собралось ≥ `capture.minAttackers` — все разом идут на капт очередной
  точки. Новых отрядов у КПП не появляется.
- `war.active(f)` — стреляли у КПП за `activeWindow` с: указатели на КПП у края экрана
  (`EffectsRenderer.drawFrontMarkers`, с именами точек и их состоянием), перестрелку слышно из города.
- **Капт точки** (`WAR.capture`, `startCapture`/`endCapture`/`updateCapture`): точки берутся по
  очереди (`Front.held` — сколько, с внешней, у повстанцев). Капт на `duration` с; **во время капта
  Протекторат шлёт подкрепления** (`capture.reinforce`: погибшие часовые с ГЭС бегут на посты, OTA
  выдвигаются; «Резерв выдвигается — держать точку!»). Повстанцы в режиме `capture`
  идут перебежками по двору штурмуемой точки (`coverAt` по `DPoint.floor`): укрытие на доле пути
  `advance`, `coverWait`, `advanceStep`, под огнём — `shootStop`/`dash`. **Не одной толпой**:
  `RebelCommand.formTeams` делит штурмующих на звенья по `capture.teamSize` (глава с HYDRA — звено 0;
  подошедшие позже — в самое малое звено). У звена своя полоса двора из `lanes` (поперёк оси вход →
  центр, `lateralOf`), свой проход во внутренний двор (чётные — шорт, нечётные — лонг; без звена —
  `longChance`), точки маршрута у каждого свои; перекаты — каждые `bound` с бегут чётные или
  нечётные звенья (`boundTurn`), в проход звено входит в свой такт. Укрытие, точка сбора и точки
  маршрута — не ближе `spacing` к цели другого штурмующего (`takenSpots`, `crowdAt`). Клич NPC-главы
  двигает звенья до его рубежа своими полосами (без очереди перекатов), за игроком-главой бегут
  врассыпную (`COMMAND.rally.spread`). Внешний двор взят — сбор уже в
  нём (вне видимости постов внутреннего), а на штурм внутреннего идут и державшие внешний
  (на постах остаётся `keepOnHeld`). Капт начинается, когда у КПП ≥ `minAttackers` бойцов его отряда
  (отходящие в лагерь не в счёт). Итог: защитников на точке не осталось — гарнизон
  (`capture.defenders` — часовые её постов, OTA на них, у внутренней ещё медики) перебит, ВС и OTA
  во дворе нет, а штурмующие во дворе держат его `secure` с подряд (`Capture.secured`; подошли ВС или
  OTA — счёт сначала) — точка взята; или `killsToWin` убийств с перевесом, если повстанцы во дворе
  (`yardCount`); штурмовавшие держат её посты (`hold`), лишние — назад на сбор; все штурмующие погибли —
  отбит; по таймеру (`duration` 90 с) — захват при ≥ `minKills`, перевесе и повстанцев во дворе не меньше,
  чем Протектората (`Capture.inside`). Захват точки — точка тревоги у
  проходной (код не меняется). Обе точки — **КПП прорван** (`breach`, `owner = 'rebels'`); тогда
  сильнейшие (`capture.gateHold`: до `count`, от `minHp` HP — `holdGate`) встают у углов проходной и
  перед ней (`gateSpots`: анкеры в `radius` px от двери на проспект с ≥ `minWalls` сплошных тайлов
  вокруг) лицом к проспекту (`orderHold(post, face)`) и отстреливают выходящих из города. В лонге
  блоков нет; завалы в полосе пустоши шаблона (`CHECKPOINT_OUTLANDS_W`) — зона пустоши.
- **ГЭС**: погибшие ВС и OTA возвращаются у ворот Управы (постоянный состав) — не сразу
  (`ROSTER.respawn`: ВС 60 с, OTA 90 с, иначе гарнизон восполняется быстрее, чем повстанцы
  закрепляются) — и бегут на свои посты (`GUARD`: дальше `LAW.cpRunToPost` — бегом), и во время капта
  (`capture.reinforce`; выключен — ждут его конца). Армия пополняется медленнее — из пустоши
  (`army` 220 с, глава 540, HYDRA 400).
  Захваченную точку отбивают контрудары резерва OTA (`counterattack`: через `counterDelay` с, потом
  раз в `retakeEvery` — `retakeOta` свободных OTA на посты ближней к городу захваченной точки,
  `OtaBrain.assignPost`). Точка отбита, когда в её дворе (и ближе к городу) нет повстанцев, а ВС уже
  там, `retakeCalm` с (не раньше `holdTime`). **OTA — туда, где сопротивление** (`WAR.ota`,
  `deployOta`, `rebelsAtFronts`): раз в `every` с резерв и OTA с тихих КПП уходят на КПП, где
  повстанцев (во дворах и на пустоши) ≥ `minRebels` и больше всего, — до `perFront` на посты ближайшей
  к пустоши точки Протектората (и во время капта, если `capture.reinforce`). На тихом КПП без захваченных
  точек — в резерв. Повстанцы рвутся в город (`cityPush`) — OTA, кроме заслона, уходят держать ГЭС; при
  красном коде контрударов нет (штурм отбит — снова идут).
- **Заслон у прорыва** (`WAR.blockade`, `updateBlockade`, `blockaders`): КПП прорван — Протекторат
  перекрывает выход из проходной в город. До `cp` ближайших патрульных ВС (не с постов, `CpBrain.rally`
  поверх службы, состояние `guard`) и до `ota` легионеров резерва (`assignPost(-1, …)`; остальные отбивают
  КПП контрударами) встают на места `blockadeSpots`: якоря города в `radius` px от выхода, откуда он
  виден, за углом (≥ `minWalls` сплошных тайлов рядом), не ближе `spacing` друг к другу, лицом к
  проходной. КПП отбит — заслон расходится (`releaseBlockade`); мобилизация красного кода — поверх.
- **Граждане к прорванному КПП** (`WAR.defect`, `updateDefection`, `ai/brains/DefectorBrain.ts`): раз в
  `every` с не-лоялист бежит к КПП (чуть медленнее «бега» — чтобы ВС не остановил; от ВС — бегом),
  в коридоре становится повстанцем (`defect`: MP7, розыск, держит пост). Не больше `max` бегущих,
  `perBreach` за прорыв, граждан не меньше `minShare` от начального числа; КПП отбит — бегущие
  возвращаются к жизни. Игрок-гражданин/ТС в коридоре прорванного КПП — E (событие `defected`).
- **Прорыв в город** (`cityPush`, `WAR.cityPushOn`): `'breach'` — как только прорван любой КПП, через
  него (глава не уводит армию на второй КПП: `breach` оставляет цель); `'all'` — прежнее правило, только
  при всех точках D. На прорванном КПП остаются держать посты `holdKeep` и стрелки у выхода
  (`gateGuards` из `holdGate`; при красном коде и они на штурм), остальные — `assault` через внутренние
  ворота; отряд непрорванного КПП в город не идёт. Боец в `assault`
  (или при `cityPush`) в городе → прорвавшийся (`infiltrators`; из отряда фронта исключён навсегда —
  `RebelCommand` не возвращает режимы `storm`/`infiltrate` в `f.squad`, иначе приказ повторялся каждый
  тик и боец стоял) → при `cityPush` — КРАСНЫЙ КОД (только штурм Управы): комендантский час, раздача
  закрыта, **никто не возрождается** (`RosterSystem`, игрок — `Game`, санитар; выборы Коменданта —
  после отбоя, `ElectionSystem.owed`),
  патрули PCU прочёсывают город по данным «Надзора» (`lastKnown`); OTA по городу не ходит — держит
  ГЭС (OTA с постов КПП — домой). **Мобилизация** (`WAR.mobilize`, `updateMobilize`): все ВС с
  постов (часовые и медики КПП, RCT проходных и города, кладовщик, экипаж конвоя, охрана склада, кроме
  `depotKeep` часовых) получают место обороны Управы (`CpBrain.rally` — поверх поста, состояние
  `guard`; места — `nexusSpots`: якоря зоны Управы через `spacing` px, ближе к воротам — раньше,
  лицом к воротам); командование, охрана и инспекторы — при своих; отбой — все назад. Повстанцы на
  КПП при красном коде оставляют `rebelKeep` (0) вместо `holdKeep` — остальные на штурм. Граждане
  уходят в подъезды/дворы (`shelters`). Отбой — прорвавшихся нет `calmToGreen` с (не раньше
  `redMinTime`): КПП ещё у повстанцев — код жёлтый (`declareYellow`: штурм отбит, возрождение и
  контрудары снова идут), иначе зелёный; через `redMaxTime` прорвавшиеся «уходят в подполье».
  `forceAssault` — для тестов.
- **Штурм Управы** (`WAR.nexus`, `updateNexus`, режим `storm`) — цель выхода в город. При `cityPush`
  бойцы в `assault` сначала собираются во внутреннем дворе прорванного КПП (`staged`); собралось
  `waveSize` (или ждали `stageMax` с и собралась треть идущих, или `stageHardMax` с) — **волна** (`nexus.wave`): все разом через проходную к Управе,
  в городе — `storm` (перебежками к зоне Управы, внутри меняют позицию не кучей, раненые не
  отходят; дальше `alleysUntil` px от ворот — переулками: проспект и площадь в A* дороже в
  `alleyCost` раз — `Mover.avoidCost`, чтобы не идти под огнём по открытому проспекту); внутри доля
  `huntAdmin` идёт прямо на Коменданта. В зоне Управы ≥ `minAttackers` штурмующих и не меньше защитников (боеспособных: раненые ниже
  `COMBAT.woundedFraction`, отошедшие перевязываться, не в счёт) — захват
  копится `captureTime` с (иначе убывает); **Управа захвачен и Комендант мёртв** (`adminAlive`) —
  **победа восстания** (`rebelVictory`: событие `victory`, повстанцы — `withdraw`, код зелёный,
  игрокам-повстанцам `reward`; через `restartDelay` с — событие `restart`: `Game` на следующем тике
  генерирует новый город, роль игрока прежняя); повстанцев в Управе не осталось — отбит.
  Табло — `CaptureBar`.
- **Терминал кодов тревоги** (POI `code_terminal`, символ `T` шаблона Управы — у стены кабинета
  Коменданта; `ui/CodePanel`, `WarSystem.setCode`): E рядом (`WAR.terminal.reach`) — панель:
  1 жёлтый, 2 красный, 3 отбой. Доступ — Комендант и ВС с ранга `terminal.minCpRank` (OFC).
  Код с терминала (`manualCode`) держится, пока его не снимут (автоматический отбой не действует),
  но автоматическая эскалация до красного работает; погиб или разжалован включивший — снова по
  обстановке. Экран терминала — цвета кода, мигает, если код с терминала.
- Нападение «в городе» (тревога, эскалация до красного) — только если и цель, и стрелок в городе:
  огонь с постов КПП по проспекту — это фронт. `war.reinforcements = false` — тесты без контрударов.

### Канализация и сопротивление (`systems/UndergroundSystem.ts`, `systems/InsurgencySystem.ts`, `config/underground.ts`)
- Люк: E в радиусе `UNDERGROUND.useRadius` → `climbTime` с на месте → у парного люка на другом
  уровне (`climb` ставит на свободный якорь, без интерполяции). NPC ходят через люки `HatchTravel`:
  `route` выбирает пару люков по сумме «сюда → люк» + «люк → цель».
- Люков два (в запретной зоне у края), пользуются ими только партизаны и спецагент (`UndergroundSystem.canUse`).
  Схрон: `ROSTER.partisans` (4) партизана (`UndergroundBrain`, автомат в кармане) и `ROSTER.agents` (3) спецагента (MP7 и USP)
  (`AgentBrain`, роль `agent`, `InsurgencySystem.agents`; `agent` — первый) — постоянный состав; тайник (E: патроны к своим стволам,
  `refillAmmo`), игрок-партизан и игрок-спецагент появляются здесь.
- **Личина** (`Character.cover` — фракция, юнит, профессия, имя; `entities/cover.ts`: `apparentFaction`,
  `coverAuthority`, `displayName`): партизан всегда под личиной горожанина или ТС
  (`InsurgencySystem.giveCover`, `PARTISANS.cwuCoverShare`), подпись и внешность — по личине. Под
  личиной ствол в кармане, приказу ВС подчиняется (`ai/comply.ts`), от ВС не бежит; проверка CID
  раскрывает с шансом `PARTISANS.checkReveal` (в розыске — всегда). Ствол в руках и ранение личину не
  снимают (ранивший под личиной не получает `hostile`) — только убийство (`CombatSystem.kill` →
  `reveal`, за убитого из Протектората — `hostile` и розыск); ствол в руках — всё же нарушение `weapon`.
  Подпольщик под личиной без `holdFire` сам берёт цели из Протектората (`Gunner.acquire`, `covert`).
  Подпольщики и спецагент начинают с «чистыми» документами (не в розыске). Вернулся в схрон раскрытым или
  в розыске — через `PARTISANS.newPapers` с новые документы и личина; в тайнике — гранаты до
  `cacheGrenades`. Возрождение долгое:
  `ROSTER.respawn.partisan` 300 с, `agent` 600 с.
- Вылазки раз в `outingEvery` (в убежище остаётся ≥ `minAtBase`): обход тоннелей до люка, поход
  на рынок, разведка в город через люк (1–2 бойца, режим `outing`). Разведчик скрытен: огонь не
  открывает (`Gunner.holdFire`), заметил ВС — уходит вниз; отвечает, только если ранили.
- Операции раз в `opEvery` (у каждого свободного подпольщика — своя, `InsurgencySystem.ops`; на дело идёт
  только под личиной и не в розыске; доли — `PARTISANS.ops`): **взлом КПЗ** (`startJailbreak`: быстрым
  шагом `briskWalk` через люк в Управу к занятой камере КПЗ — `occupiedCell` (тюрьму — только штурмом): свои первыми, иначе
  где больше сидящих; товарищ сидит — взлом с шансом `rescueChance`; пока шёл, выпустили — к другой,
  КПЗ пуста — ждёт у камер `jailWait` с; у двери `jailReach` px — `agent.breakTime` с → `jailbreak`, у
  двери оставляет растяжку), **минирование** (`startMine`, `mineSpot`: свежее тело сотрудника Протектората
  без оцепления, у ворот Управы, у выхода проходной КПП, на пути патрульного — из двух случайных
  ближнее к люку; не в зонах `PARTISANS.mineAvoid` — склад, тюрьма, запретная зона: туда под личиной не пустят), **ствол бандиту** (с шансом `PARTISANS.armChance`: партизан через люк к
  бандиту — `armable`, вплотную `armBandit`: MP7 и патроны, мозг `HiredGunBrain` — ищет патрульного ВС
  в городе, в `hired.engage` px достаёт ствол, `hostile` и розыск, стреляет; время `hired.time` или
  ранен — прячет ствол, прежний мозг) или **саботаж** (боец через люк к узлу Протектората, `sabotageTime` с).
  Раненые и закончившие — к ближайшему люку и вниз. Связь сопротивления видна только игроку-повстанцу.
  Игрок-партизан — E перед бандитом.
- **Группы (ячейки)** (`UndergroundGroup`, `InsurgencySystem.groups/groupOf/formGroup`, `PARTISANS.group`):
  на дело вдвоём-втроём, у каждого роль (`GroupRole`: `lead` — делает дело, `cover` — прикрытие рядом,
  `lookout` — дозор), общие сигналы `attack` и `alarm`. **Саботаж** — второй дозорный (`UndergroundBrain`
  режим `cover`, `lookoutRing`): видит ВС ближе `watch` px — «шухер» (`groupAlarm`), все уходят.
  **Взлом** — второй прикрывает у камер (`coverRing`). **Засада на конвой ВС** (`ambush`, доля
  `ops.ambush`, `startAmbush`, режим `ambush`): все свободные (до `ambush.size[1]`) берут в схроне
  автомат (`weapon`), идут к месту на пути колонны (`ambushSpot`: доля `along` от склада к пункту, не у
  Управы и КПП), остальные держатся рядом с ведущим; собрались (двое в `huddle` px) и колонна на марше
  ближе `intercept` — наперерез, ближе `engage` и на виду — сигнал (`groupAttack`: личина снята,
  `hostile`, розыск, тревога), огонь первым делом по носильщикам; брошенные ящики — забрать
  (`lootCrate`: патроны или гранаты), бой не дольше `fight` с, потом к люку. `allies` — задел под банды и
  мафию (союзники группы со стороны).
- **Допрос** (`PARTISANS.interrogation`, `InsurgencySystem.interrogate`): начальник тюрьмы (SU.INSP,
  служба `warden`; в `nextDuty` — дверь камеры, где сидит нерасколовшийся подпольщик, `Prison.questionCell`)
  раз в `every` с — вопрос, стон пленного и урон (не ниже `minHealth`); через `time` с пленный раскалывается
  (`brokeUnder`) и выдаёт личину другого подпольщика или спецагента из тех, кто сейчас в схроне (не на
  деле): личина снята, розыск. **Рейд** (`PARTISANS.raid`, `startRaid`): двое (`raid.caged`) партизан в тюрьме одновременно — часовые
  КПП (`CpBrain.raidPost`, `postOf`) и свободные OTA (`assignPost(-1, …)`) идут к лагерю
  сопротивления на `duration` с; один рейд на каждый такой раз.
- **Спецагент** (`AgentBrain`, `PARTISANS.agent`): из схрона раз в `rest` с — миссия (`missions`):
  свой в камере — почти всегда взлом (`rescueChance`), после взлома — растяжка у двери;
  **покушение** на Коменданта и высоких чинов (`pickTarget`: Комендант, CMD.EPU, инспекторы,
  офицеры), **взлом** камер КПЗ и клеток (`jailbreak` → `breakCell`, тревога), **бунт**
  (`startRiot`: до `riot.count` горожан — не лоялистов — в `radius` px переходят в состояние `riot`
  `CitizenBrain`: мечутся вокруг точки и кричат лозунги `riot.time` с; нарушение `riot`; тревога).
  Перед покушением и взломом переодевается: форма свежего (`corpseFresh`) тела ВС (`dressAs`,
  `Corpse.stripped`; в OTA — никогда: ни тело OTA, ни шкаф); в форме ВС его не проверяют. Свежего тела
  нет — идёт под гражданской личиной (`goUndressed`; «по наряду» без формы — бунт). Миссия — не дольше
  `agent.missionMax` с, точка миссии запомнена (`missionAt`), встал рядом — засчитано, далеко — путь
  заново. Раскрывает только убийство (`revealAgent` — вручную: `hostile`, розыск); в схроне — новые
  документы. **Парой**: на покушение и взлом свободный второй спецагент идёт прикрытием (`joinBackup`,
  `backup`/`partner`): переодевается, держится в `agent.backupGap` px за ведущим, ведущий открыл огонь —
  тоже огонь; ведущий ушёл — и он к люку. Игрок-спецагент: E у тела ВС, у занятой
  камеры КПЗ; G — бунт (откат `riot.cooldown`). На штурм тюрьмы спецагенты идут вместе с партизанами
  (`joinPrison`, миссия `prison`).
  **Выпустили из КПЗ** (`LawSystem.onReleased` → `InsurgencySystem.released`): подпольщику возвращают
  документы (гражданская личина, не в розыске) и он бросает дело — в схрон (`retreat`); иначе ВС у
  ворот Управы тут же узнавал бы его снова. Под личиной не бегает от ВС, даже «без CID» (поддельная),
  ствол в кармане, пока огонь запрещён (`holdFire` — и на саботаже, у барыги, по дороге домой), домой —
  быстрым шагом (`briskWalk`, бег — нарушение). **Взлом КПЗ** — только если там кто-то сидит,
  вызволять своих — с шансом `rescueChance`, после любого взлома (и агентов) — пауза `jailCooldown` с.
- Узлы Протектората (`EconomySystem.nodes`: терминалы у стен на проспектах и площади) ломаются только
  от саботажа; чинит ТС (дороже щитка). Игрок-повстанец саботирует сам (E), награда `sabotageReward`.
- **Тревога** (`WarSystem.raiseAlarm(x, y, what, yellow)`): саботаж, ранение сотрудника Протектората в
  городе (`CombatSystem.onDamage`), побег, бунт, донос, сканер, захват точки КПП — точка тревоги
  (`alarmActive`: патрули рядом прочёсывают и при зелёном коде), код не меняется. **Код жёлтый — только
  когда ВС, OTA или Комендант увидел тело убитого ВС в городе** (`scanCorpses` раз в
  `ALARM.corpseScan` с, один раз на тело). Тогда же — **место преступления** (`systems/CrimeScenes.ts`,
  `war.scenes`, `CRIME.scene`); его открывают и для **убитого гражданского** (горожанин, ТС, поднадзорный —
  `SceneKind` `civil`, только точка тревоги, код не меняется). **Оцепление по клеткам** (`cordon`): пол в
  `radius`/`civilRadius` px от тела, связный с ним (стены и двери не пересекает) — `cells`; клетки края,
  за которыми ещё пол, — проходы; группы клеток края — линии (`CordonLine`, `line`): по углу вокруг тела
  (разрыв — в самом большом промежутке), концы — до грани стены. Линия до `tapeMax` px — **жёлтая
  лента в чёрную полоску, провисает между двумя дорожными конусами** (конусы в изометрии у стен —
  `drawCone`, отступ `coneInset`; провисание `sag`, тень на земле; край с изломом дальше `bend` px от хорды
  — делится на ленты по проходам); длиннее (улица, проспект) — ряд **козел** (бело-красная доска в косую
  полоску на двух опорах — `drawBarriers`). **Мирные проходят всегда** — под лентой и между козлами
  (`blockCivilians` выключен; включить — не пустят к убитому ВС с оружием: `block`, `updateBlock`, выталкивает
  к `outside`). Тело не обыскать (`sealed`). **Близкие
  происшествия — одна зона** (`open`: тело ближе `merge` px к телу открытой зоны — `addBody`; новое тело
  связало две зоны — `absorb`): `bodies`, граница — вокруг тел не дальше `span` px от первого (`core`,
  `reshape` → `cordon`; бой растянулся по улице — граница не расползается), следователь и
  медик обходят тела по очереди (`nextBody` 'scan'/'cover'), убит ВС — зона «ВС» с офицером. **Без лишних
  лент**: оцеплений не больше `maxOpen` (лишнее тело — в зону не дальше `gather` px, иначе без ленты); пока
  рядом стреляли (ближе `calmRadius` за `calm` с — `CrimeScenes.quiet`, свои «горячие точки» из
  `combat.shots`), тело ждёт в `WarSystem.sceneQueue` — оцепляют после боя; гражданского — только убитого
  (`killer`), в помещениях Протектората (`skipZones`: КПЗ, тюрьма, склад) — нет. Метка на мини-карте и
  большой карте — жёлтый квадрат в чёрной рамке с мигающим кольцом (`MINIMAP.colors.scene`). Из `seek`
  px идут следователь SU.01 (`CpBrain` состояние `scene`, роль `investigate`: осмотр `scanTime` с →
  `crime.investigate`, убийца в розыск) и **медик** — SU.02 (роль `examine`), пока на местах их меньше
  `suMedicMax`, иначе **медик ТС** (`cwu_medic`, временный мозг `ExamineBrain`, потом — к своей работе;
  лента его не выталкивает): у тела на корточках с **планшетом** (`Character.notepadUntil`,

### Телефон: сенсорное управление (`ui/TouchControls.ts`, `ui/touch.css`, `core/touch.ts`, `config/touch.ts`)

## Соглашения
- Все числа, цвета, скорости, зарплаты и т.п. — в `src/config/*`. Новый параметр → в конфиг.
- `src/` не использует API Node; `tests/` может (свой `tests/tsconfig.json`).
- Случайность в генерации и мире — только через `Rng` (seed), не `Math.random` (кроме выбора нового seed).
- Логика не трогает DOM; UI подписывается на `EventBus`. Новые события — в `GameEvents`.
- Персонаж игрока и NPC — один класс `Character`; различие только в источнике управления.
- Отрисовка тайлов — в экранных пикселях с округлением (без щелей); подписи — в экранных пикселях.
- Перед коммитом: `npm run typecheck && npm test`.
- Тесты детерминированы: `makeSim` сбрасывает общий набор номеров CID (`resetCids`), иначе случайность
  теста зависела бы от предыдущих тестов файла.

  Затем: у барыги появился товар — подполье без краденого идёт на склад за стволами со стоек, с явок

- [x] **Распорядок дня и игра за гражданского**: горожане живут по часам — ночью спят дома, утром очередь

- [x] **Аудит живого мира** (цель — мир как в Kenshi): стенд `npm run worldstats` (`tests/worldstats.test.ts`) —

- [x] **Война реалистичнее**: КПП больше не прорывают на 4-й минуте. Армия ходит в **наступления** — ночью,
  раз в 7–12 мин, когда в лагере ≥ 12 готовых; между ними лечится, к КПП ходит разведка; выбыла половина —
  отход. В капте Протекторат шлёт подкрепления, точка взята, только если двор удержан 12 с; армия
  пополняется медленнее (220 с). **Прорван КПП — повстанцы рвутся в город через него**, а Протекторат
  ставит **заслон** у выхода из проходной (патрули ВС и пара легионеров за углами), остальные OTA отбивают
