# CLAUDE.md — Сити-17 (HL2RP 2D)

Браузерная 2D-игра с видом сверху в духе HL2RP-серверов Garry's Mod: тесный город из переулков под
контролем Альянса. Все персонажи — пешки в стиле RimWorld (цвет формы по рангу) с подписью имени/роли. Игрок управляет одним,
остальные — NPC, ведущие себя как игроки RP-сервера.

**Язык:** интерфейс, комментарии и документация — по-русски; идентификаторы в коде — по-английски.

## Команды

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # vitest: генератор, A*, коллизии, JSON, симуляция NPC
npm run typecheck  # tsc для src и tests
npm run build      # typecheck + сборка в dist/
npm run mapstats   # метрики генератора по 30 сидам (DEBUG_GEN=1 — причины отбраковки попыток)
```

Параметры адреса: `?seed=123` (карта по seed, пишется в адрес автоматически), `?map=city17`
(загрузить `public/maps/city17.json`), `?npcs=40`, `?debug=1`.

## Стек и почему без движка

TypeScript + Vite + HTML5 Canvas 2D, без игровых движков. Всё ключевое здесь нестандартное —
генератор переулков, туман войны лучами, A* по якорям 2×2 с учётом радиуса, уступание дороги;
Phaser не дал бы готового для этого, а добавил бы свой цикл, сцену и физику, с которыми пришлось бы
бороться. Логика не зависит от DOM и целиком тестируется в Node (vitest), включая безголовую
симуляцию NPC (`tests/simHarness.ts`).

### Тик логики (`Game.update`, 60 Гц)
1. `PlayerController`: ввод → `player.wantX/wantY`, взгляд на курсор, прицел (ПКМ), огонь, смена оружия, E/F/1/2/3.
   Задержанному игроку временно ставится `PrisonerBrain` — тогда ввод движения игнорируется.
2. `updateNpcs`: мозги (FSM) → `Mover` выставляет `wantX/wantY` → `dodgeGrenades` (граната рядом —
   бегство поверх решения мозга); затем `PathService.process()`.
3. `DoorSystem`: двери открываются, если рядом кто-то есть; закрываются через `DOORS.closeDelay`.
4. `stepPhysics`: разгон → движение → расталкивание по массам → выталкивание из стен.
5. `LawSystem.update`: неподчинение игрока, заведение в камеру, сроки, освобождение.
5a. `EconomySystem` (раздача, голод, зарплаты, поломки) → `CombatSystem` (перезарядка, регенерация,
   уборка убитых) → `WarSystem` (отряды у КПП, подкрепления, прорыв, тревоги) → `InsurgencySystem`
   (гарнизон убежища, операции) → возрождение игрока.
6. Видимость: многоугольник обзора игрока (`VISION.rays` лучей DDA) и `c.visible` у всех.
7. Камера (в границах уровня игрока; сменил уровень — `snapTo`), зоны, UI (DOM — с частотой `GAME.hudInterval`).

Отрисовка (`Game.render`): карта → терминал найма → эффекты на земле (тела, щитки, очередь) →
персонажи (только видимые; нос-треугольник — взгляд, силуэт оружия по классу) → конусы NPC →
трассеры и взмахи дубинки → туман → конус игрока → подписи и реплики → отладка → виньетка →
красный код/ранение → указатели на КПП → прицел. Интерполяция `prevX → x`.

### Ключевые понятия
- **Тайл** 16 px. Город 300×230 тайлов (4800×3680 px; главный проспект между КПП ~165 тайлов —
  бегом ~15 с) в кольце пустоши за стеной (8 тайлов слева и справа, 26 снизу: тропа и лагерь
  сопротивления) — 316×256; справа за зазором — канализация (масштаб 1:2), вся карта 478×256. Типы — `world/tiles.ts` (`solid`, `opaque`, символ для JSON).
  Добавляя тип, допишите его в `TILE_DEFS`, палитру `MapRenderer` и `DevPanel`.
- **Уровни** (`Level`: city / sewer) — две области одной сетки без прохода между ними; связь только
  люками. `GameMap.underground` (прямоугольник канализации по её зонам), `levelAt`, `levelBounds`;
  `NavGrid.level` по якорям. A* между уровнями сразу отказывает, `randomAnchorAround` берёт цели
  только на своём уровне, камера не выходит за границы уровня, в канализации обзор короче
  (`VISION.sewerRadius`), выстрелы с другого уровня не слышны.
- **Якорь 2×2**: персонаж радиусом 12 px занимает квадрат 2×2 тайла. Якорь (ax, ay) ↔ центр в
  ((ax+1)·16, (ay+1)·16). Связность карты, A* и поиск «карманов» работают по якорям — поэтому
  проход 2 тайла (32 px) пропускает ровно одного, 3 тайла (48 px) — двоих.
- **Зоны** — сетка `zoneGrid` (id зоны на тайл) + список `zones` (kind + имя). `ZoneKind`:
  residential, avenue, plaza, nexus, cells, industrial, restricted, checkpoint (пограничные КПП),
  outlands (пустоши за стеной), shop (магазин ГСР), sewer, rebel_base (убежище), black_market,
  cwu_hq (штаб ГСР).
- **Точки интереса (POI)** — `map.pois` в координатах тайлов: лагерь сопротивления и его тайник, окно раздачи, центр площади, терминал
  найма, ворота и стойка Нексуса, терминал кодов тревоги, камеры КПЗ, ворота запретной зоны, заводские дворы, посты часовых
  КПП, выходы в пустоши, люки (`hatch` в городе / `sewer_hatch` в канализации: якорь 2×2, x,y — его
  левый верхний тайл; пары связаны одинаковым `id`), убежище, тайник, прилавок и место торговца.
- **Двери** — группы соседних тайлов `DOOR`. Состояние (закрыта/заперта) живёт в `GameMap.doorClosed/
  doorLocked`: закрытая перекрывает обзор (`isOpaque`), запертая — ещё и проход (`isSolid`).
  Запирание вызывает `NavGrid.refresh` вокруг двери.
- **Видимость**: `visibility.ts` — луч DDA до первого непрозрачного тайла. Игрок видит в радиусе
  `VISION.radius`; NPC — в `VISION.npcRange` с углом обзора `npcFovDeg` (вплотную — во все стороны).
  Одни и те же функции для игрока и NPC: от ГО можно скрыться за поворотом или за дверью.
- **Фракции и ранги** — `config/factions.ts`. Цвет формы пешки по рангу (`colorsOf`): ГО от голубого
  (RCT) до тёмно-синего (DvL). У сопротивления юнит — по профессии (`REBEL_RANKS`, `rebelUnitOf`,
  `REBEL_UNIT`; `rank` = номер юнита, HP — `roleHp`): армия — жёлтые ники, глава Патрик и HYDRA
  (`elite`) — красные. Рубаха армии синяя, жилет — с солдата.
  `authority` — кто проверяет, а не проверяется (ГО, OTA, администратор).

### Генератор (`world/generator/CityGenerator.ts`)
1. `layout`: магистраль по центру (+ вторая с шансом 50%), линии решётки с отступами от проспекта,
   углы запретной зоны и промзоны, площадь на длинном прямом участке проспекта, Нексус рядом.
1б. **Улицы-артерии** (`generator/streets.ts`, `GENERATOR.streets/dorms/villas`) — по решётке после
   разметки регионов, до лабиринта (`planStreets`): стволы шириной 4 от узлов проспекта (и от дальнего
   края площади) на `branchRow` линий вглубь, на конце — ветви вдоль горизонтальной линии в обе
   стороны (до `branchMax` рёбер), от ветвей — улочки шириной 3 (`lanes`) дальше вглубь; сторона без
   стволов (там Нексус и КПП) получает улицу через `detachedRow` линий. Рёбра артерий сразу вырезаны
   (`LEdge.artery`, ширина не меняется в `finalizeEdges`), изломы Z-образные, как у переулков; асфальт
   (`carveArteries`), у каждой артерии своя зона вида `avenue` («улица Брина»…, `ZONE_NAMES.streets`).
   Вдоль улиц — места под **общежития** (`DORM_TEMPLATE` 21×17: Т-коридор, 7 комнат `r` → POI `home`
   с `kind: 'dorm'`, общая комната `m` → `dorm_common` со столом `x` → `dorm_table`) и **особняки
   лоялистов** (`VILLA_TEMPLATE` 16×14: живая изгородь `h` → `HEDGE`, сад `v` → `GARDEN`, деревья `t`
   → POI `tree`, спальня → `home` `kind: 'villa'`, гостиная → `villa_living`); вход на улицу
   (`faceTemplate`: S/N/E/W), здания — пустоты решётки (лабиринт их обходит), штампуются вместе с
   Нексусом, выходы прокапываются. Зоны: «Общежитие №k», «Особняки лоялистов» — вид residential
   (стены — штукатурка). Символы зон в JSON у многочисленных зон (улицы, общежития, особняки) —
   первый свободный из `ZONE_CHAR_POOL` (`addZone(…, null)`). Проверка карты требует ≥ 2 общежитий
   и ≥ 2 особняков.
   **Штаб ГСР** (`CWU_HQ_TEMPLATE` 25×17, `GENERATOR.cwuHq`) — ставится первым: из `tries` случайных
   мест вдоль улиц берётся ближайшее к узлам главного проспекта (`StreetPlan.hq`). Т-образный коридор,
   как в Нексусе: сверху цех фасовки `p` с тремя конвейерами `y` (POI `ration_line`) и складом коробок
   `u` (`cwu_store`), комната отдыха `l` (`cwu_lounge`), кабинет главы `e` (`cwu_office`) со столом `H`
   (`cwu_head_desk`); по сторонам «ножки» — приёмная `a` (`cwu_lobby`) со стойкой найма `J` (`cwu_hire`)
   и столовая `n` (`cwu_canteen`); POI `cwu_hq` — прямоугольник здания, `cwu_production` — цех. Зона
   `cwu_hq` «Штаб ГСР» (пол — плитка). Помещения по символам — `StampResult.areas`. Проверка карты
   требует штаб, стойку, стол главы, три конвейера и склад.
2. `lattice`: узлы с «дрожанием» (соседи на линии смещены ≥ 3 тайла) → лабиринт «растущее дерево»
   от узлов проспекта + петли (несколько маршрутов). Рёбра вырезаются Z-образно; излом ставится так,
   чтобы прямой участок ≤ 25 тайлов и перемычка не вставала в створ соседних переулков.
3. Вырезание переулков и магистралей, чистка «шипов» (двухфазная — иначе съедаются тонкие стены).
4. Зоны, штампы: площадь с будкой и терминалом найма, Нексус по ASCII-шаблону (`templates.ts`,
   правится руками, 36×30: 7 одиночных камер КПЗ `c`, общая камера `C` → POI `common_cell` (x, y, w, h),
   коридоры в 4 тайла (Т-образный зал), двор с воротами, кабинет Администратора с
   терминалом `T`, канцелярия со столами `w` → POI `clerk_desk`, казарма ГО с нарами `b` → `bunk`,
   комната OTA `q` → `ota_spot`), кольцо запретной зоны с КПП (позиция ворот подбирается перебором),
   два пограничных КПП на концах главного проспекта (шаблон `CHECKPOINT_TEMPLATE`, восточный —
   зеркальный, 66×25): пустошь → внешние ворота → **внешний двор** (D3/D5) → два прохода, как в CS:
   **шорт** (прямой, 3 тайла) и **лонг** (обход поверху) → **внутренний двор** (D4/D6) → внутренние
   ворота → **проходная** → дверь → проспект (ось — `CHECKPOINT_AXIS_ROW`). Во дворах бетонные
   блоки-укрытия (`BARRIER`: не пройти, но видно поверх), посты `P` (2 во внешнем, 3 во внутреннем)
   и бункеры ГО. Проходная (`CHECKPOINT_GATEHOUSE_X`) отгораживает город от боя: стена-«зигзаг» на
   оси (из двора в город нет ни прямой видимости, ни прострела — даже при открытой двери), дверь со
   стороны проспекта (закрыта, пока рядом никого) и 2 поста RCT `R` (POI `gate_post`). Каждая часть —
   своя зона (`checkpointSection`, имена «… · D3», «… · шорт», «… · лонг», «… · D4», «… · проходная»).
   Пол КПП (`BUNKER`) не считается «переулком» в метрике прямых участков.
5. `features`: заводские дворы, дворы-колодцы с арками, сквозные арки (только если обход длинный;
   подъезды-коридоры с дверями отключены — `passages.archChance = 1`), тупики. Каждая деталь
   откатывается (`GenGrid.snapshot/restore`), если открывает прямой обзор длиннее нормы.
5б. **Городок** (`world/houses.ts`, `generator/homes.ts`, `HOUSES`): сплошная застройка (WALL) между
   переулками режется на участки-дома (`computeLots`: связные массивы стен рекурсивно делятся на
   прямоугольники `lot.min…max`) — детерминированно по тайлам и seed, поэтому генератор и
   `MapRenderer` получают одну нарезку без хранения в JSON. `addHomes`: доля `homes.share`
   прямоугольных участков у переулка в жилых кварталах — жилой дом: стены в тайл, пол
   (`INTERIOR`), дверь в 2 тайла на переулок, POI `home` (x, y, w, h — пол комнаты, для мебели);
   прострел длиннее нормы — откат. Узкие переулки (2–3 тайла) не меняются. Отрисовка: у каждого
   участка своя двускатная крыша (сдержанный серый шифер с лёгкой разницей оттенков — `RENDER.tiles.roof`;
   скаты, конёк, черепица, труба, швы между домами), стены
   жилых домов — светлая штукатурка. Пол помещений: в жилых зонах — доска, в остальных (Нексус,
   КПЗ, магазин) — серая плитка (`MapRenderer.floor`, `RENDER.tiles.woodFloor/tileFloor`).
5в. **Убранство** (`world/furnish.ts`, `config/furniture.ts`, `world/FurnitureRenderer.ts`) — не
   генератор, а отрисовка по готовой карте: `furnishMap` детерминированно раскладывает мебель по
   комнатам (POI `home` по `kind` — дом, общежитие, особняк; `dorm_common`, `villa_living`) по
   рецептам `FURNITURE.recipes`: вдоль стен, от углов к середине, проход у двери (`doorClear`)
   свободен; кровать обязательна (в тесной комнате — узкий проход `doorClearMin`, потом кровать
   поменьше), стол со стульями — после кровати, в свободной части. Размеры — по пешке (≈16×28 px):
   кровать 22×32, двуспальная 36×34, койка казармы 20×30. Плюс мебель Нексуса по точкам шаблона
   (койки `bunk`, столы канцелярии, шкафчики OTA) и стол для карт общежития. Рисунок в духе
   RimWorld (плоские заливки, тёмный контур, волокна дерева, цветные корешки книг), каждый предмет —
   спрайт в кэше (вид, размер, поворот, вариант, квантованный масштаб).
6. `ensureConnectivity`: flood fill по якорям; мелкие фрагменты засыпаются, крупные соединяются
   тоннелем минимальной стоимости (Дейкстра); недостижимые тайлы засыпаются.
7. Метрики и проверка (`validateMap`); до `GENERATOR.validation.attempts` попыток, иначе лучшая.
8. `wastes.addWastes`: карта расширяется влево, вправо и вниз — скалы (`ROCK`), в них тропа шириной
   `trail` от выхода в пустошь каждого КПП (проход сквозь стену) вдоль края и по низу карты; в
   середине нижней полосы — лагерь сопротивления (зона `rebel_camp`, POI `rebel_camp`, `camp_cache`).
   Тропа — зона `wasteland`: горожане, патрули и сканеры туда не ходят.
9. `sewers.addSewers`: карта расширяется вправо; ровно два люка — в запретной зоне у края города
   (`hatchEdge`; зона застроена — прорезается ход к площадке, `carveHatchYards`), сеть тоннелей (решётка → «растущее дерево» + петли; 3 тайла — сток
   посередине, дорожки по бокам), от каждого люка в масштабе 1:2 — ниша с лестницей и сухой ход к
   узлу, убежище с ящиками-укрытиями и тайником, рядом чёрный рынок с прилавком; засыпка мест, куда
   не пролезть. Только добавляет проходимое — связность по построению (проверяет тест).
Генерация детерминирована по seed; ~25–40 мс на попытку.

  приподнята, в профиль — выносятся вперёд и назад. Ствол на ходу без прицела — по ходу.

  (2–3 тона, контур), размером с пешку (`WEAPON_POSE.scale`), повёрнуты за прицелом, влево —
  отражены; на север — за спиной; перезарядка опускает ствол, отдача откатывает; трассер — от

  Круг столкновений (радиус 12) не менялся.
- Магазин у каждого ствола свой (`c.mags`): смена оружия (Q — следующее, H — убрать) патроны не теряет.

### Война на границе (`systems/WarSystem.ts`, `ai/brains/RebelBrain.ts`, `config/war.ts`)
- Фронт = пограничный КПП из **двух отдельных дворов-точек**, как «война на D» на UnionRP: «Запад» —
  D3 → D4, «Восток» — D5 → D6 (`WAR.pointNames`), между ними шорт и лонг (`Front.short/long`,
  `shortZone/longZone`). `buildFronts` находит части по зонам: двор с воротами к пустоши — внешний,
  с воротами к городу — внутренний, из двух проходов ближе к оси ворот — шорт. `DPoint`: зона, посты,
  пол (от входа), центр. Пустошь 14 тайлов с завалами; гарнизон — спецназ SU.03 на всех постах
  (2 во внешнем дворе, 3 во внутреннем) + медик SU.02 в бункере. Проходная (`Front.gatehouse`,
  узнаётся по концу имени зоны `ZONE_NAMES.gatehouse`) — не часть точек D: там 2 RCT.PCU (роль `gate`,
  `Front.gatePosts`, проверяют входящих), `Front.apron` — за её дверью, в городе. `sectionAt` (0 — внешний двор,
  1 — шорт/лонг, 2 — внутренний), `pointAt`, `pointOfPost`. Разметка на полу — `drawPoints`.
- Ритм фронта «сбор → капт»: армия сопротивления приходит из лагеря тропой (этап 7) и собирается на
  пустоши вне видимости постов (`RebelBrain` режим `gather`, `pickGather`, `WAR.gatherDist`) — не
  лезет под огонь по одному. Собралось ≥ `capture.minAttackers` — все разом идут на капт очередной
  точки. Новых отрядов у КПП не появляется.
- `war.active(f)` — стреляли у КПП за `activeWindow` с: указатели на КПП у края экрана
  (`EffectsRenderer.drawFrontMarkers`, с именами точек и их состоянием), перестрелку слышно из города.
- **Капт точки** (`WAR.capture`, `startCapture`/`endCapture`/`updateCapture`): точки берутся по
  очереди (`Front.held` — сколько, с внешней, у повстанцев). Капт на `duration` с; **во время капта
  подкрепления ГО не выходят, новые отряды повстанцев не подходят**. Повстанцы в режиме `capture`
  идут перебежками по двору штурмуемой точки (`coverAt` по `DPoint.floor`): укрытие на доле пути
  `advance`, `coverWait`, `advanceStep`, под огнём — `shootStop`/`dash`. **Не одной толпой**:
  `RebelCommand.formTeams` делит штурмующих на звенья по `capture.teamSize` (глава с HYDRA — звено 0;
  подошедшие позже — в самое малое звено). У звена своя полоса двора из `lanes` (поперёк оси вход →
  центр, `lateralOf`), свой проход во внутренний двор (чётные — шорт, нечётные — лонг; без звена —
  `longChance`), точки маршрута у каждого свои; перекаты — каждые `bound` с бегут чётные или
  нечётные звенья (`boundTurn`), в проход звено входит в свой такт. Укрытие, точка сбора и точки
  маршрута — не ближе `spacing` к цели другого штурмующего (`takenSpots`, `crowdAt`). Клич NPC-главы
  двигает звенья до его рубежа своими полосами (без очереди перекатов), за игроком-главой бегут
  врассыпную (`COMMAND.rally.spread`). Внешний двор взят — сбор уже в
  нём (вне видимости постов внутреннего), а на штурм внутреннего идут и державшие внешний
  (на постах остаётся `keepOnHeld`). Капт начинается, когда у КПП ≥ `minAttackers` бойцов его отряда
  (отходящие в лагерь не в счёт). Итог: защитников на точке не осталось — гарнизон
  (`capture.defenders` — часовые её постов, OTA на них, у внутренней ещё медики) перебит, ГО и OTA
  во дворе нет, а штурмующие уже во дворе — точка взята сразу; или `killsToWin` убийств с перевесом;
  штурмовавшие держат её посты (`hold`), лишние — назад на сбор; все штурмующие погибли — отбит; по
  таймеру (`duration` 60 с) — захват при ≥ `minKills` и перевесе. Захват точки — точка тревоги у
  проходной (код не меняется). Обе точки — **КПП прорван** (`breach`, `owner = 'rebels'`); тогда
  сильнейшие (`capture.gateHold`: до `count`, от `minHp` HP — `holdGate`) встают у углов проходной и
  перед ней (`gateSpots`: анкеры в `radius` px от двери на проспект с ≥ `minWalls` сплошных тайлов
  вокруг) лицом к проспекту (`orderHold(post, face)`) и отстреливают выходящих из города. В лонге
  блоков нет; завалы в полосе пустоши шаблона (`CHECKPOINT_OUTLANDS_W`) — зона пустоши.
- **Цитадель**: погибшие ГО и OTA возвращаются у ворот Нексуса (постоянный состав) — не сразу
  (`ROSTER.respawn`: ГО 60 с, OTA 90 с, иначе гарнизон восполняется быстрее, чем повстанцы
  закрепляются) — и бегут на свои посты (`GUARD`: дальше `LAW.cpRunToPost` — бегом); часовые КПП, где идёт капт, ждут его конца.
  Захваченную точку отбивают контрудары резерва OTA (`counterattack`: через `counterDelay` с, потом
  раз в `retakeEvery` — `retakeOta` свободных OTA на посты ближней к городу захваченной точки,
  `OtaBrain.assignPost`). Точка отбита, когда в её дворе (и ближе к городу) нет повстанцев, а ГО уже
  там, `retakeCalm` с (не раньше `holdTime`). **OTA — туда, где сопротивление** (`WAR.ota`,
  `deployOta`, `rebelsAtFronts`): раз в `every` с резерв и OTA с тихих КПП уходят на КПП, где
  повстанцев (во дворах и на пустоши) ≥ `minRebels` и больше всего, — до `perFront` на посты ближайшей
  к пустоши точки Альянса; во время капта этого КПП не выходят. На тихом КПП без захваченных точек —
  в резерв. Все точки D у повстанцев (`cityPush`) — OTA уходят держать Цитадель, контрударов нет.
- **Граждане к прорванному КПП** (`WAR.defect`, `updateDefection`, `ai/brains/DefectorBrain.ts`): раз в
  `every` с не-лоялист бежит к КПП (чуть медленнее «бега» — чтобы ГО не остановил; от ГО — бегом),
  в коридоре становится повстанцем (`defect`: MP7, розыск, держит пост). Не больше `max` бегущих,
  `perBreach` за прорыв, граждан не меньше `minShare` от начального числа; КПП отбит — бегущие
  возвращаются к жизни. Игрок-гражданин/ГСР в коридоре прорванного КПП — E (событие `defected`).
- **Выход в город**: только когда **все точки D** (оба КПП) у повстанцев (`cityPush`): на каждом КПП
  остаются держать посты `holdKeep`, остальные — `assault` через внутренние ворота. Боец в `assault`
  (или при `cityPush`) в городе → прорвавшийся (`infiltrators`; из отряда фронта исключён навсегда —
  `RebelCommand` не возвращает режимы `storm`/`infiltrate` в `f.squad`, иначе приказ повторялся каждый
  тик и боец стоял) → при `cityPush` — КРАСНЫЙ КОД (только штурм Нексуса): комендантский час, раздача
  закрыта, **никто не возрождается** (`RosterSystem`, игрок — `Game`, крематор; выборы Администратора —
  после отбоя, `ElectionSystem.owed`),
  патрули PCU прочёсывают город по данным «Надзора» (`lastKnown`); OTA по городу не ходит — держит
  Цитадель и КПП. Граждане
  уходят в подъезды/дворы (`shelters`). Отбой — прорвавшихся нет `calmToGreen` с (не раньше
  `redMinTime`); через `redMaxTime` прорвавшиеся «уходят в подполье». `forceAssault` — для тестов.
- **Штурм Нексуса** (`WAR.nexus`, `updateNexus`, режим `storm`) — цель выхода в город. При `cityPush`
  бойцы в `assault` сначала собираются во внутреннем дворе прорванного КПП (`staged`); собралось
  `waveSize` (или ждали `stageMax` с и собралась треть идущих, или `stageHardMax` с) — **волна** (`nexus.wave`): все разом через проходную к Нексусу,
  в городе — `storm` (перебежками к зоне Нексуса, внутри меняют позицию не кучей, раненые не
  отходят; дальше `alleysUntil` px от ворот — переулками: проспект и площадь в A* дороже в
  `alleyCost` раз — `Mover.avoidCost`, чтобы не идти под огнём по открытому проспекту); внутри доля
  `huntAdmin` идёт прямо на Администратора. В зоне Нексуса ≥ `minAttackers` штурмующих и не меньше защитников (боеспособных: раненые ниже
  `COMBAT.woundedFraction`, отошедшие перевязываться, не в счёт) — захват
  копится `captureTime` с (иначе убывает); **Нексус захвачен и Администратор мёртв** (`adminAlive`) —

  игрокам-повстанцам `reward`; через `restartDelay` с — событие `restart`: `Game` на следующем тике
  генерирует новый город, роль игрока прежняя); повстанцев в Нексусе не осталось — отбит.
  Табло — `CaptureBar`.

### Канализация и сопротивление (`systems/UndergroundSystem.ts`, `systems/InsurgencySystem.ts`, `config/underground.ts`)
- Люк: E в радиусе `UNDERGROUND.useRadius` → `climbTime` с на месте → у парного люка на другом
  уровне (`climb` ставит на свободный якорь, без интерполяции). NPC ходят через люки `HatchTravel`:
  `route` выбирает пару люков по сумме «сюда → люк» + «люк → цель».
- Люков два (в запретной зоне у края), пользуются ими только партизаны и спецагент (`UndergroundSystem.canUse`).
  Схрон: `ROSTER.partisans` (2) партизан (`UndergroundBrain`) и `ROSTER.agents` (1) спецагент
  (`AgentBrain`, роль `agent`) — постоянный состав; тайник (E: патроны к своим стволам,
  `refillAmmo`), игрок-партизан и игрок-спецагент появляются здесь.
- **Личина** (`Character.cover` — фракция, юнит, профессия, имя; `entities/cover.ts`: `apparentFaction`,
  `coverAuthority`, `displayName`): партизан всегда под личиной горожанина или ГСР
  (`InsurgencySystem.giveCover`, `PARTISANS.cwuCoverShare`), подпись и внешность — по личине. Под
  личиной ствол в кармане, приказу ГО подчиняется (`ai/comply.ts`), от ГО не бежит; проверка CID
  раскрывает с шансом `PARTISANS.checkReveal` (в розыске — всегда). Ствол в руках и ранение личину не
  снимают (ранивший под личиной не получает `hostile`) — только убийство (`CombatSystem.kill` →
  `reveal`, за убитого из Альянса — `hostile` и розыск); ствол в руках — всё же нарушение `weapon`.
  Подпольщик под личиной без `holdFire` сам берёт цели из Альянса (`Gunner.acquire`, `covert`).
  Вернулся в схрон раскрытым, но не в розыске — новая личина. Возрождение долгое:
  `ROSTER.respawn.partisan` 300 с, `agent` 600 с.
- Вылазки раз в `outingEvery` (в убежище остаётся ≥ `minAtBase`): обход тоннелей до люка, поход
  на рынок, разведка в город через люк (1–2 бойца, режим `outing`). Разведчик скрытен: огонь не
  открывает (`Gunner.holdFire`), заметил ГО — уходит вниз; отвечает, только если ранили.
- Операции раз в `opEvery`: **ствол бандиту** (с шансом `PARTISANS.armChance`: партизан через люк к
  бандиту — `armable`, вплотную `armBandit`: MP7 и патроны, мозг `HiredGunBrain` — ищет патрульного ГО
  в городе, в `hired.engage` px достаёт ствол, `hostile` и розыск, стреляет; время `hired.time` или
  ранен — прячет ствол, прежний мозг) или **саботаж** (боец через люк к узлу Альянса, `sabotageTime` с).
  Раненые и закончившие — к ближайшему люку и вниз. Связь сопротивления видна только игроку-повстанцу.
  Игрок-партизан — E перед бандитом.
- **Допрос** (`PARTISANS.interrogation`, `InsurgencySystem.interrogate`): CMD.EPU (у него в `nextDuty`
  место перед занятой клеткой) раз в `every` с — вопрос, стон пленного и урон (не ниже `minHealth`);
  через `time` с пленный раскалывается и выдаёт другого подпольщика или спецагента (личина снята,
  розыск). **Рейд** (`PARTISANS.raid`, `startRaid`): оба партизана в клетках одновременно — часовые
  КПП (`CpBrain.raidPost`, `postOf`) и свободные OTA (`assignPost(-1, …)`) идут к лагерю
  сопротивления на `duration` с; один рейд на каждый такой раз.
- **Спецагент** (`AgentBrain`, `PARTISANS.agent`): из схрона раз в `rest` с — миссия (`missions`):
  **покушение** на Администратора и высоких чинов (`pickTarget`: Администратор, CMD.EPU, инспекторы,
  офицеры), **взлом** камер КПЗ и клеток (`jailbreak` → `breakCell`, тревога), **бунт**
  (`startRiot`: до `riot.count` горожан — не лоялистов — в `radius` px переходят в состояние `riot`
  `CitizenBrain`: мечутся вокруг точки и кричат лозунги `riot.time` с; нарушение `riot`; тревога).
  Перед покушением и взломом переодевается: форма свежего (`corpseFresh`) тела ГО/OTA (`dressAs`,
  `Corpse.stripped`) или броня OTA у шкафа в комнате OTA (`dressAsOta`); в форме Альянса ГО его не
  проверяет. Раскрывает только убийство (`revealAgent` — вручную: `hostile`, розыск); в схроне — новые
  документы. Игрок-спецагент: E у тела ГО/OTA, у шкафа OTA, у занятой камеры/клетки; G — бунт
  (откат `riot.cooldown`).
- Узлы Альянса (`EconomySystem.nodes`: терминалы у стен на проспектах и площади) ломаются только
  от саботажа; чинит ГСР (дороже щитка). Игрок-повстанец саботирует сам (E), награда `sabotageReward`.
- **Тревога** (`WarSystem.raiseAlarm(x, y, what, yellow)`): саботаж, ранение сотрудника Альянса в
  городе (`CombatSystem.onDamage`), побег, бунт, донос, сканер, захват точки КПП — точка тревоги
  (`alarmActive`: патрули рядом прочёсывают и при зелёном коде), код не меняется. **Код жёлтый — только
  когда ГО, OTA или Администратор увидел тело убитого ГО в городе** (`scanCorpses` раз в
  `ALARM.corpseScan` с, один раз на тело). Тогда же — **место преступления** (`systems/CrimeScenes.ts`,
  `war.scenes`, `CRIME.scene`): вокруг тела лента на `cones` конусах по кругу `radius` px
  (`EffectsRenderer.drawScenes`; лента не проходит сквозь стены), за неё не пускают никого, кроме Альянса
  (выталкивает к краю), тело не обыскать (`sealed` — и игроку, и NPC). Из `seek` px идут следователь
  SU.01 (`CpBrain` состояние `scene`, роль `investigate`: осмотр `scanTime` с → `crime.investigate`,
  убийца в розыск) и офицер PCU.OFC или инспектор SU.INSP (роль `guard`: стоит у ленты лицом наружу);
  отвлеклись на бой — возвращаются (`SCENE_RESUME`); погиб следователь — присылают другого. Снимают через
  `holdAfter` с после осмотра, через `maxTime` с или когда тело увезли (крематор ждёт снятия ленты —
  `awaiting`; пока лента стоит, тело не исчезает); при красном коде оцеплений нет
  (`closeAll`). Лента держит только мирных (горожане, ГСР, вортигонты — `CORDONED`). Без оцепления **бандиты обирают
  тела ГО с оружием** (`CRIME.loot`, работа `loot` в `CitizenBrain`, когда ГО не видно). Нападавшие → `war.operatives` (ушли под землю — след
  потерян), точка тревоги держится `ALARM.pointTime`. Патрули в `respondRadius` → «hunt»: не толпой в
  последнюю известную позицию / точку тревоги, а прочёсывание вокруг неё (`CpBrain.sweep`, `LAW.hunt`:
  у каждого своя точка не ближе `spacing` к точкам других, осмотрелся — следующая); проверки CID чаще (`LAW.alarmCheckMul`). Отбой — `calmToGreen`
  без известных нападавших (не раньше `minTime`); до красного жёлтый сам не растёт.
- Чёрный рынок (прилавок в канализации, торговец — `PostBrain`): оружие и патроны
  (`ECONOMY.blackMarket.stock`), скупка трофеев и рационов (`sell`), поддельная CID (снимает розыск).
- ИИ без «глаз на спине»: `Gunner.acquire` — только в угле обзора `VISION.npcFovDeg` или вплотную;
  ранили / выстрел врага рядом → через реакцию поворот в примерную сторону (`COMBAT.ai.alert*`);
  мозги зовут `gunner.look` последним, чтобы бой и тревога перебивали дежурный взгляд.

### Этап 5: лояльность, чат, карты, сохранение (`config/loyalty.ts`, `config/chat.ts`, `config/minimap.ts`, `config/save.ts`)
- **Лояльность** (`Character.loyalty`, только граждане и ГСР — `hasLoyalty`): + за полученный рацион,
  пройденную проверку, работу ГСР, донос, поощрение ГО; − за штраф, арест, оскорбление, ложный донос.
  Уровни (`LOYALTY.tiers`): неблагонадёжный → гражданин → лоялист → образцовый: множитель плановых
  проверок CID (`checkMul`), надбавка к рациону, скидка в магазине ГСР (`EconomySystem.shopPrice`).
  Граждане-лоялисты (от `LOYALTY.uniform.min`) — в светло-фиолетовой форме и с такой же подписью
  (`isLoyalistUniform` в `EntityRenderer`).
- **Чат** (`ChatSystem.submit`, ввод — `ui/ChatBox`, Enter или «/»): речь — реплика и строка журнала
  (вид `chat`); ГО, который видит, на оскорбление (`CHAT.insult`) требует документы — нарушение
  `insult`, штраф; на приветствие отвечает прохожий. Команды: /me, /r (рация ГО), /roll, /cid,
  /донос (виден повстанец/вооружённый/в розыске: повстанец — тревога, иначе патрульный идёт
  разбираться), /поощрить (ГО), /помощь.
- **Карты** (`ui/MapView`): мини-карта в углу и большая карта (M) уровня игрока, собираются из тайлов
  один раз; канализация открывается по мере исследования (повстанцам — сразу), люки — найденные.
  Маркеры: КПП (бой/капт/захвачен), Нексус, раздача, магазин, сломанные узлы, тревога, свои.
- **Сохранение** (`SaveGame`, localStorage `SAVE.key`): роль, имя, деньги, лояльность, здоровье,
  сытость, инвентарь и оружие, статус CID, позиция, знание карты; seed карты. Автосохранение раз в
  `SAVE.interval` с, при выборе роли и закрытии вкладки. Без ?seed (или с тем же seed) игра
  продолжается; «Новая игра» (в главном меню — экран подтверждения, в меню роли — второе нажатие; `window.confirm` в песочнице не работает) стирает сохранение. Задержанный сохраняется в розыске.
- **Пауза** — P. **Меню** (`ui/GameMenu`): главное при запуске (продолжить / играть, новая игра,
  управление, звук) и пауза по Esc (продолжить, сохранить, сменить роль, управление, звук, выйти в
  главное меню — с сохранением). Пока меню открыто, мир стоит. Esc сначала закрывает открытые панели
  (`Game.onEscape`, перехват до остальных обработчиков); список клавиш — `CONTROLS_HELP` в `HelpBar`.

  одно место у заводского двора промзоны), `packStep`; курьер носит их со склада цеха

  `EconomySystem.rationStock` расходуется поваром на раздаче (пусто — `onEmpty`, рацион не выдаётся).

- **Бумажная работа лоялистов** (`LABOR.paperwork`, `LaborSystem.desks/claimDesk/payPaperwork`, работа

  за жертвой чуть быстрее шага (`stalk`, не бег), держась за спиной.
- **Лояльность**: у уровней `perks` (`run` — бег без нарушения, `queue` — очередь впереди, `escort` —
  `/охрана`, BODYGUARD у `CpBrain`).
- **ГО** — юниты силового блока (см. «Закон»). Следователь SU.01 (`cpHas(c, 'investigate')`): состояние
  SCAN — осмотр тела, `CrimeSystem.investigate` объявляет убийцу (`Corpse.killer`) в розыск. Техник
  SU.02 (`drone`): дрон `ScannerSystem` (время жизни и откат, облёт, повстанец/вооружённый →
  `raiseAlarm`, розыск → ближайший патрульный).
- **Повстанцы**: в отрядах WarSystem медики (`RebelBrain.medic`) и пиро; партизан — `disguised`
  (`isHostile`/`observe` его не узнают; оружие в руках или проверка — `reveal`).
- **Огонь** (`FIRE`): граната пиро оставляет зону (`combat.fires`), болт поджигает; `ignite` →
  `burnUntil`, урон `dps`. **Крематор** (`CrematorBrain`, `LaborSystem.ensureCremator`) — один на

- **Штаб ГСР** (`systems/CwuHq.ts`, `config/cwuHq.ts`, `ctx.cwuHq`): **глава ГСР** (профессия

  `hire.time` с → `hire(c, prof)`: берут туда, где рабочих меньше всего не хватает (`hire.needs`,
  `vacancy`), не больше `maxWorkers` ГСР и граждан не меньше `minCitizenShare` — иначе «мест нет».
  Принятый — рабочий ГСР: фракция, профессия, набор без потери вещей, роль (возрождается рабочим),

  столу главы; дошёл — требует отчёт, глава отчитывается (`inspection`, журнал). На картах маркер

## Соглашения
- Все числа, цвета, скорости, зарплаты и т.п. — в `src/config/*`. Новый параметр → в конфиг.
- `src/` не использует API Node; `tests/` может (свой `tests/tsconfig.json`).
- Случайность в генерации и мире — только через `Rng` (seed), не `Math.random` (кроме выбора нового seed).
- Логика не трогает DOM; UI подписывается на `EventBus`. Новые события — в `GameEvents`.
- Персонаж игрока и NPC — один класс `Character`; различие только в источнике управления.
- Отрисовка тайлов — в экранных пикселях с округлением (без щелей); подписи — в экранных пикселях.
- Перед коммитом: `npm run typecheck && npm test`.
- Тесты детерминированы: `makeSim` сбрасывает общий набор номеров CID (`resetCids`), иначе случайность
  теста зависела бы от предыдущих тестов файла.
