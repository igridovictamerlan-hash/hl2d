# CLAUDE.md — Сити-17 (HL2RP 2D)

Браузерная 2D-игра с видом сверху в духе HL2RP-серверов Garry's Mod: тесный город из переулков под
контролем Альянса. Все персонажи — пешки в стиле RimWorld (цвет формы по рангу) с подписью имени/роли. Игрок управляет одним,
остальные — NPC, ведущие себя как игроки RP-сервера.

**Язык:** интерфейс, комментарии и документация — по-русски; идентификаторы в коде — по-английски.

## Команды

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # vitest: генератор, A*, коллизии, JSON, симуляция NPC
npm run typecheck  # tsc для src и tests
npm run build      # typecheck + сборка в dist/
npm run mapstats   # метрики генератора по 30 сидам (DEBUG_GEN=1 — причины отбраковки попыток)
```

Параметры адреса: `?seed=123` (карта по seed, пишется в адрес автоматически), `?map=city17`
(загрузить `public/maps/city17.json`), `?npcs=40`, `?debug=1`, `?mode=squad&side=rebel|combine`
(экспериментальный режим «отряд на отряд»).

## Стек и почему без движка

TypeScript + Vite + HTML5 Canvas 2D, без игровых движков. Всё ключевое здесь нестандартное —
генератор переулков, туман войны лучами, A* по якорям 2×2 с учётом радиуса, уступание дороги;
Phaser не дал бы готового для этого, а добавил бы свой цикл, сцену и физику, с которыми пришлось бы
бороться. Логика не зависит от DOM и целиком тестируется в Node (vitest), включая безголовую
симуляцию NPC (`tests/simHarness.ts`).

### Тик логики (`Game.update`, 60 Гц)
1. `PlayerController`: ввод → `player.wantX/wantY`, взгляд на курсор, прицел (ПКМ), огонь, смена оружия, E/F/1/2/3.
   Задержанному игроку временно ставится `PrisonerBrain` — тогда ввод движения игнорируется.
2. `updateNpcs`: мозги (FSM) → `Mover` выставляет `wantX/wantY` → `dodgeGrenades` (граната рядом —
   бегство поверх решения мозга) → присед (в бою стоит — сел, `CROUCH.npcStill`); тяжелораненые
   лежат, их мозг ждёт; затем `PathService.process()`.
3. `DoorSystem`: двери открываются, если рядом кто-то есть; закрываются через `DOORS.closeDelay`.
4. `stepPhysics`: разгон → движение → расталкивание по массам → выталкивание из стен.
5. `LawSystem.update`: неподчинение игрока, заведение в камеру, сроки, освобождение.
5a. `EconomySystem` (раздача, голод, зарплаты, поломки) → `CombatSystem` (пули в полёте, гранаты, дым,
   перезарядка, перевязка, кровотечение, регенерация, уборка убитых) → `Particles` (эффекты) →
   `WarSystem` (отряды у КПП, подкрепления, прорыв, тревоги) → `InsurgencySystem` (гарнизон убежища,
   операции) → … → `CwuHq` → `ArsenalSystem` (борт и заявки, брошенный груз, приёмка, отсек, конвои, смена, заряд, инспекция) → возрождение игрока. В «отряд на отряд» после боя — только `SquadArena`.
6. Видимость: многоугольник обзора игрока (`VISION.rays` лучей DDA) и `c.visible` у всех.
7. Камера (в границах уровня игрока; сменил уровень — `snapTo`), зоны, UI (DOM — с частотой `GAME.hudInterval`).

Отрисовка (`Game.render`): карта → терминал найма → эффекты на земле (тела, щитки, очередь, склад и
тень корабля) → персонажи (только видимые; нос-треугольник — взгляд, силуэт оружия по классу) → ящики
в руках грузчиков → конусы NPC → дымок из труб → **свет** (карта света × картинку) → свечение ламп и
огня, маяк склада → пылинки → частицы боя → пули и гранаты → взмахи дубинки → туман → отсвет взрывов и
дым → корабль Альянса (в небе — поверх тумана) → конус игрока → подписи и реплики → отладка → виньетка →
зерно → красный код/ранение → вспышка ранения и маркер попадания → указатели на КПП → прицел. Интерполяция `prevX → x`.
Вспышки выстрелов, пули и частицы рисуются после света — ночью они ярко видны.

### Свет и уют (`world/Lighting.ts`, `world/Ambience.ts`, `config/lighting.ts`) — только картинка
- **Время суток**: `LIGHTING.dayLength` с игрового времени (`Game.time`), начало — закат (`start`);
  `dayFraction`, `dayState` — плавно между ключевыми точками `keys` (свет вокруг `ambient`, насколько
  горят лампы `lamps`, название), `clockText`; часы в HUD («19:40 · вечер», `Game.clock`). На логику
  не влияет (NPC видят как раньше).
- **Карта света** (`Lighting.draw`): холст в `lightmapScale` от экрана — заливка светом суток, поверх
  сложением мягкие пятна-спрайты (по спрайту на цвет): фонари улиц (`lamp`, ночью), бочки и костры
  (мерцают), комнаты и места по POI (`LIGHTING.pois`: жилые — тёплые лампы, Альянс — холодный белый,
  КПП — прожекторы, `night` — только в темноте), узлы Альянса (сломан — не горит), свет из люков в
  канализации; пламя, взрывы, вспышки выстрелов (`Fx.t`, `muzzle.time`), горящие, свой свет игрока.
  Потом `multiply` на картинку. Ясный день — проход пропускается (`skipDay`); канализация — свои
  сумерки (`sewer`). Источники карты собираются раз (`staticLights`).
- **Свечение** (`drawBloom`): плафоны, окна, огонь — пятна в мелком буфере, на экран одним проходом
  `lighter`, тем ярче, чем темнее. **Пылинки** в свете ламп, **дымок из труб** (`MapRenderer
  .chimneyPoints`, сносит ветром, чаще ночью), **зерно** (тайл шума со сдвигом раз в два кадра),
  тёплая виньетка (`COZY.vignette`), тёплая палитра интерфейса. Звук: ветер с порывами (ночью громче),
  треск огня у бочек и костров (`GunfireAudio.ambient`, `AUDIO.ambient`, `Game.fireSpots`).
- **Меню**: «Атмосфера» вкл/выкл (`COZY.storageKey`). Слабая машина (кадров меньше `autoLite.fps`
  дольше `after` с) — упрощённо (`lite`: без зерна, свечения и пылинок), сама обратно не усложняется.
- Тесты — `tests/lighting.test.ts` (сутки, часы, источники).

### Ключевые понятия
- **Тайл** 16 px. Город 300×230 тайлов (4800×3680 px; главный проспект между КПП ~165 тайлов —
  бегом ~15 с) в кольце пустоши за стеной (8 тайлов слева и справа, 26 снизу: тропа и лагерь
  сопротивления) — 316×256; справа за зазором — канализация (масштаб 1:2), вся карта 478×256. Типы — `world/tiles.ts` (`solid`, `opaque`, символ для JSON).
  Добавляя тип, допишите его в `TILE_DEFS`, палитру `MapRenderer` и `DevPanel`.
- **Уровни** (`Level`: city / sewer) — две области одной сетки без прохода между ними; связь только
  люками. `GameMap.underground` (прямоугольник канализации по её зонам), `levelAt`, `levelBounds`;
  `NavGrid.level` по якорям. A* между уровнями сразу отказывает, `randomAnchorAround` берёт цели
  только на своём уровне, камера не выходит за границы уровня, в канализации обзор короче
  (`VISION.sewerRadius`), выстрелы с другого уровня не слышны.
- **Якорь 2×2**: персонаж радиусом 12 px занимает квадрат 2×2 тайла. Якорь (ax, ay) ↔ центр в
  ((ax+1)·16, (ay+1)·16). Связность карты, A* и поиск «карманов» работают по якорям — поэтому
  проход 2 тайла (32 px) пропускает ровно одного, 3 тайла (48 px) — двоих.
- **Зоны** — сетка `zoneGrid` (id зоны на тайл) + список `zones` (kind + имя). `ZoneKind`:
  residential, avenue, plaza, nexus, cells, industrial, restricted, checkpoint (пограничные КПП),
  outlands (пустоши за стеной), shop (магазин ГСР, лавки и кафе проспекта — у каждой своя зона с
  названием), sewer, rebel_base (убежище), black_market, cwu_hq (штаб ГСР), arsenal (склад Альянса),
  canteen (общая столовая).
- **Точки интереса (POI)** — `map.pois` в координатах тайлов: лагерь сопротивления и его тайник, окно раздачи, центр площади, терминал
  найма, ворота и стойка Нексуса, терминал кодов тревоги, камеры КПЗ, ворота запретной зоны, заводские дворы, посты часовых
  КПП, выходы в пустоши, люки (`hatch` в городе / `sewer_hatch` в канализации: якорь 2×2, x,y — его
  левый верхний тайл; пары связаны одинаковым `id`), убежище, тайник, прилавок и место торговца.
- **Двери** — группы соседних тайлов `DOOR`. Состояние (закрыта/заперта) живёт в `GameMap.doorClosed/
  doorLocked`: закрытая перекрывает обзор (`isOpaque`), запертая — ещё и проход (`isSolid`).
  Запирание вызывает `NavGrid.refresh` вокруг двери.
- **Видимость**: `visibility.ts` — луч DDA до первого непрозрачного тайла. Игрок видит в радиусе
  `VISION.radius`; NPC — в `VISION.npcRange` с углом обзора `npcFovDeg` (вплотную — во все стороны).
  Одни и те же функции для игрока и NPC: от ГО можно скрыться за поворотом или за дверью.
- **Фракции и ранги** — `config/factions.ts`. Цвет формы пешки по рангу (`colorsOf`): ГО от голубого
  (RCT) до тёмно-синего (DvL). У сопротивления юнит — по профессии (`REBEL_RANKS`, `rebelUnitOf`,
  `REBEL_UNIT`; `rank` = номер юнита, HP — `roleHp`): армия — жёлтые ники, глава Патрик и HYDRA
  (`elite`) — красные. Рубаха армии синяя, жилет — с солдата.
  `authority` — кто проверяет, а не проверяется (ГО, OTA, администратор).

### Генератор (`world/generator/CityGenerator.ts`)
1. `layout`: магистраль по центру (+ вторая с шансом 50%), линии решётки с отступами от проспекта,
   углы запретной зоны и промзоны, площадь на длинном прямом участке проспекта, Нексус рядом.
   **Проспект старого города** (`GENERATOR.avenue`, `planAvenueSegs`): ширина `width` (10), ось плавно
   изгибается (`bends` полуволн синусоиды амплитудой `amp`, от КПП разгон `ease`), проспект — череда
   участков `segmentLength` (≈ фасад дома; `AvenueSeg` — свои `offset` и `width`), ось на стыке сдвигается
   не больше `maxStep`, края — ещё на ±`edgeJitter`; у площади — прямой участок. Линии решётки отходят от
   проспекта на полосу домов (`avenueSpacing`: `avenueReach` + `facadeReach`); переулки от узлов
   проспекта пересекают её прямо — излом ребра за полосой (`constrainAvenueLanes` → `LEdge.kinkMin/
   kinkMax`). Между фасадом Нексуса и неровным краем асфальта — площадка (`fillForecourt`).
1б. **Улицы-артерии** (`generator/streets.ts`, `GENERATOR.streets/dorms/villas`) — по решётке после
   разметки регионов, до лабиринта (`planStreets`): стволы шириной 4 от узлов проспекта (и от дальнего
   края площади) на `branchRow` линий вглубь, на конце — ветви вдоль горизонтальной линии в обе
   стороны (до `branchMax` рёбер), от ветвей — улочки шириной 3 (`lanes`) дальше вглубь; сторона без
   стволов (там Нексус и КПП) получает улицу через `detachedRow` линий. Рёбра артерий сразу вырезаны
   (`LEdge.artery`, ширина не меняется в `finalizeEdges`), изломы Z-образные, как у переулков; асфальт
   (`carveArteries`), у каждой артерии своя зона вида `avenue` («улица Брина»…, `ZONE_NAMES.streets`).
   Вдоль улиц — места под **общежития** (`DORM_TEMPLATE` 21×17: Т-коридор, 7 комнат `r` → POI `home`
   с `kind: 'dorm'`, общая комната `m` → `dorm_common` со столом `x` → `dorm_table`) и **особняки
   лоялистов** (`VILLA_TEMPLATE` 16×14: живая изгородь `h` → `HEDGE`, сад `v` → `GARDEN`, деревья `t`
   → POI `tree`, спальня → `home` `kind: 'villa'`, гостиная → `villa_living`); вход на улицу
   (`faceTemplate`: S/N/E/W), здания — пустоты решётки (лабиринт их обходит), штампуются вместе с
   Нексусом, выходы прокапываются. Зоны: «Общежитие №k», «Особняки лоялистов» — вид residential
   (стены — штукатурка). Символы зон в JSON у многочисленных зон (улицы, общежития, особняки) —
   первый свободный из `ZONE_CHAR_POOL` (`addZone(…, null)`). Проверка карты требует ≥ 2 общежитий
   и ≥ 2 особняков.

4б. **Ряды домов** (`generator/arbat.ts`, `GENERATOR.facades`, `config/arbat.ts`) — после штампов, до

   у каждой лавки своя зона с названием. Посередине проспекта (`placeAvenueDecor`, `decor`) — ларьки 3×2
   (`kiosk`, `sub`, окошко на `face`) и клумбы 2×2 (`planter`) через `every` тайлов, чередуясь: укрытие
   `BARRIER`, вокруг кольцо асфальта, не у устья переулка, не ближе `endClear` к КПП. Проверка карты
   требует столовую, ≥ 2 стола, ≥ 2 ларька, ≥ 40 домов и ≥ 4 продавцов.
5. `features`: заводские дворы, дворы-колодцы с арками, сквозные арки (только если обход длинный;

   откатывается (`GenGrid.snapshot/restore`), если открывает прямой обзор длиннее нормы.
5б. **Городок** (`world/houses.ts`, `generator/homes.ts`, `HOUSES`): сплошная застройка (WALL) между
   переулками режется на участки-дома (`computeLots`: связные массивы стен рекурсивно делятся на

   прямоугольных участков у переулка в жилых кварталах — жилой дом: стены в тайл, пол
   (`INTERIOR`), дверь в 2 тайла на переулок, POI `home` (x, y, w, h — пол комнаты, для мебели);
   прострел длиннее нормы — откат. Узкие переулки (2–3 тайла) не меняются. Отрисовка: у каждого
   участка своя двускатная крыша (сдержанный серый шифер с лёгкой разницей оттенков — `RENDER.tiles.roof`;
   скаты, конёк, черепица, труба, швы между домами), стены
   жилых домов — светлая штукатурка. Дома вдоль улиц (POI `facade`) крыш не имеют: у каждого своя

   через `windowEvery` тайлов (у лавок — витрины с бликом), над входом лавки — полосатая маркиза с
   вывеской трафаретом (`MapRenderer.overlays`, в кэше кусков карты); прилавки и столы — дерево, ларёк —
   с окошком и вывеской, клумба — с цветами; проспекты вымощены брусчаткой (`cobble`). Ночью светятся
   витрины, окошки ларьков и зал столовой (`LIGHTING.pois`). Пол помещений: в жилых зонах — доска, в остальных (Нексус,
   КПЗ, магазин) — серая плитка (`MapRenderer.floor`, `RENDER.tiles.woodFloor/tileFloor`).
5в. **Убранство** (`world/furnish.ts`, `config/furniture.ts`, `world/FurnitureRenderer.ts`) — не
   генератор, а отрисовка по готовой карте: `furnishMap` детерминированно раскладывает мебель по
   комнатам (POI `home` по `kind` — дом, общежитие, особняк; `dorm_common`, `villa_living`) по
   рецептам `FURNITURE.recipes`: вдоль стен, от углов к середине, проход у двери (`doorClear`)
   свободен; кровать обязательна (в тесной комнате — узкий проход `doorClearMin`, потом кровать
   поменьше), стол со стульями — после кровати, в свободной части. Размеры — по пешке (≈16×28 px):
   кровать 22×32, двуспальная 36×34, койка казармы 20×30. Плюс мебель Нексуса по точкам шаблона
   (койки `bunk`, столы канцелярии, шкафчики OTA) и стол для карт общежития. Рисунок в духе
   RimWorld (плоские заливки, тёмный контур, волокна дерева, цветные корешки книг), каждый предмет —
   спрайт в кэше (вид, размер, поворот, вариант, квантованный масштаб).
6. `ensureConnectivity`: flood fill по якорям; мелкие фрагменты засыпаются, крупные соединяются
   тоннелем минимальной стоимости (Дейкстра); недостижимые тайлы засыпаются.
7. Метрики и проверка (`validateMap`); до `GENERATOR.validation.attempts` попыток, иначе лучшая.
8. `wastes.addWastes`: карта расширяется влево, вправо и вниз — скалы (`ROCK`), в них тропа шириной
   `trail` от выхода в пустошь каждого КПП (проход сквозь стену) вдоль края и по низу карты; в
   середине нижней полосы — лагерь сопротивления (зона `rebel_camp`, POI `rebel_camp`, `camp_cache`).
   Тропа — зона `wasteland`: горожане, патрули и сканеры туда не ходят.
9. `sewers.addSewers`: карта расширяется вправо; ровно два люка — в запретной зоне у края города
   (`hatchEdge`; зона застроена — прорезается ход к площадке, `carveHatchYards`), сеть тоннелей (решётка → «растущее дерево» + петли; 3 тайла — сток
   посередине, дорожки по бокам), от каждого люка в масштабе 1:2 — ниша с лестницей и сухой ход к
   узлу, убежище с ящиками-укрытиями и тайником, рядом чёрный рынок с прилавком; засыпка мест, куда
   не пролезть. Только добавляет проходимое — связность по построению (проверяет тест).
Генерация детерминирована по seed; ~25–40 мс на попытку.

### Формат карты JSON (`world/mapIO.ts`, версия 1)
`tiles` и `zoneGrid` — массивы строк по символу на тайл (легенда в `legend`), `zones`, `pois`
(у люков — `id` пары), `stats`. Связность в F2 и тестах считается с учётом люков (`hatchLinks`). Карту можно поправить в редакторе с моноширинным шрифтом; при загрузке проверяются размеры
и символы (ошибка с номером строки/столбца), панель F2 показывает связность и прямые участки.

### ИИ NPC
- `Brain` (интерфейс) решает, что делать; каждая фракция — свой класс в `ai/brains/` с
  `StateMachine` (idle, walk, work, patrol, chase, flee, fight, arrested — по мере этапов).
- `Mover` — общее передвижение: запрос пути, следование со «сглаженным» путём, объезд встречных
  по правилу правой руки (но не в стену), распознавание блокировки:
  встречные лоб в лоб → уступает младший по `FACTIONS[*].yieldPriority` (игрок главнее всех),
  при равенстве — тот, кому ближе до «кармана»; стоящего NPC просят отойти; стоящего игрока ждут,
  потом разворачиваются; упёрся в стену — перестраивает путь.
  Сторож затора (`AI.move.giveUp*`, `ghost*`): идёт к цели, но не отходит дальше 64 px от одного места —
  через 4 с, упираясь в NPC, ненадолго проходит сквозь NPC (`Character.ghost`, физика не расталкивает;
  игрока — никогда), через 12 с бросает цель (`failed`). Тест: никто не упирается дольше 20 с.
- Цели прогулок — `ai/destinations.ts`; зоны, которых NPC избегают, — через `avoidZones` в A*.
  Сторож затора проходит сквозь и соседа вплотную сбоку (`ghostContact`), не только впереди: тот
  может прижимать к стене или завалу (глава и его охрана HYDRA на тропе).
- **Уличная жизнь** (`systems/StreetLife.ts`, `config/street.ts`, состояния `CitizenBrain`): после
  паузы житель с долей `STREET.activityChance` занят своим, а не бредёт в случайную точку —
  **chat** (подходит к свободному жителю в прямой видимости, стоят лицом друг к другу, вопрос —
  ответ из `STREET.dialogues`; потом иногда гуляют вдвоём к одной цели), **barrel** (место в круге у
  бочки с огнём — бочки во дворах-колодцах и широких местах, `EffectsRenderer.drawBarrels`),
  **home** (якорь в помещении жилого квартала, побыть там), **listen** (обращение Администратора
  на площади раз в `broadcast.every` с: строки в журнал, жители в `radius` идут слушать), **bench**
  (только при зелёном коде: место на скамейке главного проспекта, `takeBenchSeat` — где уже сидят,
  привлекательнее; вдвоём беседуют — ведёт младший по id, один — изредка бормочет; код сменился —
  встают). Фонари и скамейки (`StreetLifeSystem.lamps/benches`, `placeAvenue`, `STREET.avenue`) —
  у стен главного проспекта, детерминированно без rng: якорь 2×2 на асфальте, за ним сплошная стена;
  скамейка — два таких якоря подряд (два места, перед ними ещё 2 тайла асфальта), не у дверей и
  постов проходной; всё это — на проспекте и всех улицах-артериях. **cards** (стол общей комнаты
  общежития, места вокруг — `takeTableSeat`; где уже играют — привлекательнее; рабочие ГСР не играют),
  **smoke** (перекур в сторонке: `Character.smoking` — огонёк и дымок, `EffectsRenderer.drawSmokers`),
  **notice** (доска объявлений на стене улицы — `boards`, прочитать и хмыкнуть), **family** (к
  родственнику через полгорода — `startFamilyChat`, семейные реплики `FAMILIES.dialogues`); `home` —
  к себе домой, если есть семья. Реплики — `STREET.dialogues/benchLines/barrelLines/cardLines/
  smokeLines/noticeLines`. Отрисовка — `EffectsRenderer.drawAvenue` (фонари, скамейки, доски; пятно
  света — спрайт, градиент один раз), мебель — `FurnitureRenderer`, деревья садов —
  `EffectsRenderer.drawFurniture`. **shopping** (`STREET`-занятие с весом `ARBAT.visit.weight`, только при
  зелёном коде и если лавка не дальше `visit.seek`): к прилавку лавки или окошку ларька
  (`StreetShops.pickShop`), постоять `stay` с, купить что по карману (`npcBuy`, голодный — еду; «для
  вида» — ателье, газеты, цветы), реплики `ARBAT.lines`. **canteen** (в `decide`, до уличных занятий):
  горожанин (не вор и не бандит; у ГСР своя столовая в штабе) с едой и сытостью ниже `meal.hungerBelow`
  с шансом `meal.chance` идёт в общую столовую — место за столом (`takeSeat`, где уже едят —
  привлекательнее), ест `eat` с (`StreetShops.eat`: паёк из инвентаря, лояльным +`loyalty`), с соседями
  по столу болтает. Игрок — E у прилавка (`ShopPanel` вид `street`) и у места за столом. На ходу
  иногда останавливаются оглядеться (`glance`). Воры и бандиты этим не заняты; при красном коде —
  нет. Прервать может ГО, стрельба, комендантский час — собеседник тоже расходится.

- **Лавки и товар** (`systems/StreetShops.ts`, `ARBAT.supply/staff/soup`): у лавки, кафе, ларька и столовой
  запас `goods` (до `cap`), покупка — единица. За прилавком лавки и кафе — **продавец** ГСР (профессия

### Оружие и бой (`systems/CombatSystem.ts`, `systems/wounds.ts`, `ai/Gunner.ts`, `config/items.ts`, `config/combat.ts`)
- 14 стволов в `WEAPONS`: дубинка ГО (удар в секторе, оглушает — `speedMul`), нож (`blade`: в спину —
  `backstab` и мимо брони, два удара валят PCU.03), USP, револьвер .357, MP7, трофейный MP7,
  самодельный пистолет, M4A4 и АК-74 (`rifle`), энерговинтовка AR2 (`pulse`, пробивает укрытия и
  броню), SPAS-12 (8 дробин, по патрону), снайперская винтовка (`sniper`), арбалет, РПГ (`launcher`,
  `blastMul`). У каждого: режим огня (`semi/auto/pump/melee`), урон по корпусу без брони, падение урона
  (`effectiveRange → range`, `falloff`), конус разброса, отдача (`recoil` — разброс, `kick/kickSide/
  kickMax` — увод ствола, `shake` — толчок камеры), скорость пули `speed`, бронебойность `pierce`,
  магазин, перезарядка, пробитие блоков, время доставания, замедление при прицеливании, слышимость.
- **Пули** (`CombatSystem.bullets`, `Bullet`): куда попадёт, решается при выстреле (стена, блок, первый
  на линии — цель и зона), пуля летит от дула со скоростью оружия, урон — по прилёту (`land`), долетевшая
  живёт ещё тик (хвост дорисовывается). `fire` возвращает, в кого попадёт. Ракета РПГ проверяет
  попадание на лету (`rocketHit`, взводится через `ROCKET.arm`) и взрывается о стену/блок/первого.
  ИИ стреляет с упреждением по скорости цели (`d / speed`).
- **Хитбоксы и броня** (`HITS`, `ARMOR`, `wounds.ts`): зона — `rollZone` по весам (прицел добавляет к
  голове `headAim`), урон × `HITS.mul[зона]` × (1 − броня зоны × (1 − `pierce`)); броня — `armorOf`:
  силовой блок по юниту, OTA и армия по профессии (Патрик в берете — голова открыта), остальные без
  брони. **Голова без шлема — смерть от любого огнестрела** (`headshots`). Взрыв — без зон, жилет держит
  `blastVest` своей доли; осколки за радиусом (`fragReach`, `fragChance`) — в руки и ноги.
- **Кровотечение** (`Character.bleed`, HP/с): каждое ранение добавляет `урон × HITS.bleed[зона]` (до
  `bleedMax`), само не проходит; истёк — `kill(…, 'истёк кровью')` от ранившего (`bledOut`), регенерации
  при кровотечении нет. Нога — хромота (`limpUntil`, `HITS.limp`), рука — конус шире (`armUntil`).
  Перевязка (`startBandage`, игрок — B): `HITS.bandageTime` с стоит и не стреляет, потом бинт (или
  аптечка, если ранен сильно) — кровь остановлена, аптечка снимает и хромоту. NPC перевязывается сам,
  когда в него `selfHealCalm` с не попадали; медики (`heal`, `LaborSystem.treat`, `EconomySystem.use`)
  тоже останавливают кровь. HUD игрока — строка ранений.
- **Конус как в Foxhole**: `spreadOf(c)` — полуугол от `spreadHip` до `spreadAim` по мере
  прицеливания `c.aim` (игрок — ПКМ, NPC — пока ведёт цель; копится стоя, медленнее на ходу,
  теряется на бегу), + движение (`moveSpread`, бег — сильнее) + отдача `c.recoil` (спадает
  `recovery`/с), рука ранена — × `armSpread`. Пуля/дробина — треугольное распределение строго внутри
  конуса вокруг `прицел + c.kick` (увод ствола: `kickDir` меняется с шансом `kickSide`, возвращается со
  скоростью `recovery × COMBAT.kickReturn`; модель в руках повёрнута на `kick`).
  `AimRenderer`: треугольник разброса, заливка обрезана стенами лучами DDA, дуга на предельной
  дальности (белая — прицел полный, серая с заполнением — перезарядка), штрихами — дальность полного
  урона. У игрока — всегда (от бедра бледный), у NPC — когда целится. При прицеливании камера
  отдаляется и уходит к курсору (`CAMERA.aim*`), чтобы дуга была в кадре. V — масштаб камеры по
  кругу (`CAMERA.zoomLevels`, `Camera.cycleZoom`, плавно — `zoomRate`; умножается на прицельный).

  N — вкл/выкл. Логика звук не трогает — UI читает `combat.shots` и `combat.fx`.
- **Эффекты** (`world/Particles.ts`, `RENDER.particles`): бой пишет `combat.fx` (`Fx`: muzzle, hit, wall,
  stab, blast, fire, smoke, rocket — по возрастанию `seq`, последние 400), частицы читают новые и
  рождают вспышку и язык пламени у дула, кровь по ходу пули, искры/пыль/крошку от стен, огненные клубы,
  дым, осколки, искры и ударную волну взрыва, отсвет поверх тумана (`drawOver`), дымовые завесы.
  Массивы фиксированного размера (`max`), своя случайность (не игровая), без save/restore. Тряска
  экрана (`shake`: свой выстрел — `w.shake × shot`, попали в игрока, взрыв рядом), красная вспышка
  ранения и маркер попадания у прицела (`drawHud`; убил — красный).
- **Гранаты** (`GRENADE` в `config/combat.ts`; `GrenadeId`: `grenade` — осколочная, `smoke_grenade`,
  `fire_grenade`; `GRENADE_KINDS`): `CombatSystem.throwGrenade(c, x, y, kind)` — летит к точке (стену не
  перелетает, блок — да), срабатывает через свой `fuse`: осколочная — `explode` (урон по кругу с
  падением к краю, стена закрывает, блок ослабляет; «выстрел» `weapon: 'blast'`); дымовая — облако
  (`Smoke`: тайлы в радиусе, куда дым дотекает, получают `GameMap.smoke` — `isOpaque` для взгляда,
  тумана и обзора NPC, но не `blocksShot`; `smoke.time` с); зажигательная — пламя `fire.radius` на
  `fire.time` с (поджигает, `FIRE`). Игрок — T к курсору, Y — сменить (`Character.grenadeKind`).
  ИИ (`Gunner.tryGrenade`): осколочная, иначе зажигательная — цель за укрытием или кучка врагов, своих
  у точки нет; дым — `trySmoke`. `ai/Dodge.ts`: заметил гранату (не дымовую) — бежит за стену.
  Наборы: армия, SU, OTA; все три продаются на чёрном рынке.
- **Растяжки** (`MINE`, `CombatSystem.mines`, `Mine`): осколочная или зажигательная граната под ноги
  (`startPlant` → `plantMine` через `plantTime` с, игрок — Z; `Character.plantUntil`, `busy` — стоит и не
  стреляет); рядом тело (`corpseReach`) — минируется тело (`Mine.corpse`; тело убрали — растяжка
  снята). Взводится через `arm` с; задевает враг ставившего (`minesFor`: для повстанца — сотрудник
  Альянса, мирных не трогает) ближе `trigger` px — граната «на земле» взрывается через `delay`
  (Dodge успевает крикнуть). Сотрудник Альянса, видящий чужую растяжку ближе `spot` px, замечает с
  шансом `spotChance`/с и обезвреживает (`mineStats`). Не больше `max` на карте. Рисует
  `EffectsRenderer.drawMines`: своя сторона видит все, чужие — ближе `seeRange` и в прямой видимости.
- **Следы** (`combat.decals`, `COMBAT.decals`): гильзы, кровь, выбоины у стен, копоть; живут десятки
  секунд, список ограничен. Взрыв — вспышка/дым (`combat.blasts`) и тряска экрана (`Game.shake`).
- **Производительность отрисовки** (бой у КПП — десятки пешек, тел и следов): карта — куски по
  `RENDER.mapCache.chunk` тайлов, нарисованные в холст на уровне масштаба (`levels`, ближайший не
  меньше текущего) и дальше только копируемые (LRU до `max`, не больше `buildPerFrame` новых за кадр;

  состоянию, `refresh` сбрасывает куски вокруг тайла (прицел отдаляет камеру — раньше тысячи заливок
  тайлов на кадр давали фриз). Пешки и тела — спрайты из `PawnCache` (один раз на внешность, сторону и
  уровень масштаба, дальше `drawImage`; `PAWN.cache`), мебель — так же (`FURNITURE.cache`); уровни —
  `perOctave` на удвоение (`core/spriteCache.ts`: `scaleLevel`, `LruCache` — вытесняются давние, кэш не
  сбрасывается целиком). Туман — две заливки прямо на экран (без полноэкранного холста),
  следы — без `save/restore` и новых строк цвета, их не больше `COMBAT.decals.max`, цвета тайлов —
  hex. Новую отрисовку в цикле по сущностям — без `save/restore`, градиентов и сборки строк на кадр.
- **Подавление огнём** (`config/tactics.ts` `SUPPRESS`, `Character.suppress` 0..1): пуля, прошедшая
  ближе `radius` от персонажа другой стороны (`CombatSystem.nearMiss` по отрезку полёта за тик, раз на
  пулю — `Bullet.pressed`; вес ствола `Bullet.press`), взрыв (`blastReach` радиусов) и попадание
  (`press`) прижимают; держится `hold` с, спадает `decay`/с. Конус шире (`spread`), прицел медленнее
  (`aimSlow`), реакция ИИ дольше; с `pinned` NPC стреляет вслепую короткими очередями (`blindBurst`), не
  идёт вперёд (капт — `coverLeft` стоит), граната в прижатую цель — × `TACTICS.grenadeMul`. Игроку —
  тёмные края (`RENDER.suppressVignette`, `Game.drawCondition`), дрожь и щелчок пролёта (`Fx` `whiz`,
  `GunfireAudio.whiz`, `AUDIO.whiz`).
- **Присед** (`CROUCH`, `Character.crouch`; игрок — C, бег встаёт; NPC — `updateNpcs`): скорость ×
  `speedMul`, конус × `spreadMul`, прицел быстрее, в ноги реже (`rollZone(…, legMul)`). Низкое укрытие:
  у присевшего бетонный блок ближе `coverReach` на линии огня держит пулю с шансом `coverStop` (запись
  входов луча в блоки — `barrierAt` в `bullet`); присевший за блоком не виден дальше `hideMinDist`, пока
  не выстрелил (`lastFired`, `CombatSystem.concealed` — в `Gunner.acquire` и туман игрока). Пешка ниже
  (`squash` по вертикали к ступням).
- **Тяжёлое ранение** (`DOWNED`, `Character.downedUntil/downedAt`, `downed`, `fit` — жив и на ногах):
  смертельный урон — `down()`: лежит `time` (20) с, `health` 1, не стреляет (`busy`), не угроза
  (`threat`), пули поверх (в него — только прицельно, в своего лежащего — никогда; выпущенные до падения
  — мимо), физика и `Mover` его не замечают; истёк — смерть от ранившего (`bledOut`). Сразу насмерть:
  голова без шлема (`damage(…, instant)`), взрыв ближе `blastInstant` радиуса, урон сверх `overkill` ×
  макс. здоровья; кровотечение до нуля — тоже падает. Любой урон по лежащему добивает (`finished`).
  Поднять (`canRevive/startRevive/finishRevive`, игрок — E): свой с бинтом/аптечкой `reviveTime` с
  (медик `isMedic` — × `medicMul`, здоровья × `medicHp`), встаёт с `reviveHp`/`kitHp`, хромает; медики
  через `heal` поднимают сразу. Тащить (`startDrag/stopDrag`, игрок — X): `dragDist` позади,
  скорость × `dragSpeed`. ГО — `startRevive(…, arrest)`: `cuffTime` с, ствол отобран, `hostile` снят,
  `law.arrest`; задержанные (`inCustody`) — не цель. Добивание — `Gunner.wantsFinish`: раз за падение
  на сторону (`finish`: OTA, повстанцы, ГО — только на фронте). Счётчики: `downs`, `revives`,
  `finished`. Отрисовка — `EntityRenderer.downedBody` (лужа, пешка на боку, кольцо-таймер), подпись
  «тяжело ранен · N с», экран игрока — красные края и надпись. В войне и арене считаются только `fit`.
- **Тактика ИИ** (`ai/Tactics.ts`, `TACTICS`; `Tactician` у `CpBrain`, `OtaBrain`, `RebelBrain`,
  `ArenaBrain`): `fight(…, home, leash, zones)` — `findCover` из `sample` проб в `search` px: **угол**
  (врага не видно, в `peekDist` px сбоку — видно: `hide` → `peek` на очередь → назад, прижат — сидит
  дольше, перезаряжается за стеной) или **блок** (`blockToward`; сидит, `suppressive` — очереди по месту,
  где видели врага); не у своих (`claims`, `spacing`), не дальше `leash` от поста/места боя; засвечено —
  пересмотр (`rethink`, `exposedRecheck`); цель помнит `memory` с (`Gunner.memory`). `rescue` — свой
  тяжелораненый в `helpRange`: подбежать, на виду у врага — оттащить (`safeSpot`), поднять (один
  спасатель — `rescuers`). `detain` — ГО в городе стабилизирует лежащего врага и ведёт в КПЗ (`escort`).
  **Колонна** (`columnSpot`/`followColumn`/`watchSector`): след ведущего — крошки через `stack.crumb`, k-й
  на `k × gap` по следу, стоя смотрит в свой сектор. Ведомые PCU — колонной за ведущим (`FOLLOW`,
  `columnIndex`); на капте звено (`RebelBrain.pointman`: глава-NPC или младший по номеру) — ведущий
  у входа в шорт/лонг ждёт, пока звено выстроится (`teamStacked`, `stackWait`, не дольше `stackMax`),
  «Заходим!» — остальные идут следом (`inColumn`), прошли — каждый своей полосой; звено, чья очередь не
  бежать, давит огнём по постам (`suppress`). Арена — колонной за первым боеспособным NPC. У КПП укрытия
  повстанцев — только на пустоши и в КПП (`FRONT_ZONES`).
- **Реплики** (`systems/Barks.ts`, `config/barks.ts`): контакт, перезарядка, ранен, убил, потеря
  своего (видит тело), «вперёд» на перебежке в капте; на улице — бытовое, а если у КПП бой — о границе
  (`ai/streetBark.ts`). Откат у каждого, говорящего не перебивают.

### Война на границе (`systems/WarSystem.ts`, `ai/brains/RebelBrain.ts`, `config/war.ts`)
- Фронт = пограничный КПП из **двух отдельных дворов-точек**, как «война на D» на UnionRP: «Запад» —
  D3 → D4, «Восток» — D5 → D6 (`WAR.pointNames`), между ними шорт и лонг (`Front.short/long`,
  `shortZone/longZone`). `buildFronts` находит части по зонам: двор с воротами к пустоши — внешний,
  с воротами к городу — внутренний, из двух проходов ближе к оси ворот — шорт. `DPoint`: зона, посты,
  пол (от входа), центр. Пустошь 14 тайлов с завалами; гарнизон — спецназ SU.03 на всех постах
  (2 во внешнем дворе, 3 во внутреннем) + медик SU.02 в бункере. Проходная (`Front.gatehouse`,
  узнаётся по концу имени зоны `ZONE_NAMES.gatehouse`) — не часть точек D: там 2 RCT.PCU (роль `gate`,
  `Front.gatePosts`, проверяют входящих), `Front.apron` — за её дверью, в городе. `sectionAt` (0 — внешний двор,
  1 — шорт/лонг, 2 — внутренний), `pointAt`, `pointOfPost`. Разметка на полу — `drawPoints`.
- Ритм фронта «сбор → капт»: армия сопротивления приходит из лагеря тропой (этап 7) и собирается на
  пустоши вне видимости постов (`RebelBrain` режим `gather`, `pickGather`, `WAR.gatherDist`) — не
  лезет под огонь по одному. Собралось ≥ `capture.minAttackers` — все разом идут на капт очередной
  точки. Новых отрядов у КПП не появляется.
- `war.active(f)` — стреляли у КПП за `activeWindow` с: указатели на КПП у края экрана
  (`EffectsRenderer.drawFrontMarkers`, с именами точек и их состоянием), перестрелку слышно из города.
- **Капт точки** (`WAR.capture`, `startCapture`/`endCapture`/`updateCapture`): точки берутся по
  очереди (`Front.held` — сколько, с внешней, у повстанцев). Капт на `duration` с; **во время капта
  подкрепления ГО не выходят, новые отряды повстанцев не подходят**. Повстанцы в режиме `capture`
  идут перебежками по двору штурмуемой точки (`coverAt` по `DPoint.floor`): укрытие на доле пути
  `advance`, `coverWait`, `advanceStep`, под огнём — `shootStop`/`dash`. **Не одной толпой**:
  `RebelCommand.formTeams` делит штурмующих на звенья по `capture.teamSize` (глава с HYDRA — звено 0;
  подошедшие позже — в самое малое звено). У звена своя полоса двора из `lanes` (поперёк оси вход →
  центр, `lateralOf`), свой проход во внутренний двор (чётные — шорт, нечётные — лонг; без звена —
  `longChance`), точки маршрута у каждого свои; перекаты — каждые `bound` с бегут чётные или
  нечётные звенья (`boundTurn`), в проход звено входит в свой такт. Укрытие, точка сбора и точки
  маршрута — не ближе `spacing` к цели другого штурмующего (`takenSpots`, `crowdAt`). Клич NPC-главы
  двигает звенья до его рубежа своими полосами (без очереди перекатов), за игроком-главой бегут
  врассыпную (`COMMAND.rally.spread`). Внешний двор взят — сбор уже в
  нём (вне видимости постов внутреннего), а на штурм внутреннего идут и державшие внешний
  (на постах остаётся `keepOnHeld`). Капт начинается, когда у КПП ≥ `minAttackers` бойцов его отряда
  (отходящие в лагерь не в счёт). Итог: защитников на точке не осталось — гарнизон
  (`capture.defenders` — часовые её постов, OTA на них, у внутренней ещё медики) перебит, ГО и OTA
  во дворе нет, а штурмующие уже во дворе — точка взята сразу; или `killsToWin` убийств с перевесом;
  штурмовавшие держат её посты (`hold`), лишние — назад на сбор; все штурмующие погибли — отбит; по
  таймеру (`duration` 60 с) — захват при ≥ `minKills` и перевесе. Захват точки — точка тревоги у
  проходной (код не меняется). Обе точки — **КПП прорван** (`breach`, `owner = 'rebels'`); тогда
  сильнейшие (`capture.gateHold`: до `count`, от `minHp` HP — `holdGate`) встают у углов проходной и
  перед ней (`gateSpots`: анкеры в `radius` px от двери на проспект с ≥ `minWalls` сплошных тайлов
  вокруг) лицом к проспекту (`orderHold(post, face)`) и отстреливают выходящих из города. В лонге
  блоков нет; завалы в полосе пустоши шаблона (`CHECKPOINT_OUTLANDS_W`) — зона пустоши.
- **Цитадель**: погибшие ГО и OTA возвращаются у ворот Нексуса (постоянный состав) — не сразу
  (`ROSTER.respawn`: ГО 60 с, OTA 90 с, иначе гарнизон восполняется быстрее, чем повстанцы
  закрепляются) — и бегут на свои посты (`GUARD`: дальше `LAW.cpRunToPost` — бегом); часовые КПП, где идёт капт, ждут его конца.
  Захваченную точку отбивают контрудары резерва OTA (`counterattack`: через `counterDelay` с, потом
  раз в `retakeEvery` — `retakeOta` свободных OTA на посты ближней к городу захваченной точки,
  `OtaBrain.assignPost`). Точка отбита, когда в её дворе (и ближе к городу) нет повстанцев, а ГО уже
  там, `retakeCalm` с (не раньше `holdTime`). **OTA — туда, где сопротивление** (`WAR.ota`,
  `deployOta`, `rebelsAtFronts`): раз в `every` с резерв и OTA с тихих КПП уходят на КПП, где
  повстанцев (во дворах и на пустоши) ≥ `minRebels` и больше всего, — до `perFront` на посты ближайшей
  к пустоши точки Альянса; во время капта этого КПП не выходят. На тихом КПП без захваченных точек —
  в резерв. Все точки D у повстанцев (`cityPush`) — OTA уходят держать Цитадель; при красном коде
  контрударов нет (штурм отбит — снова идут).
- **Граждане к прорванному КПП** (`WAR.defect`, `updateDefection`, `ai/brains/DefectorBrain.ts`): раз в
  `every` с не-лоялист бежит к КПП (чуть медленнее «бега» — чтобы ГО не остановил; от ГО — бегом),
  в коридоре становится повстанцем (`defect`: MP7, розыск, держит пост). Не больше `max` бегущих,
  `perBreach` за прорыв, граждан не меньше `minShare` от начального числа; КПП отбит — бегущие
  возвращаются к жизни. Игрок-гражданин/ГСР в коридоре прорванного КПП — E (событие `defected`).
- **Выход в город**: только когда **все точки D** (оба КПП) у повстанцев (`cityPush`): на каждом КПП
  остаются держать посты `holdKeep`, остальные — `assault` через внутренние ворота. Боец в `assault`
  (или при `cityPush`) в городе → прорвавшийся (`infiltrators`; из отряда фронта исключён навсегда —
  `RebelCommand` не возвращает режимы `storm`/`infiltrate` в `f.squad`, иначе приказ повторялся каждый
  тик и боец стоял) → при `cityPush` — КРАСНЫЙ КОД (только штурм Нексуса): комендантский час, раздача
  закрыта, **никто не возрождается** (`RosterSystem`, игрок — `Game`, крематор; выборы Администратора —
  после отбоя, `ElectionSystem.owed`),
  патрули PCU прочёсывают город по данным «Надзора» (`lastKnown`); OTA по городу не ходит — держит
  Цитадель (OTA с постов КПП — домой). **Мобилизация** (`WAR.mobilize`, `updateMobilize`): все ГО с
  постов (часовые и медики КПП, RCT проходных и города, кладовщик, экипаж конвоя, охрана склада, кроме
  `depotKeep` часовых) получают место обороны Нексуса (`CpBrain.rally` — поверх поста, состояние
  `guard`; места — `nexusSpots`: якоря зоны Нексуса через `spacing` px, ближе к воротам — раньше,
  лицом к воротам); командование, охрана и инспекторы — при своих; отбой — все назад. Повстанцы на
  КПП при красном коде оставляют `rebelKeep` (0) вместо `holdKeep` — остальные на штурм. Граждане
  уходят в подъезды/дворы (`shelters`). Отбой — прорвавшихся нет `calmToGreen` с (не раньше
  `redMinTime`): КПП ещё у повстанцев — код жёлтый (`declareYellow`: штурм отбит, возрождение и
  контрудары снова идут), иначе зелёный; через `redMaxTime` прорвавшиеся «уходят в подполье».
  `forceAssault` — для тестов.
- **Штурм Нексуса** (`WAR.nexus`, `updateNexus`, режим `storm`) — цель выхода в город. При `cityPush`
  бойцы в `assault` сначала собираются во внутреннем дворе прорванного КПП (`staged`); собралось
  `waveSize` (или ждали `stageMax` с и собралась треть идущих, или `stageHardMax` с) — **волна** (`nexus.wave`): все разом через проходную к Нексусу,
  в городе — `storm` (перебежками к зоне Нексуса, внутри меняют позицию не кучей, раненые не
  отходят; дальше `alleysUntil` px от ворот — переулками: проспект и площадь в A* дороже в
  `alleyCost` раз — `Mover.avoidCost`, чтобы не идти под огнём по открытому проспекту); внутри доля
  `huntAdmin` идёт прямо на Администратора. В зоне Нексуса ≥ `minAttackers` штурмующих и не меньше защитников (боеспособных: раненые ниже
  `COMBAT.woundedFraction`, отошедшие перевязываться, не в счёт) — захват
  копится `captureTime` с (иначе убывает); **Нексус захвачен и Администратор мёртв** (`adminAlive`) —
  **победа восстания** (`rebelVictory`: событие `victory`, повстанцы — `withdraw`, код зелёный,
  игрокам-повстанцам `reward`; через `restartDelay` с — событие `restart`: `Game` на следующем тике
  генерирует новый город, роль игрока прежняя); повстанцев в Нексусе не осталось — отбит.
  Табло — `CaptureBar`.
- **Терминал кодов тревоги** (POI `code_terminal`, символ `T` шаблона Нексуса — у стены кабинета
  Администратора; `ui/CodePanel`, `WarSystem.setCode`): E рядом (`WAR.terminal.reach`) — панель:
  1 жёлтый, 2 красный, 3 отбой. Доступ — Администратор и ГО с ранга `terminal.minCpRank` (OFC).
  Код с терминала (`manualCode`) держится, пока его не снимут (автоматический отбой не действует),
  но автоматическая эскалация до красного работает; погиб или разжалован включивший — снова по
  обстановке. Экран терминала — цвета кода, мигает, если код с терминала.
- Нападение «в городе» (тревога, эскалация до красного) — только если и цель, и стрелок в городе:
  огонь с постов КПП по проспекту — это фронт. `war.reinforcements = false` — тесты без контрударов.

### Канализация и сопротивление (`systems/UndergroundSystem.ts`, `systems/InsurgencySystem.ts`, `config/underground.ts`)
- Люк: E в радиусе `UNDERGROUND.useRadius` → `climbTime` с на месте → у парного люка на другом
  уровне (`climb` ставит на свободный якорь, без интерполяции). NPC ходят через люки `HatchTravel`:
  `route` выбирает пару люков по сумме «сюда → люк» + «люк → цель».
- Люков два (в запретной зоне у края), пользуются ими только партизаны и спецагент (`UndergroundSystem.canUse`).
  Схрон: `ROSTER.partisans` (3) партизана (`UndergroundBrain`) и `ROSTER.agents` (2) спецагента
  (`AgentBrain`, роль `agent`, `InsurgencySystem.agents`; `agent` — первый) — постоянный состав; тайник (E: патроны к своим стволам,
  `refillAmmo`), игрок-партизан и игрок-спецагент появляются здесь.
- **Личина** (`Character.cover` — фракция, юнит, профессия, имя; `entities/cover.ts`: `apparentFaction`,
  `coverAuthority`, `displayName`): партизан всегда под личиной горожанина или ГСР
  (`InsurgencySystem.giveCover`, `PARTISANS.cwuCoverShare`), подпись и внешность — по личине. Под
  личиной ствол в кармане, приказу ГО подчиняется (`ai/comply.ts`), от ГО не бежит; проверка CID
  раскрывает с шансом `PARTISANS.checkReveal` (в розыске — всегда). Ствол в руках и ранение личину не
  снимают (ранивший под личиной не получает `hostile`) — только убийство (`CombatSystem.kill` →
  `reveal`, за убитого из Альянса — `hostile` и розыск); ствол в руках — всё же нарушение `weapon`.
  Подпольщик под личиной без `holdFire` сам берёт цели из Альянса (`Gunner.acquire`, `covert`).
  Подпольщики и спецагент начинают с «чистыми» документами (не в розыске). Вернулся в схрон раскрытым или
  в розыске — через `PARTISANS.newPapers` с новые документы и личина; в тайнике — гранаты до
  `cacheGrenades`. Возрождение долгое:
  `ROSTER.respawn.partisan` 300 с, `agent` 600 с.
- Вылазки раз в `outingEvery` (в убежище остаётся ≥ `minAtBase`): обход тоннелей до люка, поход
  на рынок, разведка в город через люк (1–2 бойца, режим `outing`). Разведчик скрытен: огонь не
  открывает (`Gunner.holdFire`), заметил ГО — уходит вниз; отвечает, только если ранили.
- Операции раз в `opEvery` (у каждого свободного подпольщика — своя, `InsurgencySystem.ops`; на дело идёт
  только под личиной и не в розыске; доли — `PARTISANS.ops`): **взлом КПЗ** (`startJailbreak`: быстрым
  шагом `briskWalk` через люк в Нексус к занятой камере или клетке — `occupiedCell`: свои первыми, иначе
  где больше сидящих; товарищ сидит — взлом с шансом `rescueChance`; пока шёл, выпустили — к другой,
  КПЗ пуста — ждёт у камер `jailWait` с; у двери `jailReach` px — `agent.breakTime` с → `jailbreak`, у
  двери оставляет растяжку), **минирование** (`startMine`, `mineSpot`: свежее тело сотрудника Альянса
  без оцепления, у ворот Нексуса, у выхода проходной КПП, на пути патрульного — из двух случайных
  ближнее к люку), **ствол бандиту** (с шансом `PARTISANS.armChance`: партизан через люк к
  бандиту — `armable`, вплотную `armBandit`: MP7 и патроны, мозг `HiredGunBrain` — ищет патрульного ГО
  в городе, в `hired.engage` px достаёт ствол, `hostile` и розыск, стреляет; время `hired.time` или
  ранен — прячет ствол, прежний мозг) или **саботаж** (боец через люк к узлу Альянса, `sabotageTime` с).
  Раненые и закончившие — к ближайшему люку и вниз. Связь сопротивления видна только игроку-повстанцу.
  Игрок-партизан — E перед бандитом.
- **Группы (ячейки)** (`UndergroundGroup`, `InsurgencySystem.groups/groupOf/formGroup`, `PARTISANS.group`):
  на дело вдвоём-втроём, у каждого роль (`GroupRole`: `lead` — делает дело, `cover` — прикрытие рядом,
  `lookout` — дозор), общие сигналы `attack` и `alarm`. **Саботаж** — второй дозорный (`UndergroundBrain`
  режим `cover`, `lookoutRing`): видит ГО ближе `watch` px — «шухер» (`groupAlarm`), все уходят.
  **Взлом** — второй прикрывает у камер (`coverRing`). **Засада на конвой ГО** (`ambush`, доля
  `ops.ambush`, `startAmbush`, режим `ambush`): все свободные (до `ambush.size[1]`) берут в схроне
  автомат (`weapon`), идут к месту на пути колонны (`ambushSpot`: доля `along` от склада к пункту, не у
  Нексуса и КПП), остальные держатся рядом с ведущим; собрались (двое в `huddle` px) и колонна на марше
  ближе `intercept` — наперерез, ближе `engage` и на виду — сигнал (`groupAttack`: личина снята,
  `hostile`, розыск, тревога), огонь первым делом по носильщикам; брошенные ящики — забрать
  (`lootCrate`: патроны или гранаты), бой не дольше `fight` с, потом к люку. `allies` — задел под банды и
  мафию (союзники группы со стороны).
- **Допрос** (`PARTISANS.interrogation`, `InsurgencySystem.interrogate`): CMD.EPU (у него в `nextDuty`
  место перед занятой клеткой) раз в `every` с — вопрос, стон пленного и урон (не ниже `minHealth`);
  через `time` с пленный раскалывается и выдаёт другого подпольщика или спецагента (личина снята,
  розыск). **Рейд** (`PARTISANS.raid`, `startRaid`): двое (`raid.caged`) партизан в клетках одновременно — часовые
  КПП (`CpBrain.raidPost`, `postOf`) и свободные OTA (`assignPost(-1, …)`) идут к лагерю
  сопротивления на `duration` с; один рейд на каждый такой раз.
- **Спецагент** (`AgentBrain`, `PARTISANS.agent`): из схрона раз в `rest` с — миссия (`missions`):
  свой в камере — почти всегда взлом (`rescueChance`), после взлома — растяжка у двери;
  **покушение** на Администратора и высоких чинов (`pickTarget`: Администратор, CMD.EPU, инспекторы,
  офицеры), **взлом** камер КПЗ и клеток (`jailbreak` → `breakCell`, тревога), **бунт**
  (`startRiot`: до `riot.count` горожан — не лоялистов — в `radius` px переходят в состояние `riot`
  `CitizenBrain`: мечутся вокруг точки и кричат лозунги `riot.time` с; нарушение `riot`; тревога).
  Перед покушением и взломом переодевается: форма свежего (`corpseFresh`) тела ГО (`dressAs`,
  `Corpse.stripped`; в OTA — никогда: ни тело OTA, ни шкаф); в форме ГО его не проверяют. Свежего тела
  нет — идёт под гражданской личиной (`goUndressed`; «по наряду» без формы — бунт). Миссия — не дольше
  `agent.missionMax` с, точка миссии запомнена (`missionAt`), встал рядом — засчитано, далеко — путь
  заново. Раскрывает только убийство (`revealAgent` — вручную: `hostile`, розыск); в схроне — новые
  документы. **Парой**: на покушение и взлом свободный второй спецагент идёт прикрытием (`joinBackup`,
  `backup`/`partner`): переодевается, держится в `agent.backupGap` px за ведущим, ведущий открыл огонь —
  тоже огонь; ведущий ушёл — и он к люку. Игрок-спецагент: E у тела ГО, у занятой
  камеры/клетки; G — бунт (откат `riot.cooldown`).
  **Выпустили из КПЗ** (`LawSystem.onReleased` → `InsurgencySystem.released`): подпольщику возвращают
  документы (гражданская личина, не в розыске) и он бросает дело — в схрон (`retreat`); иначе ГО у
  ворот Нексуса тут же узнавал бы его снова. Под личиной не бегает от ГО, даже «без CID» (поддельная),
  ствол в кармане, пока огонь запрещён (`holdFire` — и на саботаже, у барыги, по дороге домой), домой —
  быстрым шагом (`briskWalk`, бег — нарушение). **Взлом КПЗ** — только если там кто-то сидит,
  вызволять своих — с шансом `rescueChance`, после любого взлома (и агентов) — пауза `jailCooldown` с.
- Узлы Альянса (`EconomySystem.nodes`: терминалы у стен на проспектах и площади) ломаются только
  от саботажа; чинит ГСР (дороже щитка). Игрок-повстанец саботирует сам (E), награда `sabotageReward`.
- **Тревога** (`WarSystem.raiseAlarm(x, y, what, yellow)`): саботаж, ранение сотрудника Альянса в
  городе (`CombatSystem.onDamage`), побег, бунт, донос, сканер, захват точки КПП — точка тревоги
  (`alarmActive`: патрули рядом прочёсывают и при зелёном коде), код не меняется. **Код жёлтый — только
  когда ГО, OTA или Администратор увидел тело убитого ГО в городе** (`scanCorpses` раз в
  `ALARM.corpseScan` с, один раз на тело). Тогда же — **место преступления** (`systems/CrimeScenes.ts`,
  `war.scenes`, `CRIME.scene`); его открывают и для **убитого гражданского** (горожанин, ГСР, вортигонт —
  `SceneKind` `civil`, только точка тревоги, код не меняется). **Оцепление по клеткам** (`cordon`): пол в
  `radius`/`civilRadius` px от тела, связный с ним (стены и двери не пересекает) — `cells`; клетки края,
  за которыми ещё пол, — проходы; группы клеток края — линии (`CordonLine`, `line`): по углу вокруг тела
  (разрыв — в самом большом промежутке), концы — до грани стены. Линия до `tapeMax` px — **лента прямо от
  стены до стены** (край с изломом дальше `bend` px от хорды — делится на ленты по проходам); длиннее
  (улица, проспект) — ряд **переносных барьеров** вдоль края (`barrier`). Рисует
  `EffectsRenderer.drawScenes`/`drawBarriers` (лента в полоску с креплениями у стен; бело-красные доски
  на опорах). За оцепление не пускают мирных (выталкивает к ближайшему месту за ним — `outside`), тело не
  обыскать (`sealed`). Из `seek` px идут следователь SU.01 (`CpBrain` состояние `scene`, роль `investigate`:
  осмотр `scanTime` с → `crime.investigate`, убийца в розыск) и **медик SU.02** (роль `examine`: у тела
  на корточках с блокнотом — `Character.notepadUntil`, `drawNotepads` — `examTime` с, реплики, потом
  **накрывает тело белой простынёй** — `examined` → `cover`, `Corpse.covered`: рисуется только простыня,
  тело лежит ещё `coveredKeep` с); к телу ГО — ещё офицер PCU.OFC или инспектор SU.INSP (роль `guard`:
  стоит у края оцепления — `edge` — лицом наружу). Отвлеклись на бой — возвращаются (`SCENE_RESUME`);
  погиб следователь или медик — присылают другого. Снимают через `holdAfter` с после обоих осмотров,
  через `maxTime` с или когда тело увезли; **крематор** ждёт снятия и забирает накрытое тело. **При
  красном коде оцеплений нет** (`open` отказывает, `closeAll`). Лента держит только мирных (горожане, ГСР, вортигонты — `CORDONED`). Без оцепления **бандиты обирают
  тела ГО с оружием** (`CRIME.loot`, работа `loot` в `CitizenBrain`, когда ГО не видно). Нападавшие → `war.operatives` (ушли под землю — след
  потерян), точка тревоги держится `ALARM.pointTime`. Патрули в `respondRadius` → «hunt»: не толпой в
  последнюю известную позицию / точку тревоги, а прочёсывание вокруг неё (`CpBrain.sweep`, `LAW.hunt`:
  у каждого своя точка не ближе `spacing` к точкам других, осмотрелся — следующая); проверки CID чаще (`LAW.alarmCheckMul`). Отбой — `calmToGreen`
  без известных нападавших (не раньше `minTime`); до красного жёлтый сам не растёт.
- Чёрный рынок (прилавок в канализации, торговец — `PostBrain`): оружие и патроны
  (`ECONOMY.blackMarket.stock`), скупка трофеев и рационов (`sell`), поддельная CID (снимает розыск).
- ИИ без «глаз на спине»: `Gunner.acquire` — только в угле обзора `VISION.npcFovDeg` или вплотную;
  ранили / выстрел врага рядом → через реакцию поворот в примерную сторону (`COMBAT.ai.alert*`);
  мозги зовут `gunner.look` последним, чтобы бой и тревога перебивали дежурный взгляд.

### Этап 5: лояльность, чат, карты, сохранение (`config/loyalty.ts`, `config/chat.ts`, `config/minimap.ts`, `config/save.ts`)
- **Лояльность** (`Character.loyalty`, только граждане и ГСР — `hasLoyalty`): + за полученный рацион,
  пройденную проверку, работу ГСР, донос, поощрение ГО; − за штраф, арест, оскорбление, ложный донос.
  Уровни (`LOYALTY.tiers`): неблагонадёжный → гражданин → лоялист → образцовый: множитель плановых
  проверок CID (`checkMul`), надбавка к рациону, скидка в магазине ГСР (`EconomySystem.shopPrice`).
  Граждане-лоялисты (от `LOYALTY.uniform.min`) — в светло-фиолетовой форме и с такой же подписью
  (`isLoyalistUniform` в `EntityRenderer`).
- **Чат** (`ChatSystem.submit`, ввод — `ui/ChatBox`, Enter или «/»): речь — реплика и строка журнала
  (вид `chat`); ГО, который видит, на оскорбление (`CHAT.insult`) требует документы — нарушение
  `insult`, штраф; на приветствие отвечает прохожий. Команды: /me, /r (рация ГО), /roll, /cid,
  /донос (виден повстанец/вооружённый/в розыске: повстанец — тревога, иначе патрульный идёт
  разбираться), /поощрить (ГО), /помощь.
- **Карты** (`ui/MapView`): мини-карта в углу и большая карта (M) уровня игрока, собираются из тайлов
  один раз; канализация открывается по мере исследования (повстанцам — сразу), люки — найденные.
  Маркеры: КПП (бой/капт/захвачен), Нексус, раздача, магазин, сломанные узлы, тревога, свои.
- **Сохранение** (`SaveGame`, localStorage `SAVE.key`): роль, имя, деньги, лояльность, здоровье,
  сытость, инвентарь и оружие, статус CID, позиция, знание карты; seed карты. Автосохранение раз в
  `SAVE.interval` с, при выборе роли и закрытии вкладки. Без ?seed (или с тем же seed) игра
  продолжается; «Новая игра» (в главном меню — экран подтверждения, в меню роли — второе нажатие; `window.confirm` в песочнице не работает) стирает сохранение. Задержанный сохраняется в розыске.
- **Пауза** — P. **Меню** (`ui/GameMenu`): главное при запуске (продолжить / играть, новая игра,
  управление, звук) и пауза по Esc (продолжить, сохранить, сменить роль, управление, звук, выйти в
  главное меню — с сохранением). Пока меню открыто, мир стоит. Esc сначала закрывает открытые панели
  (`Game.onEscape`, перехват до остальных обработчиков); список клавиш — `CONTROLS_HELP` в `HelpBar`.

### Этап 6: профессии (`config/professions.ts`, `config/labor.ts`, `config/crime.ts`, `config/cpUnits.ts`)
- `Character.profession` (`ProfessionId`), `PROFESSIONS` — описание, умения (для `RoleMenu`), набор;
  `DEFAULT_PROFESSION`, `professionsOf(faction)`. Сохраняется в `SaveGame` (`role.profession`).
  Одежда по профессии — `PAWN.professionOutfits`. Новая фракция `vort` (вортигонты: без лояльности,
  ГО их не проверяет, `LawSystem.checkable`).
- **Цепочка снабжения ГСР** (`LaborSystem`): фасовщик собирает коробки в цехе штаба ГСР — у каждого
  своё место у конвейера (`stations`, `claimStation`/`releaseStation`; на старых картах без штаба —
  одно место у заводского двора промзоны), `packStep`; курьер носит их со склада цеха
  (`factoryStore`) к будке (`takeBox`/`deliverBox`, `Character.carrying`), склад будки
  `EconomySystem.rationStock` расходуется поваром на раздаче (пусто — `onEmpty`, рацион не выдаётся);
  те же курьеры носят коробки в лавки, ларьки и столовую проспекта (см. «Лавки и товар»).
  Уборщик и вортигонт убирают мусор (`trash`, `cleanStep`), отброс — роется (`search`), медик ГСР
  лечит за плату (`treat`). NPC берут работу в `CitizenBrain.pickJob` по профессии.

  `law.crimeUntil` → нарушение `theft` (и причина ареста в `judge`); жертва может заметить и крикнуть;

  за жертвой чуть быстрее шага (`stalk`, не бег), держась за спиной.
- **Лояльность**: у уровней `perks` (`run` — бег без нарушения, `queue` — очередь впереди, `escort` —
  `/охрана`, BODYGUARD у `CpBrain`).

- **Повстанцы**: в отрядах WarSystem медики (`RebelBrain.medic`) и пиро; партизан — `disguised`
  (`isHostile`/`observe` его не узнают; оружие в руках или проверка — `reveal`).
- **Огонь** (`FIRE`): граната пиро оставляет зону (`combat.fires`), болт поджигает; `ignite` →

  кабинете (работа `office`), иногда обходит цех и комнату отдыха, а ждут соискатели — выходит к стойке

  `hire.time` с → `hire(c, prof)`: берут туда, где рабочих меньше всего не хватает (`hire.needs`,

## Соглашения
- Все числа, цвета, скорости, зарплаты и т.п. — в `src/config/*`. Новый параметр → в конфиг.
- `src/` не использует API Node; `tests/` может (свой `tests/tsconfig.json`).
- Случайность в генерации и мире — только через `Rng` (seed), не `Math.random` (кроме выбора нового seed).
- Логика не трогает DOM; UI подписывается на `EventBus`. Новые события — в `GameEvents`.
- Персонаж игрока и NPC — один класс `Character`; различие только в источнике управления.
- Отрисовка тайлов — в экранных пикселях с округлением (без щелей); подписи — в экранных пикселях.
- Перед коммитом: `npm run typecheck && npm test`.
- Тесты детерминированы: `makeSim` сбрасывает общий набор номеров CID (`resetCids`), иначе случайность
  теста зависела бы от предыдущих тестов файла.
