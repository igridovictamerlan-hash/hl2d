# CLAUDE.md — Сити-17 (HL2RP 2D)

Браузерная 2D-игра с видом сверху в духе HL2RP-серверов Garry's Mod: тесный город из переулков под
контролем Альянса. Все персонажи — цветные кружки с подписью имени/роли. Игрок управляет одним,
остальные — NPC, ведущие себя как игроки RP-сервера.

**Язык:** интерфейс, комментарии и документация — по-русски; идентификаторы в коде — по-английски.

## Команды

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # vitest: генератор, A*, коллизии, JSON, симуляция NPC
npm run typecheck  # tsc для src и tests
npm run build      # typecheck + сборка в dist/
npm run mapstats   # метрики генератора по 30 сидам (DEBUG_GEN=1 — причины отбраковки попыток)
```

Параметры адреса: `?seed=123` (карта по seed, пишется в адрес автоматически), `?map=city17`
(загрузить `public/maps/city17.json`), `?npcs=40`, `?debug=1`.

## Стек и почему без движка

TypeScript + Vite + HTML5 Canvas 2D, без игровых движков. Всё ключевое здесь нестандартное —
генератор переулков, туман войны лучами, A* по якорям 2×2 с учётом радиуса, уступание дороги;
Phaser не дал бы готового для этого, а добавил бы свой цикл, сцену и физику, с которыми пришлось бы
бороться. Логика не зависит от DOM и целиком тестируется в Node (vitest), включая безголовую
симуляцию NPC (`tests/simHarness.ts`).

### Тик логики (`Game.update`, 60 Гц)
1. `PlayerController`: ввод → `player.wantX/wantY`, взгляд на курсор, E/F/1/2/3.
   Задержанному игроку временно ставится `PrisonerBrain` — тогда ввод движения игнорируется.
2. `updateNpcs`: мозги (FSM) → `Mover` выставляет `wantX/wantY`; затем `PathService.process()`.
3. `DoorSystem`: двери открываются, если рядом кто-то есть; закрываются через `DOORS.closeDelay`.
4. `stepPhysics`: разгон → движение → расталкивание по массам → выталкивание из стен.
5. `LawSystem.update`: неподчинение игрока, заведение в камеру, сроки, освобождение.
5a. `EconomySystem` (раздача, голод, зарплаты, поломки) → `CombatSystem` (перезарядка, регенерация,
   уборка убитых) → `WarSystem` (отряды у КПП, подкрепления, прорыв, красный код) → возрождение игрока.
6. Видимость: многоугольник обзора игрока (`VISION.rays` лучей DDA) и `c.visible` у всех.
7. Камера, зоны, UI (DOM обновляется с частотой `GAME.hudInterval`).

Отрисовка (`Game.render`): карта → терминал найма → эффекты на земле (тела, щитки, очередь) →
персонажи (только видимые) → трассеры → туман → подписи и реплики → отладка → виньетка →
красный код/ранение → прицел. Интерполяция `prevX → x`.

### Ключевые понятия
- **Тайл** 16 px. Карта 188×188 тайлов (3008 px). Типы — `world/tiles.ts` (`solid`, `opaque`,
  символ для JSON). Добавляя тип, допишите его в `TILE_DEFS`, палитру `MapRenderer` и `DevPanel`.
- **Якорь 2×2**: персонаж радиусом 12 px занимает квадрат 2×2 тайла. Якорь (ax, ay) ↔ центр в
  ((ax+1)·16, (ay+1)·16). Связность карты, A* и поиск «карманов» работают по якорям — поэтому
  проход 2 тайла (32 px) пропускает ровно одного, 3 тайла (48 px) — двоих.
- **Зоны** — сетка `zoneGrid` (id зоны на тайл) + список `zones` (kind + имя). `ZoneKind`:
  residential, avenue, plaza, nexus, cells, industrial, restricted, checkpoint (пограничные КПП),
  outlands (пустоши за стеной), shop (магазин ГСР).
- **Точки интереса (POI)** — `map.pois` в координатах тайлов: окно раздачи, центр площади, терминал
  найма, ворота и стойка Нексуса, камеры КПЗ, ворота запретной зоны, заводские дворы, посты часовых
  КПП, выходы в пустоши.
- **Двери** — группы соседних тайлов `DOOR`. Состояние (закрыта/заперта) живёт в `GameMap.doorClosed/
  doorLocked`: закрытая перекрывает обзор (`isOpaque`), запертая — ещё и проход (`isSolid`).
  Запирание вызывает `NavGrid.refresh` вокруг двери.
- **Видимость**: `visibility.ts` — луч DDA до первого непрозрачного тайла. Игрок видит в радиусе
  `VISION.radius`; NPC — в `VISION.npcRange` с углом обзора `npcFovDeg` (вплотную — во все стороны).
  Одни и те же функции для игрока и NPC: от ГО можно скрыться за поворотом или за дверью.
- **Фракции и ранги** — `config/factions.ts`. Цвет кружка по рангу (`colorsOf`): ГО от голубого
  (RCT) до тёмно-синего (DvL), повстанцы от оранжевого (новобранец) до жёлто-золотого (командир).
  `authority` — кто проверяет, а не проверяется (ГО, OTA, администратор).

### Генератор (`world/generator/CityGenerator.ts`)
1. `layout`: магистраль по центру (+ вторая с шансом 50%), линии решётки с отступами от проспекта,
   углы запретной зоны и промзоны, площадь на длинном прямом участке проспекта, Нексус рядом.
2. `lattice`: узлы с «дрожанием» (соседи на линии смещены ≥ 3 тайла) → лабиринт «растущее дерево»
   от узлов проспекта + петли (несколько маршрутов). Рёбра вырезаются Z-образно; излом ставится так,
   чтобы прямой участок ≤ 25 тайлов и перемычка не вставала в створ соседних переулков.
3. Вырезание переулков и магистралей, чистка «шипов» (двухфазная — иначе съедаются тонкие стены).
4. Зоны, штампы: площадь с будкой и терминалом найма, Нексус по ASCII-шаблону (`templates.ts`,
   правится руками), кольцо запретной зоны с КПП (позиция ворот подбирается перебором),
   два пограничных КПП на концах главного проспекта (шаблон `CHECKPOINT_TEMPLATE`, восточный —
   зеркальный): пустошь → ворота → коридор 4 тайла с шахматными бетонными блоками-укрытиями
   (`BARRIER`: не пройти, но видно поверх) и бункерами ГО → ворота → проспект.
   Пол коридора (`BUNKER`) не считается «переулком» в метрике прямых участков.
5. `features`: заводские дворы, дворы-колодцы с арками/подъездами, сквозные подъезды и арки
   (только если обход длинный), тупики. Каждая деталь откатывается (`GenGrid.snapshot/restore`),
   если открывает прямой обзор длиннее нормы.
6. `ensureConnectivity`: flood fill по якорям; мелкие фрагменты засыпаются, крупные соединяются
   тоннелем минимальной стоимости (Дейкстра); недостижимые тайлы засыпаются.
7. Метрики и проверка (`validateMap`); до `GENERATOR.validation.attempts` попыток, иначе лучшая.
Генерация детерминирована по seed; ~25–40 мс на попытку.

### Формат карты JSON (`world/mapIO.ts`, версия 1)
`tiles` и `zoneGrid` — массивы строк по символу на тайл (легенда в `legend`), `zones`, `pois`,
`stats`. Карту можно поправить в редакторе с моноширинным шрифтом; при загрузке проверяются размеры
и символы (ошибка с номером строки/столбца), панель F2 показывает связность и прямые участки.

### ИИ NPC
- `Brain` (интерфейс) решает, что делать; каждая фракция — свой класс в `ai/brains/` с
  `StateMachine` (idle, walk, work, patrol, chase, flee, fight, arrested — по мере этапов).
- `Mover` — общее передвижение: запрос пути, следование со «сглаженным» путём, объезд встречных
  по правилу правой руки (но не в стену), распознавание блокировки:
  встречные лоб в лоб → уступает младший по `FACTIONS[*].yieldPriority` (игрок главнее всех),
  при равенстве — тот, кому ближе до «кармана»; стоящего NPC просят отойти; стоящего игрока ждут,
  потом разворачиваются; упёрся в стену — перестраивает путь.
- Цели прогулок — `ai/destinations.ts`; зоны, которых NPC избегают, — через `avoidZones` в A*.

### Закон (`systems/LawSystem.ts` + `ai/brains/CpBrain.ts`)
- Нарушения, заметные ГО (`observe`): бег быстрее `LAW.runSpeed`, запретная зона. Плюс плановые
  проверки CID (на КПП — почти всех в коридоре). Без CID / в розыске — выясняется при проверке.
- Цикл: `order` (стоять; NPC может побежать — шанс по фракции) → ГО подходит → `beginCheck` →
  `judge` → `apply`: отпустить / штраф (`LAW.fines`) / `arrest`. Бег от ГО = неподчинение → арест.
  Игрок, отошедший дальше `LAW.complyRadius` после приказа, — «в бегах».
- Арест: мозг задержанного сохраняется в `law.savedBrain`, ставится `PrisonerBrain` (идёт за
  конвоиром). ГО ведёт к свободной камере (`freeCell`/`reserve`), `putInCell` отпирает дверь,
  задержанный заходит — дверь запирается, срок `LAW.jailTime`. После срока — выход за ворота
  Нексуса и возврат прежнего мозга. Упустил беглеца на `chaseLoseTime` — тот объявлен в розыск.
- Игрок-ГО: F — проверить того, кто перед ним → панель CheckPanel (1 отпустить, 2 штраф, 3 арест);
  арестованный идёт за игроком, у свободной камеры КПЗ заводится автоматически. Беглеца надо догнать.
- Все сообщения — через `bus.emit('log', …)` в журнал событий; реплики — `Character.say`.
- ГО сразу узнаёт повстанца (`observe` → 'rebel'): безоружного задерживает, вооружённого — бой.
  Житель с оружием в руках — нарушение 'weapon'. Красный код: на улице после `WAR.curfewGrace` —
  нарушение 'curfew' (арест). Бег в панике от стрельбы нарушением не считается (`panicUntil`).
- Отряды ГО (`config/factions.ts`, `CP_DIVISIONS`): UNION — патруль, быстрее бег; GRID — гарнизон
  КПП, MP7, G — поставить бетонный блок (до трёх); HELIX — медик, G — лечить, NPC-медики сами
  выходят к раненым; JURY — проверка CID вдвое быстрее, штрафы вдвое выше.

### Экономика (`systems/EconomySystem.ts`, `config/economy.ts`)
- Раздача рационов по таймеру (`ECONOMY.rations`): окно у будки на площади, живая очередь по
  отметкам (`queueSlot`), выдаёт работник ГСР (NPC сам, игрок-ГСР — E). Рацион = паёк + токены,
  раз за раздачу на персонажа. При комендантском часе раздача не открывается.
- Сытость падает у всех; при нуле — урон. NPC едят и перевязываются сами, если есть чем.
- Зарплаты раз в минуту: ГО (с надбавкой за ранг), ГСР — если работал, Администратор.
- Поломки (щитки у стен переулков) появляются по таймеру; ГСР чинит (игроку нужен набор инструментов).
- Магазин ГСР — комната с дверью недалеко от площади (`stampShop`), E у прилавка.
- Предметы и наборы по ролям — `config/items.ts` (`ITEMS`, `WEAPONS`, `KITS`), инвентарь — `Inventory`.

### Бой (`systems/CombatSystem.ts`, `ai/Gunner.ts`, `config/combat.ts`)
- Выстрел — луч с разбросом (больше в движении). Стены и закрытые двери останавливают пулю,
  бетонный блок — с шансом `barrierStopChance` один раз на блок (свой блок у стрелка не мешает).
- Урон × броня фракции; раненый (< `woundedFraction`) отходит; убитый NPC убирается из мира,
  остаётся тело с лутом (E — обыскать). Игрок возрождается через `respawnDelay`, теряя часть токенов.
- `threat(a, b)`: повстанцы стреляют по Альянсу всегда, Альянс — по вооружённым и напавшим.
  Напавший на ГО/OTA получает `hostile` и розыск. Gunner не стреляет, если на линии свой.

### Война на границе (`systems/WarSystem.ts`, `ai/brains/RebelBrain.ts`, `config/war.ts`)
- Фронт = пограничный КПП: пустошь с отрядом повстанцев (3–4, пистолеты/MP7), гарнизон GRID на
  постах + медик HELIX в бункере. Отряды сменяют друг друга — перестрелка почти непрерывная.
- Штурм: часть отрядов (`assaultChance`) через время идёт коридором в город; оголённый пост
  (нет часовых `pushWhenUnguarded` с) — штурм сразу. Потери ГО восполняются подкреплениями из Нексуса.
- Боец отряда оказался в городе → прорвавшийся → КРАСНЫЙ КОД: комендантский час, раздача закрыта,
  из Нексуса выходит OTA, патрули ГО прочёсывают город по данным «Надзора» (`lastKnown`).
  Граждане уходят в подъезды/дворы (`shelters`). Отбой — когда прорвавшихся нет `calmToGreen` с
  (не раньше `redMinTime`); через `redMaxTime` прорвавшиеся «уходят в подполье».

## Соглашения
- Все числа, цвета, скорости, зарплаты и т.п. — в `src/config/*`. Новый параметр → в конфиг.
- `src/` не использует API Node; `tests/` может (свой `tests/tsconfig.json`).
- Случайность в генерации и мире — только через `Rng` (seed), не `Math.random` (кроме выбора нового seed).
- Логика не трогает DOM; UI подписывается на `EventBus`. Новые события — в `GameEvents`.
- Персонаж игрока и NPC — один класс `Character`; различие только в источнике управления.
- Отрисовка тайлов — в экранных пикселях с округлением (без щелей); подписи — в экранных пикселях.
- Перед коммитом: `npm run typecheck && npm test`.
