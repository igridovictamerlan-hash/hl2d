# CLAUDE.md — Сити-17 (HL2RP 2D)

Браузерная 2D-игра с видом сверху в духе HL2RP-серверов Garry's Mod: тесный город из переулков под
контролем Альянса. Все персонажи — цветные кружки с подписью имени/роли. Игрок управляет одним,
остальные — NPC, ведущие себя как игроки RP-сервера.

**Язык:** интерфейс, комментарии и документация — по-русски; идентификаторы в коде — по-английски.

## Команды

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # vitest: генератор, A*, коллизии, JSON, симуляция NPC
npm run typecheck  # tsc для src и tests
npm run build      # typecheck + сборка в dist/
npm run mapstats   # метрики генератора по 30 сидам (DEBUG_GEN=1 — причины отбраковки попыток)
```

Параметры адреса: `?seed=123` (карта по seed, пишется в адрес автоматически), `?map=city17`
(загрузить `public/maps/city17.json`), `?npcs=40`, `?debug=1`.

## Стек и почему без движка

TypeScript + Vite + HTML5 Canvas 2D, без игровых движков. Всё ключевое здесь нестандартное —
генератор переулков, туман войны лучами, A* по якорям 2×2 с учётом радиуса, уступание дороги;
Phaser не дал бы готового для этого, а добавил бы свой цикл, сцену и физику, с которыми пришлось бы
бороться. Логика не зависит от DOM и целиком тестируется в Node (vitest), включая безголовую
симуляцию NPC (`tests/simHarness.ts`).

### Тик логики (`Game.update`, 60 Гц)
1. `PlayerController`: ввод → `player.wantX/wantY`, взгляд на курсор, прицел (ПКМ), огонь, смена оружия, E/F/1/2/3.
   Задержанному игроку временно ставится `PrisonerBrain` — тогда ввод движения игнорируется.
2. `updateNpcs`: мозги (FSM) → `Mover` выставляет `wantX/wantY` → `dodgeGrenades` (граната рядом —
   бегство поверх решения мозга); затем `PathService.process()`.
3. `DoorSystem`: двери открываются, если рядом кто-то есть; закрываются через `DOORS.closeDelay`.
4. `stepPhysics`: разгон → движение → расталкивание по массам → выталкивание из стен.
5. `LawSystem.update`: неподчинение игрока, заведение в камеру, сроки, освобождение.
5a. `EconomySystem` (раздача, голод, зарплаты, поломки) → `CombatSystem` (перезарядка, регенерация,
   уборка убитых) → `WarSystem` (отряды у КПП, подкрепления, прорыв, тревоги) → `InsurgencySystem`
   (гарнизон убежища, операции) → возрождение игрока.
6. Видимость: многоугольник обзора игрока (`VISION.rays` лучей DDA) и `c.visible` у всех.
7. Камера (в границах уровня игрока; сменил уровень — `snapTo`), зоны, UI (DOM — с частотой `GAME.hudInterval`).

Отрисовка (`Game.render`): карта → терминал найма → эффекты на земле (тела, щитки, очередь) →
персонажи (только видимые; нос-треугольник — взгляд, силуэт оружия по классу) → конусы NPC →
трассеры и взмахи дубинки → туман → конус игрока → подписи и реплики → отладка → виньетка →
красный код/ранение → указатели на КПП → прицел. Интерполяция `prevX → x`.

### Ключевые понятия
- **Тайл** 16 px. Город 188×188 тайлов (3008 px), справа за зазором — канализация (94×94, масштаб
  1:2 к городу), вся карта 286×188. Типы — `world/tiles.ts` (`solid`, `opaque`, символ для JSON).
  Добавляя тип, допишите его в `TILE_DEFS`, палитру `MapRenderer` и `DevPanel`.
- **Уровни** (`Level`: city / sewer) — две области одной сетки без прохода между ними; связь только
  люками. `GameMap.underground` (прямоугольник канализации по её зонам), `levelAt`, `levelBounds`;
  `NavGrid.level` по якорям. A* между уровнями сразу отказывает, `randomAnchorAround` берёт цели
  только на своём уровне, камера не выходит за границы уровня, в канализации обзор короче
  (`VISION.sewerRadius`), выстрелы с другого уровня не слышны.
- **Якорь 2×2**: персонаж радиусом 12 px занимает квадрат 2×2 тайла. Якорь (ax, ay) ↔ центр в
  ((ax+1)·16, (ay+1)·16). Связность карты, A* и поиск «карманов» работают по якорям — поэтому
  проход 2 тайла (32 px) пропускает ровно одного, 3 тайла (48 px) — двоих.
- **Зоны** — сетка `zoneGrid` (id зоны на тайл) + список `zones` (kind + имя). `ZoneKind`:
  residential, avenue, plaza, nexus, cells, industrial, restricted, checkpoint (пограничные КПП),
  outlands (пустоши за стеной), shop (магазин ГСР), sewer, rebel_base (убежище), black_market.
- **Точки интереса (POI)** — `map.pois` в координатах тайлов: окно раздачи, центр площади, терминал
  найма, ворота и стойка Нексуса, камеры КПЗ, ворота запретной зоны, заводские дворы, посты часовых
  КПП, выходы в пустоши, люки (`hatch` в городе / `sewer_hatch` в канализации: якорь 2×2, x,y — его
  левый верхний тайл; пары связаны одинаковым `id`), убежище, тайник, прилавок и место торговца.
- **Двери** — группы соседних тайлов `DOOR`. Состояние (закрыта/заперта) живёт в `GameMap.doorClosed/
  doorLocked`: закрытая перекрывает обзор (`isOpaque`), запертая — ещё и проход (`isSolid`).
  Запирание вызывает `NavGrid.refresh` вокруг двери.
- **Видимость**: `visibility.ts` — луч DDA до первого непрозрачного тайла. Игрок видит в радиусе
  `VISION.radius`; NPC — в `VISION.npcRange` с углом обзора `npcFovDeg` (вплотную — во все стороны).
  Одни и те же функции для игрока и NPC: от ГО можно скрыться за поворотом или за дверью.
- **Фракции и ранги** — `config/factions.ts`. Цвет кружка по рангу (`colorsOf`): ГО от голубого
  (RCT) до тёмно-синего (DvL), повстанцы от оранжевого (новобранец) до жёлто-золотого (командир).
  `authority` — кто проверяет, а не проверяется (ГО, OTA, администратор).

### Генератор (`world/generator/CityGenerator.ts`)
1. `layout`: магистраль по центру (+ вторая с шансом 50%), линии решётки с отступами от проспекта,
   углы запретной зоны и промзоны, площадь на длинном прямом участке проспекта, Нексус рядом.
2. `lattice`: узлы с «дрожанием» (соседи на линии смещены ≥ 3 тайла) → лабиринт «растущее дерево»
   от узлов проспекта + петли (несколько маршрутов). Рёбра вырезаются Z-образно; излом ставится так,
   чтобы прямой участок ≤ 25 тайлов и перемычка не вставала в створ соседних переулков.
3. Вырезание переулков и магистралей, чистка «шипов» (двухфазная — иначе съедаются тонкие стены).
4. Зоны, штампы: площадь с будкой и терминалом найма, Нексус по ASCII-шаблону (`templates.ts`,
   правится руками), кольцо запретной зоны с КПП (позиция ворот подбирается перебором),
   два пограничных КПП на концах главного проспекта (шаблон `CHECKPOINT_TEMPLATE`, восточный —
   зеркальный): пустошь → ворота → коридор 4 тайла с шахматными бетонными блоками-укрытиями
   (`BARRIER`: не пройти, но видно поверх) и бункерами ГО → ворота → проспект.
   Пол коридора (`BUNKER`) не считается «переулком» в метрике прямых участков.
5. `features`: заводские дворы, дворы-колодцы с арками/подъездами, сквозные подъезды и арки
   (только если обход длинный), тупики. Каждая деталь откатывается (`GenGrid.snapshot/restore`),
   если открывает прямой обзор длиннее нормы.
6. `ensureConnectivity`: flood fill по якорям; мелкие фрагменты засыпаются, крупные соединяются
   тоннелем минимальной стоимости (Дейкстра); недостижимые тайлы засыпаются.
7. Метрики и проверка (`validateMap`); до `GENERATOR.validation.attempts` попыток, иначе лучшая.
8. `sewers.addSewers`: карта расширяется вправо; люки в переулках жилых кварталов и промзоны
   (выборка «дальней точки»), сеть тоннелей (решётка → «растущее дерево» + петли; 3 тайла — сток
   посередине, дорожки по бокам), от каждого люка в масштабе 1:2 — ниша с лестницей и сухой ход к
   узлу, убежище с ящиками-укрытиями и тайником, рядом чёрный рынок с прилавком; засыпка мест, куда
   не пролезть. Только добавляет проходимое — связность по построению (проверяет тест).
Генерация детерминирована по seed; ~25–40 мс на попытку.

### Формат карты JSON (`world/mapIO.ts`, версия 1)
`tiles` и `zoneGrid` — массивы строк по символу на тайл (легенда в `legend`), `zones`, `pois`
(у люков — `id` пары), `stats`. Связность в F2 и тестах считается с учётом люков (`hatchLinks`). Карту можно поправить в редакторе с моноширинным шрифтом; при загрузке проверяются размеры
и символы (ошибка с номером строки/столбца), панель F2 показывает связность и прямые участки.

### ИИ NPC
- `Brain` (интерфейс) решает, что делать; каждая фракция — свой класс в `ai/brains/` с
  `StateMachine` (idle, walk, work, patrol, chase, flee, fight, arrested — по мере этапов).
- `Mover` — общее передвижение: запрос пути, следование со «сглаженным» путём, объезд встречных
  по правилу правой руки (но не в стену), распознавание блокировки:
  встречные лоб в лоб → уступает младший по `FACTIONS[*].yieldPriority` (игрок главнее всех),
  при равенстве — тот, кому ближе до «кармана»; стоящего NPC просят отойти; стоящего игрока ждут,
  потом разворачиваются; упёрся в стену — перестраивает путь.
  Сторож затора (`AI.move.giveUp*`, `ghost*`): идёт к цели, но не отходит дальше 64 px от одного места —
  через 4 с, упираясь в NPC, ненадолго проходит сквозь NPC (`Character.ghost`, физика не расталкивает;
  игрока — никогда), через 12 с бросает цель (`failed`). Тест: никто не упирается дольше 20 с.
- Цели прогулок — `ai/destinations.ts`; зоны, которых NPC избегают, — через `avoidZones` в A*.

### Закон (`systems/LawSystem.ts` + `ai/brains/CpBrain.ts`)
- Нарушения, заметные ГО (`observe`): бег быстрее `LAW.runSpeed`, запретная зона. Плюс плановые
  проверки CID (на КПП — почти всех в коридоре). Без CID / в розыске — выясняется при проверке.
- Цикл: `order` (стоять; NPC может побежать — шанс по фракции) → ГО подходит → `beginCheck` →
  `judge` → `apply`: отпустить / штраф (`LAW.fines`) / `arrest`. Бег от ГО = неподчинение → арест.
  Игрок, отошедший дальше `LAW.complyRadius` после приказа, — «в бегах».
- Арест: мозг задержанного сохраняется в `law.savedBrain`, ставится `PrisonerBrain` (идёт за
  конвоиром). ГО ведёт к свободной камере (`freeCell`/`reserve`), `putInCell` отпирает дверь,
  задержанный заходит — дверь запирается, срок `LAW.jailTime`. После срока — выход за ворота
  Нексуса и возврат прежнего мозга. Упустил беглеца на `chaseLoseTime` — тот объявлен в розыск.
- Игрок-ГО: F — проверить того, кто перед ним → панель CheckPanel (1 отпустить, 2 штраф, 3 арест);
  арестованный идёт за игроком, у свободной камеры КПЗ заводится автоматически. Беглеца надо догнать.
- Все сообщения — через `bus.emit('log', …)` в журнал событий; реплики — `Character.say`.
- ГО сразу узнаёт повстанца (`observe` → 'rebel'): безоружного задерживает, вооружённого — бой.
  Житель с оружием в руках — нарушение 'weapon'. Красный код: на улице после `WAR.curfewGrace` —
  нарушение 'curfew' (арест). Бег в панике от стрельбы нарушением не считается (`panicUntil`).
- Отряды ГО (`config/factions.ts`, `CP_DIVISIONS`): UNION — патруль, быстрее бег; GRID — гарнизон
  КПП, MP7, G — поставить бетонный блок (до трёх); HELIX — медик, G — лечить, NPC-медики сами
  выходят к раненым; JURY — проверка CID вдвое быстрее, штрафы вдвое выше.

### Экономика (`systems/EconomySystem.ts`, `config/economy.ts`)
- Раздача рационов по таймеру (`ECONOMY.rations`): окно у будки на площади, живая очередь по
  отметкам (`queueSlot`), выдаёт работник ГСР (NPC сам, игрок-ГСР — E). Рацион = паёк + токены,
  раз за раздачу на персонажа. При комендантском часе раздача не открывается.
- Сытость падает у всех; при нуле — урон. NPC едят и перевязываются сами, если есть чем.
- Зарплаты раз в минуту: ГО (с надбавкой за ранг), ГСР — если работал, Администратор.
- Поломки (щитки у стен переулков) появляются по таймеру; ГСР чинит (игроку нужен набор инструментов).
- Магазин ГСР — комната с дверью недалеко от площади (`stampShop`), E у прилавка.
- Предметы и наборы по ролям — `config/items.ts` (`ITEMS`, `WEAPONS`, `KITS`), инвентарь — `Inventory`.

### Оружие и бой (`systems/CombatSystem.ts`, `ai/Gunner.ts`, `config/items.ts`, `config/combat.ts`)
- 9 стволов в `WEAPONS`: дубинка ГО (удар в секторе, оглушает — `speedMul`), USP, револьвер .357,
  MP7, трофейный MP7, самодельный пистолет, AR2 (пробивает укрытия), SPAS-12 (8 дробин, заряжается
  по патрону, выстрел прерывает перезарядку), арбалет. У каждого: режим огня (`semi/auto/pump/melee`),
  урон и падение урона (`effectiveRange → range`, `falloff`), конус разброса, отдача, магазин,
  перезарядка, пробитие блоков, время доставания (`draw`), замедление при прицеливании, слышимость.
- **Конус как в Foxhole**: `spreadOf(c)` — полуугол от `spreadHip` до `spreadAim` по мере
  прицеливания `c.aim` (игрок — ПКМ, NPC — пока ведёт цель; копится стоя, медленнее на ходу,
  теряется на бегу), + движение (`moveSpread`, бег — сильнее) + отдача `c.recoil` (спадает
  `recovery`/с). Пуля/дробина — треугольное распределение строго внутри конуса.
  `AimRenderer`: треугольник разброса, заливка обрезана стенами лучами DDA, дуга на предельной
  дальности (белая — прицел полный, серая с заполнением — перезарядка), штрихами — дальность полного
  урона. У игрока — всегда (от бедра бледный), у NPC — когда целится. При прицеливании камера
  отдаляется и уходит к курсору (`CAMERA.aim*`), чтобы дуга была в кадре.
- **Оружие в руках** (`config/weaponSprites.ts`, `entities/WeaponRenderer.ts`, `entities/weaponPose.ts`):
  у каждого ствола своя модель сверху (детали: прямоугольники, многоугольники, линии, круги,
  светящиеся — ядро AR2, кончик дубинки, болт арбалета) и кисти рук цвета перчаток фракции. Позы:
  длинные — у плеча, в прицеле ближе к центру; пистолет — у бедра одной рукой, в прицеле двумя
  перед собой; перезарядка — ствол отведён; отдача откатывает назад. Трассер и вспышка — от
  дульного среза (`muzzleWorld`).
- Магазин у каждого ствола свой (`c.mags`): смена оружия (Q — следующее, H — убрать) патроны не теряет.
- ИИ (`Gunner`): ищет цели в дальности лучшего ствола, берёт `bestWeapon` под дистанцию (дубинку
  меняет на огнестрел, дробовик — только вблизи), стреляет, когда конус у цели достаточно узкий
  (`ai.fireWidth`), очередями (у полуавтомата — сериями); ГО вне боя снова берёт дубинку.
- Стены и закрытые двери останавливают пулю, бетонный блок — с шансом `barrierStopChance ×
  (1 − penetration)` один раз на блок (свой блок у стрелка не мешает).
- Урон × падение × броня фракции; раненый (< `woundedFraction`) отходит (ГО в укрытии
  перевязывается своей аптечкой); убитый NPC убирается, остаётся тело с лутом (E — обыскать).
  Игрок возрождается через `respawnDelay`, теряя часть токенов.
- `threat(a, b)`: повстанцы стреляют по Альянсу всегда, Альянс — по вооружённым и напавшим.
  Напавший на ГО/OTA получает `hostile` и розыск. Gunner не стреляет, если на линии свой.
- Звук (`ui/GunfireAudio.ts`, `config/audio.ts`): синтез WebAudio по классу оружия, тише и глуше
  с расстоянием, панорама по стороне; N — вкл/выкл. Логика звук не трогает — UI читает `combat.shots`.
- **Гранаты** (`GRENADE` в `config/combat.ts`, предмет `grenade`): `CombatSystem.throwGrenade` — летит к
  точке (стену не перелетает, блок — да), взрыв через `fuse` с от броска: урон по кругу с падением к
  краю, стена закрывает, блок ослабляет; взрыв — «выстрел» `weapon: 'grenade'` (слышат NPC, звук).
  Игрок — T к курсору. ИИ (`Gunner.tryGrenade`): цель за укрытием (скрылась после контакта или блок на
  линии) или кучка врагов, своих у точки нет, сам вне радиуса; шанс и откат. `ai/Dodge.ts`: заметил
  гранату (видит в угле обзора; бросок «своих» — слышит крик) — бежит, предпочитая место за стеной.
  Наборы: повстанцы, GRID, OTA; продаются на чёрном рынке.
- **Следы** (`combat.decals`, `COMBAT.decals`): гильзы, кровь, выбоины у стен, копоть; живут десятки
  секунд, список ограничен. Взрыв — вспышка/дым (`combat.blasts`) и тряска экрана (`Game.shake`).
- **Реплики** (`systems/Barks.ts`, `config/barks.ts`): контакт, перезарядка, ранен, убил, потеря
  своего (видит тело), «вперёд» на перебежке в капте; на улице — бытовое, а если у КПП бой — о границе
  (`ai/streetBark.ts`). Откат у каждого, говорящего не перебивают.

### Война на границе (`systems/WarSystem.ts`, `ai/brains/RebelBrain.ts`, `config/war.ts`)
- Фронт = пограничный КПП: пустошь 14 тайлов с завалами-укрытиями, гарнизон — 3 часовых GRID на
  постах (передний — за блоком в коридоре) + медик HELIX в бункере.
- Ритм фронта «сбор → капт»: отряды по `squadSize` подходят раз в `squadGap` и собираются на пустоши
  вне видимости постов (`RebelBrain` режим `gather`, `pickGather`, `WAR.gatherDist`) — не лезут под
  огонь по одному. Собралось ≥ `capture.minAttackers` — все разом идут на капт. Состав: MP7/AR2,
  иногда дробовик, арбалетчик, командир с револьвером. Режим `raid` (перестрелка с позиции с видом на
  пост, огонь на подавление) — у пополнений захваченного КПП и при `forceAssault`. Тест: за 4 мин у
  каждого КПП ≥ 2 каптов, в каждом ≥ 5 штурмующих, подкреплений ГО во время капта нет.
- `war.active(f)` — стреляли у КПП за `activeWindow` с: указатели на КПП у края экрана
  (`EffectsRenderer.drawFrontMarkers`, в бою — оранжевые «бой»), перестрелку слышно из города.
- Штурм в город: `forceAssault` или оголённый пост (нет часовых `pushWhenUnguarded` с). Потери ГО
  вне капта восполняются подкреплениями к внутренним воротам КПП (двое раненых отошли — один сверх штата).
- **Капт КПП** (как захват территории в SAMP, `WAR.capture`, `updateCapture`): у КПП (коридор +
  пустошь фронта, `frontAt`) собралось ≥ `minAttackers` повстанцев → капт на `duration` с (следующий
  сбор — через `cooldown`). **Во время капта подкрепления ГО и медики на этот КПП не приходят, новые
  отряды повстанцев тоже** — бой тех, кто есть. Повстанцы в режиме `capture` идут по коридору
  перебежками: укрытие на доле пути `advance`, держатся `coverWait` с, продвигаются на `advanceStep`;
  под огнём — `shootStop` с стреляют, `dash` с бегут. Ранеными не отступают. Итог: гарнизон,
  стоявший в начале капта (`capture.defenders`), перебит — или `killsToWin` убийств с перевесом —
  КПП захвачен; все штурмующие погибли/ушли — капт отбит; по таймеру — захват при ≥ `minKills` и
  перевесе. Захваченный КПП (`owner = 'rebels'`): повстанцы на постах (`hold`), код жёлтый (патрули
  к воротам; держится, пока КПП у повстанцев), через `holdTime` — контрудары отрядами GRID раз в
  `retakeEvery`; в коридоре нет повстанцев `retakeCalm` с — КПП отбит, повстанцы снова собираются.
  Табло — `ui/CaptureBar` (счёт, штурмующие, живой гарнизон). В замерах: 12–14 каптов за 10 мин,
  около половины успешны.
- Боец отряда оказался в городе → прорвавшийся → КРАСНЫЙ КОД: комендантский час, раздача закрыта,
  из Нексуса выходит OTA (часть — с дробовиками), патрули ГО прочёсывают город по данным «Надзора»
  (`lastKnown`). Граждане уходят в подъезды/дворы (`shelters`). Отбой — когда прорвавшихся нет
  `calmToGreen` с (не раньше `redMinTime`); через `redMaxTime` прорвавшиеся «уходят в подполье».

### Канализация и сопротивление (`systems/UndergroundSystem.ts`, `systems/InsurgencySystem.ts`, `config/underground.ts`)
- Люк: E в радиусе `UNDERGROUND.useRadius` → `climbTime` с на месте → у парного люка на другом
  уровне (`climb` ставит на свободный якорь, без интерполяции). NPC ходят через люки `HatchTravel`:
  `route` выбирает пару люков по сумме «сюда → люк» + «люк → цель».
- Убежище: гарнизон `INSURGENCY.garrison` (`UndergroundBrain`, пополняется раз в `recruitEvery`),
  тайник (E: патроны к своим стволам, `refillAmmo`), повстанец-игрок появляется здесь.
- Вылазки раз в `outingEvery` (в убежище остаётся ≥ `minAtBase`): обход тоннелей до люка, поход
  на рынок, разведка в город через люк (1–2 бойца, режим `outing`). Разведчик скрытен: огонь не
  открывает (`Gunner.holdFire`), заметил ГО — уходит вниз; отвечает, только если ранили.
- Операции раз в `opEvery`: **саботаж** (1–2 бойца через люк к узлу Альянса, `sabotageTime` с —
  узел сломан) или **засада** (2–3 бойца через люк на патрульного ГО, бой `ambushFight` с, отход).
  Раненые и закончившие — к ближайшему люку и вниз. Связь сопротивления видна только игроку-повстанцу.
- Узлы Альянса (`EconomySystem.nodes`: терминалы у стен на проспектах и площади) ломаются только
  от саботажа; чинит ГСР (дороже щитка). Игрок-повстанец саботирует сам (E), награда `sabotageReward`.
- **Тревога Администратора — код жёлтый** (`WarSystem.raiseAlarm`): саботаж или ранение сотрудника
  Альянса в городе (`CombatSystem.onDamage`). Нападавшие → `war.operatives` (ушли под землю — след
  потерян), точка тревоги держится `ALARM.pointTime`. Патрули в `respondRadius` → «hunt» к последней
  известной позиции / точке тревоги; проверки CID чаще (`LAW.alarmCheckMul`). Отбой — `calmToGreen`
  без известных нападавших (не раньше `minTime`); погибло `escalateKills` сотрудников — красный код.
- Чёрный рынок (прилавок в канализации, торговец — `PostBrain`): оружие и патроны
  (`ECONOMY.blackMarket.stock`), скупка трофеев и рационов (`sell`), поддельная CID (снимает розыск).
- ИИ без «глаз на спине»: `Gunner.acquire` — только в угле обзора `VISION.npcFovDeg` или вплотную;
  ранили / выстрел врага рядом → через реакцию поворот в примерную сторону (`COMBAT.ai.alert*`);
  мозги зовут `gunner.look` последним, чтобы бой и тревога перебивали дежурный взгляд.

### Этап 5: лояльность, чат, карты, сохранение (`config/loyalty.ts`, `config/chat.ts`, `config/minimap.ts`, `config/save.ts`)
- **Лояльность** (`Character.loyalty`, только граждане и ГСР — `hasLoyalty`): + за полученный рацион,
  пройденную проверку, работу ГСР, донос, поощрение ГО; − за штраф, арест, оскорбление, ложный донос.
  Уровни (`LOYALTY.tiers`): неблагонадёжный → гражданин → лоялист → образцовый: множитель плановых
  проверок CID (`checkMul`), надбавка к рациону, скидка в магазине ГСР (`EconomySystem.shopPrice`).
- **Чат** (`ChatSystem.submit`, ввод — `ui/ChatBox`, Enter или «/»): речь — реплика и строка журнала
  (вид `chat`); ГО, который видит, на оскорбление (`CHAT.insult`) требует документы — нарушение
  `insult`, штраф; на приветствие отвечает прохожий. Команды: /me, /r (рация ГО), /roll, /cid,
  /донос (виден повстанец/вооружённый/в розыске: повстанец — тревога, иначе патрульный идёт
  разбираться), /поощрить (ГО), /помощь.
- **Карты** (`ui/MapView`): мини-карта в углу и большая карта (M) уровня игрока, собираются из тайлов
  один раз; канализация открывается по мере исследования (повстанцам — сразу), люки — найденные.
  Маркеры: КПП (бой/капт/захвачен), Нексус, раздача, магазин, сломанные узлы, тревога, свои.
- **Сохранение** (`SaveGame`, localStorage `SAVE.key`): роль, имя, деньги, лояльность, здоровье,
  сытость, инвентарь и оружие, статус CID, позиция, знание карты; seed карты. Автосохранение раз в
  `SAVE.interval` с, при выборе роли и закрытии вкладки. Без ?seed (или с тем же seed) игра
  продолжается; «Новая игра» (в главном меню — экран подтверждения, в меню роли — второе нажатие; `window.confirm` в песочнице не работает) стирает сохранение. Задержанный сохраняется в розыске.
- **Пауза** — P. **Меню** (`ui/GameMenu`): главное при запуске (продолжить / играть, новая игра,
  управление, звук) и пауза по Esc (продолжить, сохранить, сменить роль, управление, звук, выйти в
  главное меню — с сохранением). Пока меню открыто, мир стоит. Esc сначала закрывает открытые панели
  (`Game.onEscape`, перехват до остальных обработчиков); список клавиш — `CONTROLS_HELP` в `HelpBar`.

## Соглашения
- Все числа, цвета, скорости, зарплаты и т.п. — в `src/config/*`. Новый параметр → в конфиг.
- `src/` не использует API Node; `tests/` может (свой `tests/tsconfig.json`).
- Случайность в генерации и мире — только через `Rng` (seed), не `Math.random` (кроме выбора нового seed).
- Логика не трогает DOM; UI подписывается на `EventBus`. Новые события — в `GameEvents`.
- Персонаж игрока и NPC — один класс `Character`; различие только в источнике управления.
- Отрисовка тайлов — в экранных пикселях с округлением (без щелей); подписи — в экранных пикселях.
- Перед коммитом: `npm run typecheck && npm test`.
