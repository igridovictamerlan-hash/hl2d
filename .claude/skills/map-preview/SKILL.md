# Превью и проверка карты

Генератор детерминирован по сиду, но одна правка двигает всё: здание не встало, прямая длиннее нормы, сид стал
генерироваться за 12 попыток вместо 3, а сид-зависимые тесты поведения поменяли исход. Поэтому после правки
генератора смотри на карту **глазами** на нескольких сидах и прогоняй метрики.

## Картинка

```bash
SEEDS=12345,7919,2024,31337,424242 npx vitest run --config .claude/skills/map-preview/scripts/vitest.config.mjs map
SEEDS=12345 SCALE=6 CROP=160,140,70,50 npx vitest run --config .claude/skills/map-preview/scripts/vitest.config.mjs map   # участок крупно
```

Результат — `/tmp/hl2d-map/map_<сид>[_crop].png` и `report.txt`: размер карты, попытка генератора, время, застройка,
самая длинная прямая, люки, **проверка** (`validateMap`; «ПРОБЛЕМЫ: …» — карта не прошла) и легенда меток. Цвета —
мини-карты (`MINIMAP.tiles`), скалы светлее с высотой (`rockRelief`), снег на гребнях; метки — квадраты в центрах
POI (легенда в отчёте; правь `MARKS` в `map.viz.ts`, если появился новый объект). Пять сидов выше — разные
раскладки КПП и углов; 12345 — основной сид замеров и тестов.

Это схема, а не игра: настоящую отрисовку (крыши, фасады, мебель, свет) — скриншотом в браузере (скилл `playtest`,
`--at x,y --nofog --zoom 2`). Координаты для скриншота бери отсюда: тайл = пиксель картинки / `SCALE`.

## Метрики и тесты генератора

```bash
npm run mapstats                     # 30 сидов: попытки, застройка, прямые, тупики, связность, тоннели, мс; проблемные сиды
DEBUG_GEN=1 npm run mapstats         # + почему отбракованы попытки
npx vitest run tests/generator.test.ts tests/checkpoints.test.ts tests/town.test.ts tests/arbat.test.ts tests/housing.test.ts tests/mapio.test.ts tests/pathfinding.test.ts
```

Смотри на **попытки** (было 4–5 в среднем — стало 9 → правка ломает проверку на части сидов, `DEBUG_GEN=1`
скажет, что именно), **прямую** (норма — 25), время генерации и сиды из списка проблем.

## Правила генератора, которые легко забыть

- Новое здание — на своём генераторе (`rng.fork(…)`, как склад, тюрьма, академия): тогда места остальных зданий на
  сидах не сдвигаются и меньше тестов меняют исход.
- Новый тип тайла — в `TILE_DEFS` (`world/tiles.ts`), палитру `MapRenderer`, `MINIMAP.tiles` и `DevPanel`; символ
  для JSON уникален.
- Каждая деталь застройки откатывается (`GenGrid.snapshot/restore`), если открывает прострел длиннее нормы;
  связность — `ensureConnectivity`, люки учитываются (`hatchLinks`).
- Проверку новых объектов добавляй в `validateMap` (иначе генератор молча выдаст карту без них) и описывай в
  `docs/generator.md`.
- Любая правка карты сдвигает сид-зависимые тесты поведения (бой, банды, тюрьма…). Разбирай их по одному — скилл
  `test-triage`; ожидай этого заранее и закладывай время.
