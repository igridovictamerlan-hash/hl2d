# Плейтест в браузере

Тесты (`npm test`) проверяют логику без DOM, но не видят картинку, интерфейс и скорость в браузере. Этот скилл
открывает игру в Chromium, входит в роль, ставит игрока куда нужно и снимает скриншот или числа. Скрипты лежат в
`scripts/` рядом с этим файлом и запускаются **из корня репозитория**; сервер разработки (vite, порт 5173) они
поднимают сами, если он не запущен (лог — `/tmp/hl2d-vite.log`), и оставляют работать для следующих запусков.

Браузер уже стоит в контейнере (`/opt/pw-browsers`), Playwright — глобально: **не запускай `playwright install`** и
не ставь Playwright в проект.

## Скриншот

```bash
node .claude/skills/playtest/scripts/shot.cjs --out <путь>.png --poi plaza_center --hour 13
node .claude/skills/playtest/scripts/shot.cjs --out <путь>.png --at 190,166 --hour 21 --zoom 2 --nofog
node .claude/skills/playtest/scripts/shot.cjs --out <путь>.png --shots "60,140,9;198,123,13;265,188,22"   # три кадра одного города
```

- `--at tx,ty` — тайлы (16 px); `--poi <тип>` — первая точка интереса этого типа (`plaza_center`, `nexus_gate`,
  `cwu_hq`, `prison`, `academy`, `arsenal_pad`, `canteen`, `dugout`, `checkpoint_type`… — см. `PoiType` в
  `src/world/GameMap.ts`). Где что на карте — проще посмотреть превью карты (скилл `map-preview`).
- `--hour` — игровые часы 0–24 (свет, распорядок). `--zoom N` — N шагов `Camera.cycleZoom` (отдаление).
- `--nofog` — без тумана войны (обзорный кадр), `--nohud` — без DOM-интерфейса (только холст).
- `--seed`, `--level sparse|normal|busy|crowd|max|extreme` (население из меню) или `--npcs N` (ровно N граждан —
  быстрее для чисто визуальной проверки), `--role citizen|cwu|cp|rebel` (+ `--rank`), `--wait` секунд до снимка
  (NPC расходятся не сразу; для живой улицы ставь 8–15), `--width/--height`, `--touch` (сенсорное управление).
- `--js "<код>"` — выполнить в странице перед снимком (`game` — `window.game`), например открыть панель или
  поставить код тревоги.

Снимок кладут в scratchpad (или каталог, который пользователь откроет), смотрят сами через Read и отправляют
пользователю (SendUserFile) с короткой подписью: что на кадре и что проверялось. Если на кадре не то (тёмно,
игрок не там, перекрыто меню) — поправь параметры и сними заново, прежде чем показывать.

## Производительность

```bash
node .claude/skills/playtest/scripts/perf.cjs --levels normal,crowd,extreme
```

Игрок на площади (самое людное место), каждые `--every` с (10) — живых, тик логики (`Game.tickMs`, скользящее
среднее, мс), такт упрощённой симуляции (`LOD every/farEvery` — вырос, значит машина не успевала и `Game.adaptLod`
упростил дальних), кадры в секунду. Кадры в облаке низкие (рисует процессор, видеокарты нет) — сравнивай тик
логики и «до/после» на одной машине, а не абсолютные кадры. Числа для CLAUDE.md («Замер» в разделе «Население и
упрощённая симуляция») берутся отсюда: уровень, живых, тик, такт LOD.

## Вопрос к живой игре

```bash
node .claude/skills/playtest/scripts/probe.cjs --level crowd --wait 30 --repeat 3 --every 20 \
  --expr "Object.entries(game.entities.list.reduce((m,c)=>{const s=c.brain?.stateName?.split(' ')[0]??'-';m[s]=(m[s]??0)+1;return m},{})).sort((a,b)=>b[1]-a[1]).slice(0,12)"
```

`--expr` считается в странице раз в `--every` с, результат — JSON. `--setup` — код один раз до ожидания (поставить
код тревоги, сделать игрока бессмертным, начать наступление: `game.war.command.launchOffensive(0)` и т. п.). Объект
игры — `src/core/Game.ts` (поля `entities`, `map`, `player`, `war`, `ai` — контекст систем, `ui`, `camera`, `time`).
Приватные поля TypeScript в странице доступны как обычные.

Для массовых чисел за десятки игровых минут браузер не нужен — быстрее и точнее безголовый замер (скилл
`world-audit`).

## Если что-то не так

- Скрипт печатает «ошибки страницы» — это исключения и `console.error` игры: показывай их пользователю, если
  относятся к правке; это настоящие баги, тесты их не ловят.
- Висит на ожидании `window.game` — сборка упала: `tail -50 /tmp/hl2d-vite.log`, `npm run typecheck`.
- Порт занят чужим процессом — `--port 5174`.
- Сохранение из localStorage браузера не мешает: каждый запуск — новый профиль браузера.
