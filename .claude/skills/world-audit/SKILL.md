# Замер живого мира

Тесты проверяют сценарии, но не отвечают на «как живёт город целиком». Для этого два безголовых замера — оба на
`tests/simHarness.ts`, без DOM, детерминированы по сиду, десятки игровых минут за минуты реального времени:

1. **`npm run worldstats`** (`tests/worldstats.test.ts`) — сводка всего мира: население, смерти «кто кого и как»,
   деньги и сытость по группам, чем заняты, кто стоит 30 с и «идёт, но стоит», закон, банды, подполье, фронт по КПП,
   блиндажи, рация, разговоры, живые люди, **толпа**, штат ВС. Состав — как в тестах (множитель населения 1).
2. **Тепловая карта толпы** (`scripts/density.viz.ts`) — где люди проводят день: ячейки 6×6 тайлов, самая людная,
   сколько жителей у площади по часам и **чем они там заняты**, горячие ячейки, зоны. Население — как в игре на
   «много» (`SCALE=4`). Это то, что показывать пользователю картинкой.

## Как запускать

Из корня репозитория. Долгие прогоны — в фоне с логом, ждать завершения циклом (не `sleep` подряд):

```bash
mkdir -p /tmp/hl2d-audit
# сводка мира, 12 игровых минут (≈ 16 часов суток), лог в файл
MINUTES=12 npm run worldstats > /tmp/hl2d-audit/ws_after.log 2>&1 &
# тепловая карта (≈ 3–4 мин на ~570 жителях)
TAG=after MIN=12 OUT=/tmp/hl2d-audit npx vitest run --config .claude/skills/world-audit/scripts/vitest.config.mjs density > /tmp/hl2d-audit/density_after.log 2>&1 &
# ждать (в одном вызове Bash с timeout до 600000):
until grep -q "Test Files" /tmp/hl2d-audit/density_after.log; do sleep 5; done
```

Несколько прогонов можно запускать параллельно — это отдельные процессы. **Пока идут прогоны, не правь `src/`**:
vitest подхватывает файлы по мере импорта, и прогон смешает старый и новый код.

Переменные `worldstats` — в CLAUDE.md («Команды»): `SEED`, `MINUTES`, `RELATIONS=0`, `HOODS=0`, `CP=classic`,
`LINE=0`, `DUGOUTS=0`, `WARCFG="dugout.sortie.chance=0,line.shift=300"`. Тепловой карты: `SEED`, `MIN`, `START` (час
начала, 7), `SCALE` (4 = «много», 1 = состав тестов), `HOODS=0`, `CP=classic`, `LINE=0`, `CELL`, `NEAR`, `MAXV`, `OUT`,
`TAG`. Результат — `OUT/heat_<TAG>.png` и `OUT/density_<TAG>.txt`.

Строки `worldstats`, которые обычно нужны: `grep -E "Население при старте|Погибли|Убийцы|Как:|Занятия|Стоят на месте|«Идут»|Толпа:|Фронт|Живые люди|голодают" <лог>`.

## «До/после»

Честное сравнение — тот же сид и те же параметры на старом коде:

```bash
D=$(bash .claude/skills/world-audit/scripts/baseline.sh HEAD)      # или хеш коммита до правки; печатает путь рабочей копии
cd "$D" && TAG=before MIN=12 OUT=/tmp/hl2d-audit npx vitest run --config .claude/skills/world-audit/scripts/vitest.config.mjs density
cd "$D" && MINUTES=12 npm run worldstats > /tmp/hl2d-audit/ws_before.log 2>&1
cd /home/user/hl2d && git worktree remove --force "$D"              # вернуться в основную копию и убрать рабочую
```

`baseline.sh` делает отсоединённый `git worktree`, подключает `node_modules` ссылкой и кладёт туда скрипты скилла
(в старом коде их может не быть; скрипт замера переносит отсутствие новых систем). Если правка ещё не закоммичена —
`HEAD` и есть «до». Для одной и той же нормировки цвета дай второму прогону `MAXV` = «средняя самой людной» из txt
первого — иначе каждая картинка ярче всего в своём максимуме, и сравнение на глаз обманывает.

Склеить для пользователя:

```bash
python3 .claude/skills/world-audit/scripts/compare.py --out /tmp/hl2d-audit/compare.png \
  /tmp/hl2d-audit/heat_before.png "ДО: 513 жителей — площадь как магнит, самая людная ячейка 28" \
  /tmp/hl2d-audit/heat_after.png  "ПОСЛЕ: 567 жителей — свой район, самая людная ячейка 17"
```

(`auto` вместо подписи — число живых и самая людная ячейка из txt.) Посмотри картинку сам (Read), потом отправь
(SendUserFile) с подписью, что сравнивается.

## Как читать

- **Самая людная ячейка** и **жители у площади по часам** — толпа. Смотри строки «у площади N–M ч»: какие
  состояния мозга набились (`citizen:shop`, `idle`, `queue`…). Так нашлась вечерняя толпа у закрытого магазина ТС:
  86 человек в `shop` и 56 в `idle` — голодные ходили к закрытой двери по кругу. Толпа в одном состоянии почти
  всегда петля решения, а не «популярное место».
- `worldstats`: «Стоят на месте 30 с» и «„Идут“, но стоят» — застрявшие; «голодают (0)» — еда не доходит;
  «Кто кого» — неожиданные пары (ВС → горожанин, армия → мирные) — повод разобраться.
- Одна картинка и один сид — ещё не вывод: важные цифры проверь на втором сиде (`SEED=7919`, `SEED=6`) и
  перед записью в CLAUDE.md укажи сид, минуты и условия, как в существующих «Замер …».
- Короткие прогоны (2–3 мин) годятся проверить, что скрипт работает; для выводов о сутках — 12+ минут.
