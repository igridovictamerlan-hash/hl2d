# Сити-17 · HL2RP 2D

2D-игра в браузере с видом сверху в духе HL2RP-серверов Garry's Mod: тесный город из переулков под
контролем Альянса. Персонажи — пешки в стиле RimWorld с подписями, NPC ведут себя как игроки RP-сервера.

## Запуск

```bash
npm install
npm run dev      # откройте http://localhost:5173
npm test         # тесты
```

## Управление

| Shift | бег |
| Мышь | взгляд / прицел |
| ЛКМ / R | огонь (дубинкой — удар) / перезарядка |

| G | умение юнита/профессии: SU.02 и медики — лечить (в городе SU.02 — запустить сканер), SU.03 — бетонный блок, партизан — маскировка, глава восстания — клич |
| Enter / «/» | чат / команда: /me, /r, /roll, /cid, /донос, /поощрить, /охрана, /выборы, /голос N, /помощь |
| M | большая карта (мини-карта — всегда в углу) |

| P | пауза |

## Профессии

При выборе роли у граждан, ГСР, повстанцев и вортигонтов есть профессия (по мотивам профессий
HL2RP-серверов); в меню видны её умения. NPC работают по тем же правилам.

| Фракция | Профессия | Что делает |
|---|---|---|
| Граждане | Гражданин | живёт по правилам; лоялист бегает без нарушения, встаёт в очередь впереди, «Доверенный лоялист» — `/охрана` |
| | Вор | E за спиной прохожего — вытащить токены; E у закрытого окна раздачи — взлом. Увидел ГО — арест за кражу |
| | Отброс общества | E у мусора — порыться (чаще находит полезное); без лояльности |
| | Бандит | E перед прохожим в подворотне — гоп-стоп со стволом в руках; увидит ГО — арест или стрельба |
| | Беглец | без CID и в розыске: любая проверка — арест; КПП прорван — бежит к своим первым |
| ГСР | Повар | E у окна раздачи — выдача рационов со склада будки |
| | Фасовщик | E у конвейера в цехе штаба ГСР — собрать коробку рационов (у каждого свой конвейер) |
| | Курьер | E у склада цеха штаба ГСР — взять коробку, E у будки — сдать (склад будки пополняется) |
| | Уборщик | E у мусора — убрать, E у поломки — починить |
| | Медик ГСР | G — вылечить (граждане платят, ГО — бесплатно) |
| Повстанцы | Солдат, медик, пиротехник, партизан | медик лечит (G); пиро — огненные гранаты и поджигающий арбалет; партизан (G) выглядит как гражданин, пока не достанет оружие или не пройдёт проверку; только партизаны ходят люками |
| | Глава восстания, ветеран, подрывник | глава — 250 HP, выбирает КПП, G — клич; ветеран — AR2; подрывник — много гранат |
| | HYDRA: капитан, офицер, боец | спецотряд как SAS: противогаз, бронежилет, AR2/MP7; держится рядом с главой |
| Вортигонты | Раб | убирает улицы; документы у вортигонтов не проверяют |

Силовой блок — как на сервере. **PCU** (городская полиция): RCT.PCU (75 HP, дубинка и пистолет) стоят
на постах у проходных КПП, у ворот Нексуса и в людных местах; PCU.03 (90 HP) патрулируют; PCU.02
(100 HP) и сержанты PCU.01 (110 HP, MP7) водят патрульные группы; офицеры PCU.OFC (150 HP, их двое)
обходят посты и собирают построения на плацу Нексуса. На бойню у КПП PCU не ходит. **SU**: SU.03
(120 HP, MP7) держат посты КПП вместе с OTA, SU.02 (125 HP) — медики на КПП и техники со сканером в
городе, SU.01 ходят с патрулями и по телам находят убийц (E у тела), двое инспекторов SU.INSP
проверяют поваров ГСР и канцелярию лоялистов — всегда под охраной. Охранников SU.GUARD меньше, чем
тех, кого надо охранять, — инспекторов, Администратора, лоялистов, — поэтому они охраняют по
очереди. **CMD.EPU** — глава силового блока: сидит у Администратора, в город выходит только со всей
охраной и инспекторами. **OTA** — командир OTA.KING и бойцы OTA.ALPHA (энерговинтовка, пистолет,
гранаты) воюют только на КПП, по городу не ходят. По городу ходит крематор и сжигает тела.

## Оружие

Прицел как в Foxhole: из персонажа выходит конус разброса с дугой на предельной дальности.
Стоя и с зажатой ПКМ конус сужается (дуга становится белой — прицел полный), в движении и от
отдачи — расширяется; пуля всегда летит внутри конуса. Штрихами отмечена дальность полного урона.

| Оружие | У кого | Особенности |
|---|---|---|
| Дубинка | ГО | удар вплотную, оглушает (замедляет) |
| USP Match | ГО | точный пистолет |
| MP7 | сержанты PCU, SU, охрана | автомат, конус шире |
| AR2 | OTA | мощная импульсная винтовка, пробивает укрытия |
| SPAS-12 | OTA, повстанцы-штурмовики | 8 дробин, страшен вблизи; заряжается по патрону |
| Трофейный MP7, трофейный AR2 | повстанцы (у всех бойцов — автоматы) | MP7 менее точен, чем у ГО |
| Самодельный пистолет | повстанцы (запасной) | дешёвый, неточный |
| Револьвер .357 | командир повстанцев (ранг «Командир» и выше у игрока) | 42 урона, 6 патронов, сильная отдача |
| Арбалет | повстанец-снайпер | тихий, точный, долго целиться |
| Граната | повстанцы, SU.03, OTA; чёрный рынок | бросок к точке, взрыв по кругу; NPC кидают в засевших за укрытием и убегают от чужих |

Персонажи — пешки в стиле RimWorld: причёски с чёлкой и пучками, лица с веками. Силовой блок — по
эскизам брони RimWorld: патрульные PCU — в касках с полосой цвета ранга, противогазах с круглыми
линзами и стёганых бронежилетах (офицер — в фуражке с аксельбантом); спецназ SU — в облегчённой
сегментной броне и шлемах с визором поверх балаклавы; OTA — в силовой броне со шлемом с Т-образным
визором (OTA.KING — белый катафракт с баллоном за спиной), глава EPU — в чёрном с золотом и плаще.
Аксессуары выборочно: рации, фонари на плече, шевроны, гранаты, сумки медика, ранцы с антеннами.
Пешки ходят, а не скользят: ступни переступают, корпус подпрыгивает на шаге и наклоняется в сторону
движения; идущий боком виден в профиль.
Повстанцы — в жилетах и банданах поверх рубашки цвета ранга. Оружие — модели по мотивам RimWorld
(револьвер с деревянной рукоятью, помповый дробовик, «зарядная» AR2…) размером с пешку.

Бой живой: бойцы перекрикиваются («Контакт!», «Перезаряжаюсь!», «Потеряли юнита!»), на земле
остаются гильзы, кровь, выбоины и копоть, близкий взрыв трясёт экран. Горожане болтают на улице и
обсуждают стрельбу на границе.

## Граница

На концах главного проспекта — два пограничных КПП, выходы из города. Каждый — **два отдельных
укреплённых двора**, как «война на D» на UnionRP: «Запад» — D3 → D4, «Восток» — D5 → D6. Между
дворами, как в CS, два пути: **шорт** (короткий прямой проход) и **лонг** (длинный обход поверху).
Названия точек нарисованы на полу: синие — у Альянса, оранжевые — у повстанцев. У края экрана —
указатели на КПП.

Город отгорожен от боя **проходной**: между внутренним двором и проспектом — тамбур со стеной-зигзагом
(из двора в город не видно и не простреливается) и дверью со стороны города, у двери дежурят два
рекрута ГО (RCT) и проверяют входящих.

- **Капт точки** (как в SAMP): отряды повстанцев собираются на пустоши; как только их 5 и больше —
  все разом идут брать очередную точку: сначала внешний двор, потом внутренний — часть отряда
  шортом, часть лонгом. Пока идёт капт,
  подкрепления ГО не выходят. Точка взята, если перебит её гарнизон (или у повстанцев 5 убийств с
  перевесом). Табло сверху — счёт, время, гарнизон и какие точки у кого.
- **Цитадель**: все ГО и OTA появляются у ворот Нексуса и бегут на КПП — пополнить посты или
  отбить захваченную точку (сначала ближнюю к городу).
- **КПП прорван** (обе точки у повстанцев) — граждане бегут туда и становятся повстанцами. Игрок-
  гражданин тоже может: зайти в коридор прорванного КПП и нажать E.
- **Все точки D** (оба КПП) у повстанцев — они выходят в город: код красный, комендантский час, прочёсывание PCU.

Штурмуют не толпой, а звеньями по 3–4 бойца: у каждого звена своя сторона двора и свой проход во
внутренний двор (шорт или лонг), звенья идут перекатами — одни перебегают, другие прикрывают.

Взяв один КПП, повстанцы оставляют на нём заслон и всей армией идут на второй: захваченную точку
Альянс не может отбить раньше чем через 200 с, а погибшие ГО и OTA возвращаются из Цитадели только
через 60–90 с. Оба КПП прорваны — повстанцы выходят в город.

**Штурм Нексуса** — цель восстания. Прорвавшиеся собираются во внутреннем дворе КПП и идут волной;
пока волна идёт, Цитадель не высылает подкреплений. В Нексусе повстанцев не меньше, чем защитников, —
захват за 40 с (табло сверху); захвачен — удержать 45 с. Удержали — **победа восстания**: Альянс
перебрасывает свежие силы, КПП снова у него, армия уходит в лагерь с трофеями (игроку-повстанцу —
150 токенов), всё начинается заново. Выбили из Нексуса — штурм сорван.

ГО — самая большая вооружённая сила (патрули и гарнизоны обоих КПП), граждан — большинство населения.

## Сопротивление: лагерь, армия, партизаны

За стеной города — **пустошь**: тропа идёт от выходов обоих КПП вдоль краёв карты и по низу к
**лагерю сопротивления**. Повстанец (кроме партизана) начинает в лагере.

- **Армия — постоянный состав**: глава восстания, 4 ветерана, 6 солдат, пиротехник, подрывник и
  спецотряд **HYDRA** (капитан, 2 офицера, 3 бойца — снаряжение как у SAS: балаклава, противогаз,
  бронежилет). Повстанцы больше не появляются у КПП из ниоткуда — они приходят из лагеря по тропе.
- **Глава выбирает КПП**: большинство идёт туда, небольшая группа отвлекает на втором КПП. Если
  главой играете вы — армия идёт на тот КПП, к которому идёте вы. **Клич (G)**: бойцы рядом на время
  бегут за вами на штурм. HYDRA держится рядом с главой.
- Раненые и без патронов уходят в лагерь — лечатся, пополняют патроны и возвращаются.
- **Как на сервере**: персонажей постоянное число. Погибший появляется снова на спавне своей
  стороны: ГО и OTA — в Цитадели, армия — в лагере, партизаны — в схроне, жители — в кварталах.
  Отбивать захваченные точки из Цитадели выходит OTA (командир OTA.KING — белая броня).

Под городом — канализация: **схрон партизан** и **чёрный рынок**. Люков только два — в запретной
зоне у края города, и пользоваться ими могут только **партизаны** (E у люка).

- Партизаны ходят на операции: **саботаж** узлов Альянса и **засады** на патрули ГО.
- Нападение на ГО или саботаж в городе — **код жёлтый**; много погибших сотрудников — красный.
- Повстанец-игрок может саботировать узел сам (E у узла, 5 с) — сопротивление платит токены.
- **Чёрный рынок** (E у прилавка): оружие и патроны, поддельная CID; скупает трофеи и рационы.
- NPC не видят затылком: стрелка за спиной замечают, только когда он выстрелит, — и то не сразу.

## Выборы Администратора

Администратор города погиб — Альянс объявляет **выборы** среди лоялистов (до трёх кандидатов,
60 с). Граждане и ГСР голосуют сами; вы — командой `/голос N` (ход выборов — `/выборы`).
Победитель становится Администратором — даже если это вы.

## Терминал кодов тревоги

В кабинете Администратора в Нексусе — терминал: E рядом, затем 1 — код жёлтый (усиленные проверки
CID), 2 — код красный (комендантский час, раздача закрыта, прочёсывание), 3 — отбой. Пользуются
Администратор (выбранный на выборах) и ГО с ранга OFC. Включённый с терминала код держится, пока
его не снимут.

## Городок

Город — не лабиринт в сплошной массе: застройка между узкими переулками поделена на отдельные дома со
своими крышами (скаты, конёк, трубы), часть домов — жилые: дверь на переулок, туда заходят жители.
Город большой — 4800×3700 px: от КПП до КПП по главному проспекту бегом около 15 секунд. Комнаты
обставлены в духе RimWorld: кровати размером с человека, тумбочки, книжные полки с цветными
корешками, столы со стульями, шкафы, комоды, ящики, цветы в горшках, в особняках — диван, ковёр,
двуспальная кровать; пол в жилых домах дощатый, в казённых — плитка. Крыши — спокойный серый шифер. В Нексусе коридоры широкие (4 тайла),
КПЗ на 7 одиночных камер и общая камера: туда сажают граждан, ГСР и партизан (бойцов армии — в
одиночные), дверь заперта, пока там кто-то сидит. Там же казарма ГО (появляются погибшие ГО),
комната OTA (резерв ждёт там), канцелярия: лоялисты (лояльность от 40) приходят туда разбирать бумаги
для Администрации за плату; игрок-лоялист — E у свободного стола.

**Штаб ГСР** стоит у главного проспекта (на картах — жёлтая точка «штаб ГСР»): Т-образный коридор, как
в Нексусе, но поменьше. В цехе три конвейера — там фасуют рационы, рядом склад коробок, откуда их
берут курьеры; есть комната отдыха с диваном и креслами и столовая с длинными столами — рабочие ГСР
уходят туда на перерыв. В кабинете сидит **глава ГСР**; в приёмной — стойка найма: граждане сами
приходят устраиваться, глава выходит к стойке и оформляет их туда, где рабочих не хватает (фасовщик,
курьер, уборщик, повар, медик), а мест нет — отказывает. Игрок-гражданин — E у стойки: и вы рабочий
ГСР. Инспектор SU.INSP в обходе заходит к главе ГСР за отчётом о выработке.

От проспекта расходятся улицы-артерии (асфальт в 4 тайла) и от них улочки поменьше, но город
остался переулочным: улицы идут с изломами, а между ними — прежние узкие переулки. Вдоль улиц —
общежития для граждан (планировка как в Нексусе: Т-образный коридор, комнаты на двоих по сторонам,
общая комната со столом для карт) и особняки богатых лоялистов: дом со спальней и гостиной в саду
за живой изгородью.

## Уличная жизнь

Горожане не просто ходят туда-сюда: останавливаются поговорить вдвоём (и потом иногда идут дальше
вместе), греются компаниями у бочек с огнём во дворах, заходят домой в подъезды, останавливаются
оглядеться. Раз в три минуты на площади — обращение Администратора: жители поблизости идут слушать.
Вдоль проспекта и улиц — фонари, скамейки и доски объявлений: при зелёном коде жители садятся
посидеть, вдвоём разговаривают; при тревоге встают и расходятся. Ещё они играют в карты в общих
комнатах общежитий, выходят на перекур (видно огонёк и дымок), читают объявления.

**Семьи.** Большинство граждан живёт семьями по 2–4 человека: общая фамилия, повязка одного цвета на
рукаве, похожие лица (кожа, волосы), подпись «семья Зайцевых». У семьи свой дом — комната в
общежитии, у богатых лоялистов — особняк. Родня навещает друг друга через весь город и говорит о
своём; погибший возвращается в ту же семью.

## Лояльность и сохранение

У граждан и ГСР есть лояльность: растёт за рационы, пройденные проверки, работу, доносы и
поощрения ГО, падает за штрафы, аресты и оскорбления. Лоялистов реже проверяют, им больше токенов
в рационе и скидка в магазине; неблагонадёжных проверяют чаще. Лоялистов видно издалека — они
в светло-фиолетовой форме.

Игра сохраняется в браузере автоматически (раз в 20 с и при закрытии вкладки) и продолжается при
следующем запуске. Начать заново — «Новая игра» в меню выбора роли.

## Карты

- `?seed=123` — карта по seed (текущий seed всегда виден в адресе и в панели F2).
- «Сохранить JSON» в панели F2 скачивает карту. Положите файл в `public/maps/` и откройте
  `?map=имя_файла_без_.json`. Пример: `?map=city17`.
- В JSON тайлы записаны строками по символу на тайл — удобно дорабатывать руками
  (легенда символов — в поле `legend`). После правки панель F2 покажет, связна ли карта.

Подробности архитектуры — в [CLAUDE.md](CLAUDE.md).
