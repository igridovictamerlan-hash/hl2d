# Сити-17 · HL2RP 2D

2D-игра в браузере с видом сверху в духе HL2RP-серверов Garry's Mod: тесный город из переулков под
контролем Альянса. Персонажи — цветные кружки с подписями, NPC ведут себя как игроки RP-сервера.

## Запуск

```bash
npm install
npm run dev      # откройте http://localhost:5173
npm test         # тесты
```

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | ходьба |
| Shift | бег |
| Мышь | взгляд / прицел |
| ЛКМ / R | огонь (дубинкой — удар) / перезарядка |
| ПКМ (зажать) | прицеливание: конус сужается, шаг медленнее, камера смотрит дальше |
| Q / H | следующее оружие / убрать оружие |
| T | бросить гранату к курсору (взрыв через ~2 с; стена закрывает, бетонный блок — нет) |
| N | звук выстрелов вкл/выкл |
| Tab | инвентарь: съесть, применить, взять оружие в руки |
| E | действие рядом: терминал найма, прилавок ГСР, очередь за рационом, обыскать тело, выдача и ремонт (ГСР), боекомплект у стойки Нексуса (ГО); люк — спуститься в канализацию / подняться; тайник и прилавок чёрного рынка в канализации; повстанцу — саботаж узла Альянса |
| F | действие роли: у ГО — проверить CID у того, кто перед вами |
| 1 / 2 / 3 | решение по проверке: отпустить / штраф / арест |
| G | умение отряда ГО: HELIX — лечить, GRID — поставить бетонный блок |
| Enter / «/» | чат / команда: /me, /r, /roll, /cid, /донос, /поощрить, /помощь |
| M | большая карта (мини-карта — всегда в углу) |
| P | пауза |
| Esc | меню: продолжить, сохранить, сменить роль, управление, звук, выйти в главное меню |
| F2 | генератор: новая карта, seed, сохранение/загрузка JSON, метрики |
| F3 | отладка ИИ: пути NPC, состояния, кто кому уступает |

Клавиши работают при любой раскладке.

## Оружие

Прицел как в Foxhole: из персонажа выходит конус разброса с дугой на предельной дальности.
Стоя и с зажатой ПКМ конус сужается (дуга становится белой — прицел полный), в движении и от
отдачи — расширяется; пуля всегда летит внутри конуса. Штрихами отмечена дальность полного урона.

| Оружие | У кого | Особенности |
|---|---|---|
| Дубинка | ГО | удар вплотную, оглушает (замедляет) |
| USP Match | ГО | точный пистолет |
| MP7 | ГО GRID | автомат, конус шире |
| AR2 | OTA | мощная импульсная винтовка, пробивает укрытия |
| SPAS-12 | OTA, повстанцы-штурмовики | 8 дробин, страшен вблизи; заряжается по патрону |
| Трофейный MP7, трофейный AR2 | повстанцы (у всех бойцов — автоматы) | MP7 менее точен, чем у ГО |
| Самодельный пистолет | повстанцы (запасной) | дешёвый, неточный |
| Револьвер .357 | командир повстанцев (ранг «Командир» и выше у игрока) | 42 урона, 6 патронов, сильная отдача |
| Арбалет | повстанец-снайпер | тихий, точный, долго целиться |
| Граната | повстанцы, ГО GRID, OTA; чёрный рынок | бросок к точке, взрыв по кругу; NPC кидают в засевших за укрытием и убегают от чужих |

Бой живой: бойцы перекрикиваются («Контакт!», «Перезаряжаюсь!», «Потеряли юнита!»), на земле
остаются гильзы, кровь, выбоины и копоть, близкий взрыв трясёт экран. Горожане болтают на улице и
обсуждают стрельбу на границе.

## Граница

На концах главного проспекта — два пограничных КПП: пустошь с завалами, ворота, коридор с
бетонными блоками, бункеры ГО. У обоих не затихает перестрелка: отряды повстанцев подходят
волнами, часовые GRID держат посты, медик HELIX лечит раненых. У края экрана — указатели на КПП
(в бою — оранжевые). Иногда отряд прорывается в город — код красный, комендантский час, OTA.

**Капт КПП** (как в SAMP): если у КПП собралось 5 и больше повстанцев, начинается захват на 2,5
минуты — сверху табло со счётом убийств в зоне КПП. Повстанцы набрали 8 убийств с перевесом (или к
концу таймера хотя бы 4 и больше, чем у Альянса) — КПП захвачен: повстанцы на постах, код красный.
Альянс через минуту идёт в контрудар и отбивает КПП, когда в коридоре не останется повстанцев.
Игрок тоже в счёте: за повстанцев — помогайте брать, за ГО — держите оборону.

## Канализация и сопротивление

Под городом — канализация (отдельная область той же карты): тоннели со стоками, убежище
сопротивления с гарнизоном и тайником, чёрный рынок. В город ведут люки в переулках (E у люка).
Повстанец начинает в убежище.

- Из убежища сопротивление ходит на операции: **саботаж** узлов Альянса (терминалы на проспектах
  и площади) и **засады** на патрули ГО — через люки, потом обратно под землю.
- Нападение на ГО или саботаж в городе — **код жёлтый**: Администратор объявляет тревогу, патрули
  стягиваются к месту, проверки CID чаще. Нападавшие ушли в канализацию — след потерян, отбой.
  Много погибших сотрудников — код красный.
- Повстанец-игрок может саботировать узел сам (E у узла, 5 с) — сопротивление платит токены.
  Сломанные узлы чинит ГСР.
- **Чёрный рынок** (E у прилавка в канализации): оружие и патроны, поддельная CID; скупает трофеи
  и рационы.
- NPC не видят затылком: стрелка за спиной замечают, только когда он выстрелит, — и то не сразу.

## Лояльность и сохранение

У граждан и ГСР есть лояльность: растёт за рационы, пройденные проверки, работу, доносы и
поощрения ГО, падает за штрафы, аресты и оскорбления. Лоялистов реже проверяют, им больше токенов
в рационе и скидка в магазине; неблагонадёжных проверяют чаще.

Игра сохраняется в браузере автоматически (раз в 20 с и при закрытии вкладки) и продолжается при
следующем запуске. Начать заново — «Новая игра» в меню выбора роли.

## Карты

- `?seed=123` — карта по seed (текущий seed всегда виден в адресе и в панели F2).
- «Сохранить JSON» в панели F2 скачивает карту. Положите файл в `public/maps/` и откройте
  `?map=имя_файла_без_.json`. Пример: `?map=city17`.
- В JSON тайлы записаны строками по символу на тайл — удобно дорабатывать руками
  (легенда символов — в поле `legend`). После правки панель F2 покажет, связна ли карта.

Подробности архитектуры — в [CLAUDE.md](CLAUDE.md).
